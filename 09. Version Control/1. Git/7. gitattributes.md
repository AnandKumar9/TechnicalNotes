##### What is it

Its a file named `.gitattributes` (placed in root directory of the repository) or `attributes` in `.git/info`, and allows various micro customizations on files that match the specified patterns in the file.

Each line in gitattributes file is of the below form where pattern indicates the file path, and attributes indicate the attributes to be used for those files.
```
pattern attr1 attr2 ...
```

Thereafter for any given path, each of the attributes take one of these states. <br>
`Set` - If its just an attribute name, then this attribute's value is `True` for files that match the pattern. <br>
`Unset` - If its just an attribute name preceded by `-`, then this attribute's value is `False` for files that match the pattern. <br>
`Set to a value` - If its an attribite name followed by `=<somevalue>`, then this attribute's value is as specified for files that match the pattern. <br>
`Unspecified` - If the file that does not match any pattern, the attribute for that path is termed as undefined.

When more than one pattern matches the path, a later line overrides an earlier line.

[Official documentation](https://git-scm.com/docs/gitattributes) <br>
[Official examples](https://git-scm.com/book/en/v2/Customizing-Git-Git-Attributes) <br>

##### Examples

`merge` - Its an attribute with some particular allowed values. `text` means a usual 3-way file level merge for text files. Conflicted regions are marked with conflict markers `<<<<<<<`, `=======` and `>>>>>>>`. The version from your branch appears before the `=======` marker. `binary` means the version from your branch is kept in the work tree, but the path is left in the conflicted state for the user to sort out. `union` means a merge is done by taking lines from both versions, instead of leaving conflict markers. This tends to leave the added lines in the resulting file in random order and the user should verify the result.
```
*.pbxproj merge=union
```
Its also possible to define custom merge attributes, they need to be defined in `gitconfig` file.
```
$ git config --global merge.ours.driver true   // Make entry in gitconfig

database.xml merge=ours     // In gitattributes file
```
