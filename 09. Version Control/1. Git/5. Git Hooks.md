###### What are Git hooks

Git hooks are scripts that can automatically run when certain actions are performed. <br>
For example a `pre-push` hook runs locally before a push to a remote is made. A `pre-receive` hook runs on a remote before a push is made to it. So these hooks can be added locally or even on a server.

All hooks reside in `.git/hooks` folder. There are already a bunch of samples there which can just be activated by removing their `.sample` extension.

###### pre-push hook

Runs locally and if it exits with anything other than 0, the push is aborted. It gets 2 arguments, the first one is the name of the remote and the second one is the remote's URL.

A sample pre-push hook that contains code to stop any pushes to 'upstream'.

```
if [ "$1" = "upstream" ]
then
	echo "A pre-push hook prevents pushes to upstream. Push to origin instead." >&2
	exit 1
fi
```
That `>&2` is needed for outputting the echo message to Tower's console. [link](https://www.git-tower.com/help/mac/faq-and-tips/faq/hook-scripts)
