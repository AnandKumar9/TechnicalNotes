###### Gitignore

The files that should not be tracked can be placed in a `gitignore` file. Each line in the file specifies a glob pattern of files that should be ignored by git.

`Glob patterns` are like simplified regular expressions that shells use.

1. Blank lines or line starting with `#` are ignored. <br>
1. `*` matches zero or more characters. <br>
1. `[]` matches any character inside the brackets. <br>
1. `?` matches a single character <br>
1. `([-])` matches any character between the specified characters. <br>
