#### Components with platform specific properties (`@platform`)

Certain components may have properties that work on one platform only. All of these props are annotated with `@platform` and have a small badge next to them on the website.

#### Platform module (detecting platform from code)

There is a module that detects the platform in which the app is running. You can use the detection logic to implement platform-specific code. Use this option when only small parts of a component are platform-specific. ([Reference](https://reactnative.dev/docs/platform-specific-code#platform-module))

`````react
import {Platform, StyleSheet} from 'react-native';

const styles = StyleSheet.create({
  height: Platform.OS === 'ios' ? 200 : 100,
});
`````

#### Platform specific extensions (platform specific files)

When needed code can be split into separate files. React Native will detect when a file has a `.ios.` or `.android.` extension and load the relevant platform file when required from other components.

#### Native specific extensions

`.native.js` extension for a file is used when a module needs to be shared between NodeJS/Web and React Native but it has no Android/iOS differences. This is especially useful for projects that have common code shared among React Native and ReactJS.
