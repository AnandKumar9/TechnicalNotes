##### Adding native libraries to RN app

On iOS, usually pod install is done with `npx pod-install` , and the the app needs to be rebuilt using `npm run ios` before the native library can be used in RN codebase. (But then how to use it codebase?) ([link](https://reactnative.dev/docs/libraries?package-manager=npm#linking-native-code-on-ios))

There are similar steps for linking Android libs too using Gradle. ([link](https://reactnative.dev/docs/libraries?package-manager=npm#linking-native-code-on-android))
