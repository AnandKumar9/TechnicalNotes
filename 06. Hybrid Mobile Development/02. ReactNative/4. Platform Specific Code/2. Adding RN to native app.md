##### Adding RN to native app

([Link](https://reactnative.dev/docs/integration-with-existing-apps?language=swift) - Has steps for iOS ObjC and Android too.)

The recommended steps - 

1. Move iOS app to a new directory.
2. Add a package.json in root and add configure project specs there. Then install the RN packages with `npm install react-native`, and React packages with `npm install react@version_used_by_RN_above`. This creates a `/node_modules` folder, all JS dependencies hereon get saved there.
3. Install Cocoapods with the usual `brew install cocoapods` and have the podfile use the dependencies from ` /node_modules/react-native/React.podspec`. Install the pods.
4. Develop the required RN code. It then becomes available in native through a UIView that is of the type `RCTRootView`.
