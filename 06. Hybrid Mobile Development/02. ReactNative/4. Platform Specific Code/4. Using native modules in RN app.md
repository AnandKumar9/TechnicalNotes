##### The Basics

There are obviously times when a native API is not having an equivalent RN interface. For example, iOS' Calendar farmework does not have an equivalent RN interface. The `NativeModule` system exposes instances of Java/Objective-C/C++ (native) classes to JavaScript (JS) as JS objects, thereby allowing you to execute arbitrary native code from within JS. 

There are 3 ways the `NativeModule` system can be set up.

1. Creating a local library that can be imported in your React Native application.
2. Directly within your React Native application's iOS/Android projects
3. As a NPM package that can be installed as a dependency by your/other React Native applications.

##### iOS Native Module (Using it directly within RN's iOS project)

The idea is to create ObjC files in the project's xcodeworkspace/xcodeproj, have it import `<React/RCTBridgeModule.h>` (which it already has access to) and then use a macro named `RCT_EXPORT_MODULE` in it. This then becomes available in the JS code. ([link](https://reactnative.dev/docs/native-modules-ios))

##### Native Modules as NPM Package 

Done using `npx create-react-native-library`. ([link](https://reactnative.dev/docs/native-modules-setup))
