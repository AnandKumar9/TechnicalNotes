`react-native-dotenv` and `react-native-config` are often used for storing API endpoints, etc. The usual recommendation for handling API keys is to forward them throigh another API call which can then inject the correct API key after some more validation.

`Async Storage` is an open source package that allows asynchronous, unencrypted, key-value persistent store.

`Keychain Services` ([link](https://developer.apple.com/documentation/security/keychain_services)) is used for accessing persisting secure data on iOS (its not for iOS Keychain access however as for that there are other libraries such as `expo-secure-store`).

There are similar packages for Android too.

More [here](https://reactnative.dev/docs/security#network-security) on other things like SSL Pinning, etc.
