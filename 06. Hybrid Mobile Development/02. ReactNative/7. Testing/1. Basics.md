`Jest` ([link](https://jestjs.io/)) is the JS testing framework that is commonly used. It has support for mocking too.

`Integration Testing` typically implies making real API calls (integrating with other systems) or even doing I/O  with local files/databases, etc. in tests.

`Component Tetsing`, i.e. UI testing is often done using `Test Renderer` ([link](https://reactjs.org/docs/test-renderer.html)) and `React Native Testing Library` ([link](https://callstack.github.io/react-native-testing-library/)). 

Component tests are only JavaScript tests running in Node.js environment. They do not take into account any iOS, Android, or other platform code.

`Maestro` ([link](https://maestro.mobile.dev)) is a UI testing framework. `Detox` ([link](https://github.com/wix/detox/)) is yet another tool that is used, it actually runs on device/simulator.

Snapshot testing is also possible.

[Reference](https://reactnative.dev/docs/testing-overview)
