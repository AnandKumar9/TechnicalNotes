#### Debugging with breakpoints
Run the app in Debug mode, either from menu option or from the 'context header' in `main.dart`.

| Menu option                                     | From 'context header' in `main.dart`            |
| ----------------------------------------------- | ----------------------------------------------- |
| ![](assets/Pasted%20image%2020240619195158.png) | ![](assets/Pasted%20image%2020240619195146.png) |
|                                                 |                                                 |
|                                                 |                                                 |
Breakpoints are set just the way they usually are in any IDE, the left gutter i.e.. When the breakpoints are hit, the variables, stack trace, etc. are shown in the left pane and there is a bar on the top which can be used to step over, continue, etc.

#### Flutter DevTools

Flutter DevTools can be opened from Command Palette.

| ![](assets/Pasted%20image%2020240619200539.png) | ![](assets/Pasted%20image%2020240619200552.png) |
| ----------------------------------------------- | ----------------------------------------------- |
There are several tools there. One of them is 'Open DevTools in Web Browser', which can opens a page in a browser that shows several things including the Widget Tree. Its basically like Safari/Chrome developer tools with several things including Memory, CPU Profiler, etc.
