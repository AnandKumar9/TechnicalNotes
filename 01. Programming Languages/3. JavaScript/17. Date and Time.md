#### Date and time

```
let now = new Date();
let Jan01_1970 = new Date(0); // Date for milliseconds since 01/01/1970 UTC+0.

let date = new Date("2017-01-26"); // Local timezone
new Date(year, month, date, hours, minutes, seconds, ms);
```

`Timestamp` is the number of milliseconds that has passed since the beginning of 1970. It’s a lightweight numeric representation of a date. Dates before 01.01.1970 have negative timestamps.

Accessing date components.
```
getFullYear()
getMonth()  // 0 to 11
getDate()
getHours(), getMinutes(), getSeconds(), getMilliseconds()

getUTCHours() // Hour in UTC+0 time zone
getTime() // Get timestamp
getTimezoneOffset() // Difference between UTC and local time zone, in minutes
```

Setting date components. Every one of them except `setTime()` has a UTC-variant (for instance `setUTCHours()`).
```
setFullYear(year, [month], [date])
setMonth(month, [date])
setDate(date)
setHours(hour, [min], [sec], [ms])
setMinutes(min, [sec], [ms])
setSeconds(sec, [ms])
setMilliseconds(ms)
setTime(milliseconds)
```

```
let today = new Date();
today.setHours(0);
```

If out-of-range values are given, it auto-adjusts itself. <br>
When a Date object is converted to number, it becomes the timestamp same as `date.getTime()`. <br>

If just time needed for a task needs to be measured, a full fledged `Date` object is not needed. There’s a special method `Date.now()` that returns the current timestamp and suffices.

For more accurate instrumentation of time taken in tasks, more conventions need to be followed (they are explained in [JavaScript.info - Benchmarking](https://javascript.info/date)).

`Date.parse()` can read a date from a string. It returns a timestamp. And then a `Date` object can be created from that timestamp if needed.
```
let ms = Date.parse('2012-01-26T13:51:50.417-07:00');
alert(ms); // 1327611110417
let date = new Date(ms);
```
