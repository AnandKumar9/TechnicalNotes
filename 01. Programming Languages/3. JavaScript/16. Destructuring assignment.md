Destructuring assignment is a special syntax that allows us to “unpack” arrays or objects into a bunch of variables, as sometimes that’s more convenient. The entire array/object is not always needed.

#### Array destructuring

```
let arr = ["John", "Smith"]
let [firstName, surname] = arr;
```

Elements can be ignored using comma.
```
let [firstName, , title] = ["Julius", "Caesar", "Consul", "of the Roman Republic"];
alert( title ); // Consul
```

It also works with any iterable on the right-side, not just arrays.
```
let [a, b, c] = "abc"; // ["a", "b", "c"]
let [one, two, three] = new Set([1, 2, 3]);
```

There can be any 'assignable' at the left side.
```
let user = {};
[user.name, user.surname] = "John Smith".split(' ');
```

`...` (also known as `rest pattern`) gathers all the unnamed elements in an array itself.
```
let [name1, name2, ...rest] = ["Julius", "Caesar", "Consul", "of the Roman Republic"];
```

If the array is shorter than the list of variables at the left, there’ll be no errors. Absent values are considered undefined. A default value can be specified using `=`.
```
let [name = "Guest", surname = "Anonymous"] = ["Julius"];
```

#### Object destructuring

The basic synatx is this.
```
let {var1, var2} = {var1:…, var2:…}
```

The order atually does not matter (probably a precise verbiage matching is done for keys). This works too.
```
let {height, width, title} = { title: "Menu", height: 200, width: 100 }
```

If the property has to be assigned to a variable with another name, it can be done with variable name using a colon.
```
let options = {
  title: "Menu",
  width: 100,
  height: 200
};

let {width: w, height: h, title} = options;
```

For potentially missing properties default values can be set using `=`.
```
let {width = 100, height = 200, title} = options;
```

`Rest pattern` can be used here as well.
```
let {title, ...rest} = options;
```

> Things can get more complicated if an Object has one of its propery as an Object itself. It can still be done, and is known as `Nested destructuring`. The destructuring chapter in JavaScript.info explains it too ([link](https://javascript.info/destructuring-assignment)).

#### Smart function parameters

If a function needs several arguments, while calling it can also be simply passed as an object (and the object can also not have properties for things it need not pass and let the default values come at work).

```
let options = {
  title: "My menu",
  items: ["Item1", "Item2"]
};

function showMenu({title = "Untitled", width = 200, height = 100, items = []}) {
  ...
}

showMenu(options);  // Just the object passed hereORKIN
```
