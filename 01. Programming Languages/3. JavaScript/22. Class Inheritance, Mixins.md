#### Class Inheritance

```
class Animal {
  constructor(name) {
    this.speed = 0;
    this.name = name;
  }
  run(speed) {
    this.speed = speed;
    alert(`${this.name} runs with speed ${this.speed}.`);
  }
  stop() {
    this.speed = 0;
    alert(`${this.name} stands still.`);
  }
}

class Rabbit extends Animal {
  hide() {
    alert(`${this.name} hides!`);
  }
}

let rabbit = new Rabbit("White Rabbit");
```

Class syntax allows to specify not just a class, but any expression after `extends`.

```
function f(phrase) {
  return class {
    sayHi() { alert(phrase); }
  };
}

class User extends f("Hello") {}
```

`super.method(...)` calls a parent method. `super(...)` calls a parent constructor (only from the subclass constructor). When overriding a constructor, parent constructor must be called as `super()` in child constructor before using `this`.

Also, arrow functions have no `super`.

(JavaScript.info [link](https://javascript.info/class-inheritance))

#### private and protected

Protected fields start with `_`. Its a convention, not enforced at the language level. Programmers should only access a field starting with `_` from its class and classes inheriting from it.

Private fields start with `#`. JavaScript makes sure they can only be accessed from inside the class. Right now, private fields are not well-supported among browsers (environment?), but can be polyfilled.

```
class CoffeeMachine {
  #waterAmount = 20;
}

let machine = new CoffeeMachine();
alert(machine.#waterAmount); // Error
```

#### mixins

A mixin provides methods that implement a certain behavior, which can then be added to multiple classes.

This can be implemented by copying methods into prototype.

```
// mixin
let sayHiMixin = {
  sayHi() {
    alert(`Hello ${this.name}`);
  },
  sayBye() {
    alert(`Bye ${this.name}`);
  }
};

// usage:
class User {
  constructor(name) {
    this.name = name;
  }
}

// copy the methods
Object.assign(User.prototype, sayHiMixin);

// now User can say hi
new User("Dude").sayHi(); // Hello Dude!
```
