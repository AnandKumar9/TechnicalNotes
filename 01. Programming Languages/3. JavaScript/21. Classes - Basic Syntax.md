A similar thing can be achieved to some extent by contructor functions, but classes are more advanced.

#### Basic syntax

```
class MyClass {
  constructor() { ... }
  method1() { ... }
  method2() { ... }
  method3() { ... }
  ...
}

let a = new MyClass();
```

```
class UserA {
  constructor(name) {
    this.name = name;
  }

  sayHi() {
    console.log(this.name);
  }
}

let user1 = new UserA("user1");
user1.sayHi();
```

Within a class, no commas are required.

#### Some differences from Object constructors

Class methods are non-enumerable. A class definition sets enumerable flag to false for all methods in the `prototype`. That’s good, because then `for..in` for it does not return methods.

Classes always use strict. All code inside the class construct is automatically in strict mode.

#### Class Expression

It basically means assigning a class template itself to a variable.

```
let User = class {
  sayHi() {
    alert("Hello");
  }
};
```

Similar to Named Function Expressions, class expressions too can have a name, and it's visible only inside the class.

```
let User = class MyClass {
  sayHi() {
    alert(MyClass); // MyClass name is visible only inside the class
  }
};
```

#### Getters/Setters

```
class User {

  constructor(name) {
    this.name = name;
  }

  get name() {    // getter
    return this._name;
  }

  set name(value) {    // setter
    if (value.length < 4) {
      alert("Name is too short.");
      return;
    }
    this._name = value;
  }

}
```

#### Computed names


The method name itself can be computed dynamically.
```
class User {

  ['say' + 'Hi']() {
    alert("Hello");
  }

}

new User().sayHi();
```

#### Class fields

`Class fields` is a syntax that allows to add properties to the class.

```
class User {
  name = "John"; // class field, just need a `=`

  sayHi() {
    alert(`Hello, ${this.name}!`);
  }
}

new User().sayHi();
```

#### Static properties and methods

```
class MyClass {
  static property = ...;

  static method() {
    ...
  }
}

MyClass.property = ...
MyClass.method = ...
```

Static properties and methods too can be inherited.

#### `instanceof` operator

`instanceof` operator checks if a variable is of a certain class and takes into account inheritance too.

```
class Rabbit {}
let rabbit = new Rabbit();

alert( rabbit instanceof Rabbit ); // true
```
