#### 8 basic data types

> 7 primitive types - `string`, `number`, `bigint`, `boolean`, `symbol`, `null`, `undefined`. The 8th type is `Object` but its not a primitive type.

##### Number

`number` - Int, float. Besides regular numbers, there are so-called 'special numeric values' - `Infinity`, `-Infinity`, and `NaN`. Because of `NaN`, doing maths is “safe” in JavaScript. The script will never stop with a fatal error and at worst it’ll give `NaN` as the result. While writing any numbers, `_` can also be used as needed for ease in reading. The JavaScript engine ignores underscores in numbers. Also, a number with trailing zeroes can be written using `e` with teh successing number indicating how many trailing zeroes are there. Decimal places can similarly be specified with a negative sign after `e`. `0x`, `0b`, and `0o` are used for hexadecimal, binary and octal numbers respectively.
```
let n = 123;

let billion = 1_000_000_000;
let m = 7.3e9;  // 7.3 billions (same as 7_300_000_000)
let ms = 1e-6; // 0.000001

let h = 0xff; // hexadecimal form of 255
let a = 0b11111111; // binary form of 255
let b = 0o377; // octal form of 255
alert( a == b ); // true
```

`toString()` method converts a number from one base to another (returns a string).
```
let num = 255;
alert( num.toString(16) );  // ff
alert( num.toString(2) );   // 11111111
```

If a method has to be called directly on a number, there need to be two dots specified (As one dot could also mean a decimal point).
```
alert( 123456..toString(36) ); // 2n9c
```

Rounding can be done with functions such as `Math.floor` (lower), `Math.ceil` (upper), `Math.round` (nearest), `Math.trunc` (removes anything after decimal point).

`Math.random()` gives a random number between 0 and 1 (not including 1). `Math.pow(n, power)` returns n raised to the specified power.

##### BigInt

`BigInt` - `Number` type cannot represent integer values larger than (2^53-1), or lesser than -(2^53-1). This type is for numbers outside that bound. Its created by appending `n` to the end of an integer.
```
const bigInt = 1234567890123456789012345678901234567890n;
```

##### String

`String` - The obvious thing. Double and single quotes are simple quotes. Backticks are used when interpolated strings are needed.
```
let name = "John";
alert( `Hello, ${name}!`)
```

The internal format for strings is always `UTF-16`.

Strings can be enclosed within either single quotes, double quotes or backticks. Backticks however, are special as they allow to embed any expression into the string, by wrapping it in `${…}`. They also allow a string to span multiple lines.
```
alert(`1 + 2 = ${sum(1, 2)}.`);
```

There are special characters such as `\n` (newline), `\t` (tab), etc.

`len` property returns the length of a string.

```
str[0];  // Character at 1st position
str.charAt(0);  // Character at 1st position

alert( 'Interface'.toUpperCase() );
alert( 'Interface'.toLowerCase() );
```

`indexOf()` can be used to search (Case sensitive) for substrings. If not found, it returns `-1` and instead of checking for `-1`, a bitwise not can also be used (it somehow does the same thing.). <br>
`str.includes(substr, pos)`  is now also available and it simply returns true/false.
```
// Searching for substrings. ()
let str = 'Widget with id';

alert( str.indexOf('Widget') ); // 0, found
alert( str.indexOf('widget') ); // -1, not found

if (~str.indexOf("Widget")) {
  .... Found
}

alert( "Widget with id".includes("Widget") ); // true
```

Getting a substring from a string.
```
let str = "stringify";
alert( str.slice(0, 5) ); // 'strin',  substring from 0 to 5.
alert( str.substring(2, 6) ); // "ring"
alert( str.substr(2, 4) ); // 'ring', 4 chars from 2nd position
```

##### Boolean

`Boolean` - `true`/`false`

##### null

`null` - Just a special value which means 'nothing'.
let unknownThing = null;

##### undefined

`undefined` - Just means that a value is currently unassigned. Its the default value for variables that are declared without an initial value. However, explicitly using this type is not common or recommended.
```
age = undefined;
```

##### Symbol

`symbol` - Used to create unique identifiers for objects.

##### Object

`object` - They store keyed collections of various data and more complex entities (so they are like dictionaries).
```
let user = new Object();
let user = {};
let user = {
  name: "John",
  age: 30
};
```

##### `typeof` operator

Returns the type of the argument.

```
typeof undefined // "undefined"
typeof 0 // "number"
typeof 10n // "bigint"
typeof true // "boolean"
typeof "foo" // "string"
typeof Symbol("id") // "symbol"
typeof Math // "object"
typeof null // "object"
typeof alert // "function"  
```

`typeof x` can also be written as `typeof(x)`, however its important to remember that typeof is indeed an operator and not a function.

> `Math` is a built-in object that provides mathematical operations.

##### Type conversion

Often, operators and functions automatically convert the values given to them to the right type. For example, alert automatically converts any value to a string to show it. However, sometimes the type conversion needs to be done explicitly.

```
String(value) // Converts to String

Number(value) // Converts to Number. If value string is not a valid number, nan is returned. null and false are converted to 0, and true to 1.

Boolean(value) // Converts to Boolean. 0, an empty string, null, undefined, and NaN become false. Everything else becomes true. Note that `"0"` however is true.
```

Numeric conversion happens in mathematical functions and expressions automatically. Such as when `"6"/"2"` is done.

##### Underneath even primitve types are objects

Underneath, even primitive types are wrapped in specific objects (termed as `Object wrappers`) that actually provide the various methods that are available for primitive types. These wrappers are different for each primitive type.

Usually these object wrappers have the same name and begin with upper case (for example the wrapper for `number` is `Number`), and while its possible to use them directly its not recommended.

Also, `null` and `undefined` have no object wrappers and have no methods.
