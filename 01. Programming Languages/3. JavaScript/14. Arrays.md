#### Arrays

Array is an object and thus behaves like an object. For instance, it is copied by reference

```
// Creating an array
let arr = new Array();
let arr = [];
let fruits = ["Apple", "Orange", "Plum"];
let arr = new Array("Apple", "Pear", "etc"); // Rare

// Accessing any element in the array
alert( fruits[0] ); // Apple
fruits[2] = 'Pear';

// Array length
alert( fruits.length ); // 3

// Append an element
fruits[3] = 'Lemon';
fruits.push("Pear")
fruits.push("Orange", "Peach"); // Multiple at once

// Add an element to the beginning
fruits.unshift('Apple');
fruits.unshift("Pineapple", "Lemon"); // Multiple at once

// Remove the last element and return it
alert( fruits.pop() );

// Extracts the first element of the array and return it
alert( fruits.shift() );
```

An array can have its elements be of different types.
```
let arr = [ 'Apple', { name: 'John' }, true, function() { alert('hello'); } ];
```

> Methods `push`/`pop` run fast, while `shift`/`unshift` are slow.

Iterating through an array.
```
for (let i = 0; i < arr.length; i++) { .... }

for (let fruit of fruits) { .... }

for (let key in arr) { .... } // Not advisable
```

Arrays have their own implementation of `toString` method that returns a comma-separated list of elements.

##### Multidimensional Arrays

```
let matrix = [
  [1, 2, 3],
  [4, 5, 6],
  [7, 8, 9]
];

alert( matrix[1][1] ); // 5, the central element
```

##### Array Methods

```
arr.push(...items) – adds items to the end,
arr.pop() – extracts an item from the end,
arr.shift() – extracts an item from the beginning,
arr.unshift(...items) – adds items to the beginning.
```

```
delete arr[1] // Deletes item at index 1, but does not shift later elements!
```

`arr.splice(start[, deleteCount, elem1, ..., elemN])` modifies arr starting from the index `start:` removes `deleteCount` elements and then inserts `elem1, ..., elemN` at their place. Returns the array of removed elements. Its hence a much safer way to delete elements from an array.
```
let removed = arr.splice(0, 2); // Remove first 2 elements
```

It can also insert the elements without any removals. For that we need to set deleteCount to 0
```
arr.splice(2, 0, "complex", "language");
```

Negative indexes are allowed in `splice()` and other methods. They specify the position from the end of the array.
```
// From index -1 (one step from the end), delete 0 elements and then insert 3 and 4.
arr.splice(-1, 0, 3, 4);
```

`arr.slice([start], [end])` returns a new array copying to it all items from index `start` to `end` (not including end). Both start and end can be negative, in that case position from array end is assumed.

```
arr.concat([3, 4] // Concatenates another array and returns

indexOf(item, from) // Looks for item starting from index from, and returns the index where it was found, otherwise -1.

lastIndexOf(item, from) // Looks from right to left.

includes(item, from) // Looks for item starting from index from

arr.reverse(); // Reverses the array
```

A function can be run for each element using `forEach`. The result of the function (if it returns any) is thrown away and ignored.
```
["Bilbo", "Gandalf", "Nazgul"].forEach((item, index, array) => {
  alert(`${item} is at index ${index} in ${array}`);
});
```

Finds the first element matching a condition.
```
let user = users.find(item => item.id == 1);
```

Create a new array by filtering elements from another array.
```
let someUsers = users.filter(item => item.id < 3);
```

Map to a new array.
```
let result = arr.map(function(item, index, array) {
  // returns the new value instead of item
});
```

Reduce to a single value.
```
let value = arr.reduce(function(accumulator, item, index, array) {
  // ...
}, [initial]);

let result = arr.reduce((sum, current) => sum + current, 0);
```

Sort the array in place, changing its element order.
```
METHOD 1:
function compareNumeric(a, b) {
  if (a > b) return 1;
  if (a == b) return 0;
  if (a < b) return -1;
}

let arr = [ 1, 2, 15 ];

arr.sort(compareNumeric);

METHOD 2:
[1, -2, 15, 2, 0, 8].sort(function(a, b) {
  alert( a + " <> " + b );
  return a - b;
});
```

Split and join.
```
let arr = names.split(', ');

let str = arr.join(';')
```

`Array.isArray()` can be used to check if something is an array.
```
alert(Array.isArray([])); // true
```

Almost all array methods that call functions – like `find`, `filter`, `map`, with a notable exception of `sort`, accept an optional additional parameter `thisArg`. The value of `thisArg` parameter becomes `this` for func.
