#### Nested classes

###### When to use nested classes

Nested classes are allowed in Java and even encouraged. They can be declared as non-static as well as static.

```
class OuterClass {
    ...
    static class StaticNestedClass {
        ...
    }
    class InnerClass {
        ...
    }
}
```

It facilitates encapsulation.  
Consider two top-level classes, A and B, where B needs access to members of A that would otherwise be declared private. By hiding class B within class A, A's members can be declared private and B can access them. In addition, B itself can be hidden from the outside world.

###### Accessing members of enclosing scope

If a declaration of a type (such as a member variable or a parameter name) in a particular scope (such as an inner class or a method definition) has the same name as another declaration in the enclosing scope, then the declaration shadows the declaration of the enclosing scope. You cannot refer to a shadowed declaration by its name alone.

> Here, FirstLevel accesses ShadowTest's x as 'ShadowTest.this.x'.

```
public class ShadowTest {

    public int x = 0;

    class FirstLevel {

        public int x = 1;

        void methodInFirstLevel(int x) {
            System.out.println("x = " + x);
            System.out.println("this.x = " + this.x);
            System.out.println("ShadowTest.this.x = " + ShadowTest.this.x);
        }
    }
}
```

###### Should not be serialized

[Serialization](https://docs.oracle.com/javase/tutorial/jndi/objects/serial.html) of inner classes, including local and anonymous classes, is strongly discouraged. ([link](https://docs.oracle.com/javase/tutorial/java/javaOO/nested.html))

###### Local Classes and Anonymous Classes

`Local classes` are classes declared within the body of a method.

If they are declared without even naming the class, they are known as `anonymous classes`.

Local classes are similar to inner classes because they cannot define or declare any static members. You cannot declare static initializers or member interfaces in a local class.

A local class can have static members provided that they are constant variables.

Interfaces cannot be declared inside a block; interfaces are inherently static.

Here `frenchGreeting` is initialized using an anonymous class. ([link](https://docs.oracle.com/javase/tutorial/java/javaOO/anonymousclasses.html))
```
interface HelloWorld {
    public void greet();
    public void greetSomeone(String someone);
}

public void sayHello() {        
    HelloWorld frenchGreeting = new HelloWorld() {
        String name = "tout le monde";
        public void greet() {
            greetSomeone("tout le monde");
        }
        public void greetSomeone(String someone) {
            name = someone;
            System.out.println("Salut " + name);
        }
    };
}
```

#### Lambda Expressions

Lambda expressions are expressions that allow single-method classes to be created using a syntax that is even shorter than anonymous classes.

```
Person.printPersonsOlderThan_2(people, (Person p) -> p.age >= 36);
```

Here `printPersonsOlderThan_2` is a method that needs a `List<Person>` and another class which conforms to a functional interface (a functional interface is any interface that contains only one abstract method.).
```
interface CheckPerson {
    boolean test(Person p);
}

public static void printPersonsOlderThan_2(List<Person> roster, CheckPerson tester) {
```

The 2nd arguments is what is specified as lambda expression.

###### Syntax of Lambda expressions

It has a comma-separated list of formal parameters enclosed in parentheses. The data type of the parameters can be omitted, and if there is only one parameter the parentheses too can be omitted. `return` can be explicitly specified but the definition must be in parentheses.

###### Method References

If a lambda expression just calls another method, the syntax can be further shortened by using `method references`.

Here the 2nd argument is just a method reference and semantically the same as lambda expression `(a, b) -> Person.compareByAge(a, b)`.
```
Arrays.sort(rosterAsArray, Person::compareByAge);
```

There are 4 different kinds of method references.

Kind | Example
--- | ---
Reference to a static method | ContainingClass::staticMethodName
Reference to an instance method of a particular object | containingObject::instanceMethodName
Reference to an instance method of an arbitrary object of a particular type | ContainingType::methodName
Reference to a constructor | ClassName::new

###### Misc.

Like local and anonymous classes, lambda expressions too can capture variables from the enclosing scope.

Lambda expression can be serialized if its `target type` and its captured arguments are serializable. However, like inner classes, the serialization of lambda expressions is strongly discouraged. ([link](https://docs.oracle.com/javase/tutorial/java/javaOO/lambdaexpressions.html#target-typing))
