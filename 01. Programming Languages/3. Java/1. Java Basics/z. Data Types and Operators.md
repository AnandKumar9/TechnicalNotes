#### Data Types

##### Primitive data types
<br>

`boolean` <br>
`char` - UTF-16 character <br>
`byte` - 8 bit signed integer <br>
`short` - 16 bit signed integer <br>
`int` - 32 bit signed integer <br>
`long` - 64 bit signed integer <br>
`float` - 32 bit floating point <br>
`double` - 64 bit floating point <br>

Each of these primitive types also have a wrapper class. `Integer` is the wrapper class for `int`. In most contexts, the language automatically converts between primitive types and objects of the wrapper class if one type is used where the other is expected.

##### Reference data types
<br>

`string`

##### Misc.

`String[] args` - `args` is an array of `String` objects

#### Operators

###### Bitwise operators

`~` - Unary bitwise complement <br>
`<<` - Signed left shift <br>
`>>` - Signed/Arithmetic right shift <br>
`>>>` - Unsigned/Logical right shift <br>
`&` - Bitwise AND <br>
`^` - Bitwise exclusive OR <br>
`|` - Bitwise inclusive OR <br>

###### Increment and Decrement operators

```
i++
++i
i--
--i
```

###### Relational operators

```
- > < == >= <= !=
```
