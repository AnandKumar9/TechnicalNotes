The terminology used is `Class`, `instances` of class. The term `Object` is rather nebulous (its used interchangeably to denote both a class and its instances).

#### Class

Class with fields (i.e. variables/properties), methods (i.e. functions) and a constructor too.
```
public class Triangle {
    double base;
    double height;

    public Triangle(double base, double height) {
        this.base = base;
        this.height = height;
    }

    public double calculateSumOfBaseAndHeight() {
        return (this.base + this.height);
    }
}
```

###### Inheriting another class

Class that inherits another class. `extends` keyword needs to be used. A class can only extend one superclass.
```
class Polygon {
    int numberOfSides;
}

class Rectangle extends Polygon {
    double height;
    double width;

    Rectangle(double height, double width) {
        this.numberOfSides = 4;
        this.height = height;
        this.width = width;
    }
}
```

##### Constructors

It's not mandated to use `this` in methods and constructors. Wherever possible they need not be used.

`this` can also be used in a constructor to call another constructor of its own class.
```
public class Rectangle {
    private int x, y;
    private int width, height;

    public Rectangle() {
        this(0, 0, 1, 1);
    }

    public Rectangle(int x, int y, int width, int height) {
        this.x = x;
        this.y = y;
        this.width = width;
        this.height = height;
    }
}
```

It isn't required to provide a constructor for a class as every class gets an empty constructor (with no arguments) by default. But be careful with this as then instance variables may end up having default and unintended values. Or the superclass's default constructor may get used unintentionally.

##### Methods

It's possible to pass variable number of arguments to a function using `varargs` (its not a keyword per se). However this can be done only with the last parameter. The variable arguments get treated like an array inside the method definition.

> Here 4 gets treated as a point and 2, 9 as sides.

```
rectangle1.func1(4, 2, 9);

void func1(double point, int... sides) {
    System.out.println(sides.length);
}
```

If a parameter name happens to be same as that of field (i.e. instance variable) of same class, it is said to be `shadowing the field`. Just a jargon.

###### Passing by value and reference

Primitive arguments, such as an int or a double, are passed into methods by value.

Reference data type parameters, such as objects, are also passed into methods by value. This means that when the method returns, the passed-in reference still references the same object as before. However, the values of the object's fields can be changed in the method, if they have the proper access level.

###### Return type

If a method's declaration says that it returns a class then the returned object must be either a subclass or of the exact class as mentioned in the declaration.

It's possible for a subclass to override a method of its superclass and define it to return a subclass of the return type specified in the original declaration. This is known as `covariant return type`.

The return type can also be an `interface`.

#### Package

A package is something that organizes together related classes and interfaces.
Java platform itself comes with a huge library (known as [API](https://docs.oracle.com/javase/8/docs/api/index.html)), i.e. collection of packages.
