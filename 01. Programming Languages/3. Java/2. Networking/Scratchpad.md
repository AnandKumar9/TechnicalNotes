`Java applets` are a way to run Java programs from a browser.

Its location is typically embedded inside a web page in a special HTML tag, the `<APPLET>` tag. They can be downloaded from the internet as well as fetched locally from the system. The use of local applets however is not recommended, and local applets are blocked when the security level setting in the Java Control Panel is set to High or Very High.

An applet must be a subclass of the `java.applet.Applet` class. Swing provides a special subclass of the Applet class called `javax.swing.JApplet`.
