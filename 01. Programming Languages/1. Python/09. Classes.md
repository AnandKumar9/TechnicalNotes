##### Sample class definition

```
class Expense:
    transactionAmount = None
    transactionType = None

    def __init__(self, merchantName, transactionAmount):
        self.merchantName = merchantName
        self.transactionAmount = transactionAmount

    def doSomething1():
        print(Expense.transactionAmount)

    def doSomething2(self):
        print(self.transactionAmount)
```

A class must be defined before it can be used anywhere. And it can be placed almost anywhere, including say inside a function, or the branch of an if statement.

##### Namespace, Class Object

The moment the interpreter enters inside the class name, the following portion is said to be a new `namespace` and that namespace is used as the local/current scope. When the interpreter leaves the end of a class, it creates a `class object` using the name of the class.

Using class objects, two kinds of things can be done with its members - `Attribute references`, `Instantiation`.

##### Class attribute references

`Attribute reference` is accessing the class's members such as `Expense.transactionAmount` or even its functions like `Expense.doSomething1`.

Note that these are different from when they are accessed using class's instances, and also that there is no paranthesis when the function attribute is accessed. Class attributes can also be assigned new values, so this can be a way to change them from outside the class.

```
print(Expense.transactionAmount)   # Prints initial value, say 0
Expense.transactionAmount = 9
print(Expense.transactionAmount)   # Prints 9
```

> Does changing an attribute reference's value also change that value for instance objects of the class?

Attribute references can be for any names that were there in the class when class was defined. (So if new names/variables are later added to the class, I think those will not be available using attribute references.)

##### Class instantiation

Instantiating a class, i.e. creating an instance is as simple as calling the class name with parenthesis, such as `Expense()`. If the class has no `__init__` function defined, just the initializer needs to be passed with no arguments passed to if. If the class has an `__init__` function defined without arguments (say) it does something inside it anyway) then calling the intializer without arguments invokes that. If the class has an `__init__` function defined with arguments, the the initializer should be called with arguments.

```
class Expense:
  # No __init__ function defined

expense1 = Expense()

--

class Expense:
  def def __init__():

expense2 = Expense()

--

class Expense:
  def __init__(self, merchantName, transactionAmount):

expense3 = Expense("Netflix", 11.99)
```

##### Instance objects

The only thing understood by instance objects is attribute reference (which includes data attributes and methods).

Data attributes need not be declared; like local variables, they spring into existence when they are first assigned to.
```
class Expense:
    transactionAmount = None

expense1 = Expense()
expense1.transactionName = "name1"
```

When methods are accessed from instance objects they are called `Method objects`, and when accessed from class objects they are called `Function objects`.

When method objects are called, the instance object is automatically passed as the first argument to the function. Hence, when declared they must have the first argument as something that denotes an instance.

```
class Expense:
    transactionAmount = 0

    def doSomething2(self):
        print(self.transactionAmount)

expense1 = Expense()
expense1.doSomething2()
```

Every class has an attribute called `__class__` that can give the class name.

##### Inheritance

Derived classes may override methods of their base classes.

> In C++ jargon, all methods in Python are effectively virtual.

###### Calling another method of same class

When a base class method calls another method of the same class, its possible for it to end up calling an overridden method of the base class instead as shown below. There is a different way to call the base class method directly: just call `BaseClassName.methodname(self, arguments)`.
```
class ClassA:
    varA1 = 1
    varA2 = 2

    def funcA(self):
        print("Aa")
        self.funcB()

    def funcB(self):
        print("Ab")

    def funcC(self):
        print("Aa")
        ClassA.funcB(self)

class ClassB(ClassA):
    varB1 = 3

    def funcB(self):
        print("Ba")

instanceAa = ClassA()
instanceAa.funcA() # Prints Aa and Ab

instanceBa = ClassB()
instanceBa.funcA() # Prints Aa and Ba
instanceBa.funcC() # Prints Aa and Ab
```

###### isinstance() and issubclass()

`isinstance()` checks an instance’s type: isinstance(obj, int) will be True only if `obj.__class__` is int or some class derived from int.

`issubclass()` checks class inheritance: issubclass(bool, int) is True since bool is a subclass of int. However, issubclass(float, int) is False since float is not a subclass of int.

###### Multiple Inheritence

```
class DerivedClassName(Base1, Base2, Base3):
```

if an attribute is not found in DerivedClassName, it is searched for in Base1, then (recursively) in the base classes of Base1, and if it was not found there, it was searched for in Base2, and so on. But it does get more complicated than that. Something known as `Dynamic Ordering` to dynamically to support cooperative calls to super(). ###### Private Variables

Private instance variables that cannot be accessed except from inside an object don’t exist in Python. However, there is a convention that a name prefixed with an underscore (e.g. _spam) should be treated as a non-public part of the API.

#### Iterators and Generators

Behind the scenes, the `for` statement calls `iter()` on the container object. The function returns an `iterator` object that defines the method `__next__()` which accesses elements in the container one at a time. When there are no more elements, `__next__()` raises a `StopIteration` exception which tells the for loop to terminate.

It is possible to add iterator behavior to classes too. An  `__iter__()` method needs to be defined which returns an object which has a `__next__()` method. [Link](https://docs.python.org/3/tutorial/classes.html#iterators)

`Generators` are a simple way of creating iterators. They are written like regular functions but use the `yield` statement whenever they want to return data. ([Link](https://docs.python.org/3/tutorial/classes.html#generators))
