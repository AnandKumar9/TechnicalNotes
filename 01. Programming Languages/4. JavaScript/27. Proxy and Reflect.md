A `Proxy` object wraps another object and can intercepts operations like reading/writing properties and more.

Here `target` is the object to wrap, it can be anything (including functions), and `handler` is the proxy configuration, i.e. an object with traps (methods that intercept operations).
```
let proxy = new Proxy(target, handler)
```

For most operations on objects, there’s a so-called “internal method” in the JavaScript specification that describes how it works at the lowest level. For instance `[[Get]]`, the internal method to read a property, `[[Set]`], the internal method to write a property, and so on. These methods are only used in the specification and can't be called directly, but they can be intercepted. Proxy traps intercept invocations of these methods. They are listed in the [Proxy specification](https://tc39.es/ecma262/#sec-proxy-object-internal-methods-and-internal-slots) and some of them are mentioned here.

Internal Method | Handler Method | Triggers when
--- | --- | ---
`[[Get]]` | `get` | Reading a property
`[[Set]]`| `set` | Writing to a property
`[[HasProperty]]` | `has` | `in` operator
`[[Call]]` | `apply` | Function call

`Reflect` is a built-in object that simplifies creation of `Proxy`.
