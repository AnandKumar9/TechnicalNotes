#### Prototypal Inheritance

All objects have a special hidden property `[[Prototype]]`, that is either null or references another object. That object is called a 'prototype'.

Essentially, its a way of specifying a 'super object' for a any object, so that when an attempt is made to access an property that does not exist in an object it instead gets automatically queried in the specified super object. Its done by assigning the super object to `__proto__` property of the object.

```
let animal = {
  eats: true
};
let rabbit = {
  jumps: true
};

rabbit.__proto__ = animal; // Super object specified here
console.log(rabbit.eats);  // true
```

Also, an object may not inherit from two others.

`__proto__` is not quite the same as the internal `[[Prototype]]` property. It’s a getter/setter for `[[Prototype]]`. It exists for historical reasons, modern JavaScript suggests to use `Object.getPrototypeOf`/`Object.setPrototypeOf` funtions instead.

##### Can only be used for reading properties

The prototype is only used for reading properties. Write/delete operations work directly with the super object.

```
let animal = {
  eats: true,
  isWild: true
};
let rabbit = {
  jumps: true
};

rabbit.__proto__ = animal;
rabbit.isWild = false
console.log(animal.isWild); // true
console.log(rabbit.isWild); // false
```

##### for..in loop with inherited properties

The `for..in` loop iterates over inherited properties too. If inherited properties are to be excluded, the built-in method `obj.hasOwnProperty(key)` needs to be used.

```
for(let prop in rabbit) {
  let isOwn = rabbit.hasOwnProperty(prop);
  if (isOwn) { ... } else { ... }
}
```

#### Using prototype objects for objects created with constructor function

```
let animal = {
  eats: true
};
function Rabbit(name) {
  this.name = name;
}

Rabbit.prototype = animal;
let rabbit = new Rabbit("White Rabbit");
alert( rabbit.eats ); // true
```

If, after the creation, F.prototype property changes (`F.prototype = <another object>`), then new objects created by new F will have another object as `[[Prototype]]`, but already existing objects keep the old one.

Also, by default all functions have `F.prototype = { constructor: F }`, so the constructor of an object can be got by accessing its `constructor` property.

#### Prototype methods

There are modern methods to setup a prototype. `__proto__` is considered outdated and somewhat deprecated (in browser-only part of the JavaScript standard).

`Object.create(proto, [descriptors])` - Creates an empty object with given `proto` as `[[Prototype]]` and optional property descriptors.

`Object.getPrototypeOf(obj)` - Returns the `[[Prototype]]` of `obj`.

`Object.setPrototypeOf(obj, proto)` – Sets the `[[Prototype]]` of `obj` to `proto`.

```
let animal = {
  eats: true
};

let rabbit = Object.create(animal);
alert(rabbit.eats); // true

Object.setPrototypeOf(rabbit, {}); // change the prototype of rabbit to {}
```

Lot more details in JavaScript.info section ([link](https://javascript.info/prototype-methods)).
