###### Cloning

```
protected Object clone() throws CloneNotSupportedException
```

Object's implementation of this method checks to see whether the object on which clone() was invoked implements the `Cloneable` interface. If the object does not, the method throws a CloneNotSupportedException exception.

```
class Hexagon extends Polygon implements Cloneable {

  @Override
  protected Object clone() throws CloneNotSupportedException {
      return super.clone();
  }
}

Hexagon hexagon3 = (Hexagon)hexagon2.clone();

```

###### Checking Equality

`equals()` method compares two objects for equality and returns true if they are equal. The `equals()` method provided in the Object class uses the identity operator (`==`)

```
public boolean equals(Object obj)
```

```
@Override
public boolean equals(Object obj) {
    if (obj instanceof Hexagon)
        return numberOfSides == ((Hexagon) obj).numberOfSides;
    else
        return false;
}
```

`equals()` should always be overridden if the identity operator is not appropriate for a class. Also if `equals()` is indeed overridden, `hashCode()` should be overridden as well.


###### finalize

`finalize()` may be invoked on an object when it becomes garbage. It can be used for cleanup.

```
protected void finalize() throws Throwable
```

###### getClass, hashCode, toString

```
public final Class getClass()
```

`getClass()` returns a Class object, which has methods that can be used to get information about the class, such as its name (`getSimpleName()`), the superclass (`getSuperclass(`)), and the interfaces it implements (`getInterfaces()`).

```
public int hashCode()
```

The value returned by `hashCode()` is the object's hash code, which is the object's memory address in hexadecimal.

Object's `toString()` method returns a String representation of the object, which is very useful for debugging. This too should ideally be overridden in custom classes to provide more detailed information.

```
public String toString()
```
