##### What is it

`rbenv` is basically yet another Ruby version manager tool (like RVM) for Unix-like systems. ([Link](https://github.com/rbenv/rbenv))

##### How to Install

###### Using Homebrew

```shell
brew install rbenv ruby-build
```

Then add the the following in `PATH` (DONE IN `.zprofile` file here).

`````shell
export PATH="$HOME/.rbenv/bin:$PATH"
`````

Add this to '.zprofile' (if using zsh) either manually or through `echo 'eval "$(rbenv init -)"' >> ~/.zprofile`

```shell
eval "$(rbenv init -)" 
```

And make sure its active (if not relaunching Terminal)

```shell
source ~/.zprofile
```

##### How to use it

In the working directory, there needs to be a file named `.ruby-version` which has the Ruby version to be used listed.

`````
3.0.3
`````

Make sure that doing a `which ruby` gives the rbenv path and not the system Ruby path (i.e. '/usr/bin/ruby').

```swift
➜  Mastodon git:(bj/migrate-to-bazel) which ruby
/Users/anand/.rbenv/shims/ruby
```

And then do this

`````
rbenv install
`````

##### Commands

`rbenv versions` - Gives the local Ruby versions available using Rbenv.

```swift
➜  Mastodon git:(bj/migrate-to-bazel) rbenv versions
  system
* 3.0.3 (set by /Users/anand/Projects/iOS/Bazel/Mastodon/.ruby-version)
```

`rbenv version` - Gives the currently active Ruby version.

```swift
➜  Mastodon git:(bj/migrate-to-bazel) rbenv version 
3.0.3 (set by /Users/anand/Projects/iOS/Bazel/Mastodon/.ruby-version)
```

`rbenv local` - Sets the Ruby version to be used by writing it in the local `.ruby-version` file. If that Ruby version is not yet installed will not write it.

`````
➜  Mastodon git:(bj/migrate-to-bazel) rbenv local 3.0.4
rbenv: version `3.0.4' not installed
`````

`rbenv install` - Installs the required Ruby. Does not ship with rbenv out-of-the-box, but is provided by the 'ruby-build' plugin.
