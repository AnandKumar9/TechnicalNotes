##### Ruby and its implementations

`Ruby` is the language. <br>

In fact there can even be multiple implementations of Ruby. That is not just multiple versions of the language, but multiple implementations themselves (each  with some tweaks of their own). <br> They all should conform to a specification called `RubySpec` though.

Here are some of the `Ruby implementations`. <br>

```
MRI
JRuby
Rubinius
Maglev
Rubymotion
```
`MRI` (Matz' Reference Implementation) is the original implementation of Ruby and all other implementations maintain compatibility with it. Its written in C.

`JRuby` is written in Java and Ruby.<br> `Rubinius` is written in ruby itself but with a C++ bytecode.

##### System Ruby and why it shouldn't be messed with

It's possible to have multiple versions of Ruby installed in your system and selectively use the one you want on the go. 

macOS comes pre-installed with Ruby and its there at `/usr/bin/ruby`, and it doesn't let you change the Ruby version installed there without using 'sudo'. However its strongly discouraged to use 'sudo' to change the Ruby installed there as it may mess up the OS in unpredictable ways. 

Ruby environment managers must be used instead. They typically also entail the `PATH` variable to be modified so that the location of the new Ruby version can be easily understood.

([link](https://stackoverflow.com/questions/51126403/you-dont-have-write-permissions-for-the-library-ruby-gems-2-3-0-directory-ma))

##### Ruby environment managers

These things are enabled by a `Ruby environment manager` and there are a few of them. <br>

```
RVM
ruby-build
rbenv
chruby
```

`RVM` stands for Ruby Version Manager and is likely the most popular. It can install as well as switch between different versions of Ruby. <br>
`ruby-build` only installs Rubies and is often used in conjunction with `rbvenv` which is used to switch between rubies. `chruby` too only switches between rubies.

##### Gems

Ruby packages (i.e. libraries) themselves are called `gems`. For example, `Nokogiri` is a gem to parse XML. In fact, `Cocoapods` too is a gem.

Here are some of the common gems.

Testing frameworks - `TestUnit`, `RSpec`, `Cucumber`, `minitest` <br>
XML parsing - `Nokogiri`

##### Package Managers (RubyGems) and Dependency Resolvers (Bundler)

`RubyGems` is a package manager for Ruby and it ships with Ruby itself. (Package manager is something which is used to build and distribute packages, i.e. gems.)

`Bundler` is gem dependency resolver.  That is, it can look at all the dependencies (circular, recursive, etc.) of a gem and install the necessary ones. A gem's `gemfile` lists all its dependencies.

##### Commands

Get currently active version of Ruby - <br>
`ruby -v` (Gives something like `ruby 2.4.1p121`)

Get currently installed version of RVM -  <br>
`rvm -v` (Gives something like `rvm 1.29.4`)

Get the current version of RubyGems (?) - <br>
`gem -v` (Gives something like `2.6.14`)

Get the current version of Bundler - <br>
`bundle -v` (Gives something like `1.6.1`)

Get currently active version of Ruby through RVM - <br>
`rvm current` (Gives something like `ruby-2.4.1`)

Get the installation directory of currently active version of Ruby - <br>
`which ruby` (Gives something like `/Users/sou543/.rvm/rubies/ruby-2.4.1/bin/ruby`)


Get all the details of current RubyGems ()?) - <br>
`gem env` (Gives the RubyGems version, Ruby version, installation directory, etc.)

Install a gem (without Bundler) (?) - <br>
`gem install GemName`

Install bundler - <br>
`gem install bundler` (Remember bundler too itself is actually a gem)
