#### Supervised Learning

`Supervised Learning` - There is a known category (i.e. `label`) for all the data points that are available. The chosen algorithm is fed these datapoints along with the respective categories. The process of assigning categories (i.e. labels) to datapoints is known as `Labelling` or `Classification`

Data points are normalized and given scaled values (usually between -1 and 1, or even better 0 and 1, the less the variance the smaller the scale). That's what is known as `normalization`, a scale of 0 to 1 is best but its ok to extend on either side as its not getting ridiculously huge (like minus one million to one million) .

When an algorithm is given known data points so that it can adjust its internal weights, etc., that is known as `training the model`. The `model` here is the algorithm, and its trained using `Training data`. Its later tested using remaining known data points, termed as `Testing data`.

##### SVC (Support Vector Classification)

The dimensions in a data point are known as `features`. If the data points have just 2 features its possible to draw them in a graph. In one kind of ML algorithm, i.e. `SVC (Support vector Classification)` these points can be divided using one line. 

> The SciKit module that's there for SVC algorithm is known as `svm`.

![image-20231214115552011](assets/image-20231214115552011.png) 

Note that while its not possible to draw data points in a graph when they have more than two features, the concept of SVC still holds. There are times when such data points with n features can still be divided using SVC. Also, in reality data points usually have lot more than just 2 features.

###### Sample code snippet using Scikit

A sample code that uses supervised learning through SciKit to predict what is the hand-drawn digit in an image.

```
x = np.array([[1, 2], [5, 8], [1.5, 1.8], [8, 8], [1, 0.6], [10, 11]])  // Normalized datapoints
y = [0, 1, 0, 1, 0, 1]  // Labeling (i.e. classification) of data

clf = svm.SVC(kernel='linear', C=1.0)
clf.fit(x, y)  // Training happens here
print(clf.predict([[0.58, 10.76]]))  // Prediction happens here
```

#### Unsupervised Learning

`Unsupervised Learning` - The data points are not given categories (i.e. `clusters`). At the most the algorithm might be told that there are n categories across these data points (but not what those categories are), or not even that. 

In unsupervised learning the algorithm itself decides what is a reasonable way to decide clusters/labels.

When even the number of categories is not specified, that is known as `Hierarchical unsupervised learning`.  

##### Flat Clustering

When the number of categories is specified, that is known as `Flat unsupervised learning`.
