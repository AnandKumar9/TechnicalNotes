###### Converting a NSData having number with hexadecimal characters verbatim into a string

If a `NSData` is printed in debug console and it prints something like below, then it can be converted to `NSString` verbatim using the code snippet in above link.
```
<f6e7cd28 0fc5b5d4 88f8394b af216506 bc1bba86 4d5b483d>
@"f6e7cd280fc5b5d488f8394baf216506bc1bba864d5b483d"
```

Its advisable not to use the `description` method as even though it may appear to do the job, its implementation can change later on and besides even now its implementation differs based on the hardware.

[link](http://stackoverflow.com/questions/7520615/how-to-convert-an-nsdata-into-an-nsstring-hex-string/7520723#7520723)

###### Converting a NSString having hexadecimal number to its decimal equivalent as integer.  

Set the `scanLocation` appropriately for the NSScanner. Have it as `0` for usual cases and `1` for cases when there is a preceding `#`.

If a string has a hexadecimal such as below, it should be converted to its equivalent int.
```
@"01FFFFAB"
33554347
```
