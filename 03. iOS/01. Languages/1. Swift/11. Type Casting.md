`is` `as` `as?` `as!`

Type casting is used within a hierarchy of classes and subclasses to check the type of a particular instance and to even cast that instance to another class within the same hierarchy.
it can also be used to check whether a type conform to a protocol.

##### Type check operator (is) -

`Type check operator (is)` checks whether an instance is a of a certain class type or if it even conforms to the mentioned protocol.


```
# `SpecifiedType` below can be a class, struct, etc. or
even a protocol.
if instance is SpecifiedType { .. }

```

It returns true is instance is of the same type as the specified type. <br>
It returns true also if instance is of a type that inherits from the specified type. <br>
If returns false if instance is of a type that is a superclass of the specified type. <br><br>
It of course returns false if instance is of a type that is no where in the class hierarchy of the specified type.

> Think of `is` as _has everything that is there in_.

##### Downcasting (as? and as!) -

Downcasting attempts to downcast the instance to specified type.

`as? (conditional type cast)` returns an optional which actually has a value when the downcasting is possible and nil when it is not.

`as! (forced type cast)` does not return an optional. It just assumes that the downcasting will succeed and if it does not, it gives a runtime error (i.e. a crash).

```
if let x = houseStark as? House {
    print(x.capital!)
}

let x = houseStark as! House
print(x.capital!)
```

> Implicit optionals are treated like non-optionals, but for some reason they cannot be passed as an `inout` argument to function that takes the wrapped type as input. ** Why?, Try to simulate this. **

##### as operator -

`as` simply casts the instance to specified type and does not even compile if not possible. So is not of much practical use.

##### Any and AnyObject -

`Any` represents an instance of any type at all, including function types.
`AnyObject` represents an instance of any class type.

`Any` type even includes optional types. However the complier gives warning if an optional is used _as is_ where an Any is being expected. If however it is type casted to Any, there is no warning.
