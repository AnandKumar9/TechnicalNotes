###### for-in

`...` indicates a closed range. Hence here the loop iterator includes 1 and 5.
```
for index in 1...5 {
```

> While iterating over a dictionary, the current element is automatically made available as a tuple.
for (key, value) in numberOfLegs {

###### while and repeat while

`while` loop executes if the condition is true. `repeat-while` executes at least once and then evaluates the condition before executing again. Both these loops are mostly used when a condition has to be satisfied for the loop to run.

```
repeat {
    ..
} while (forecastedWeather ==.good)
```

###### switch

> The first thing to keep in mind is that switch need not be applied on enums alone. They can even be applied on other things such as variables and tuples.

In case of `switch`, the statements do not fall through the bottom of each case and into the next one by default. Instead, the entire switch statement finishes its execution as soon as the first matching switch case is completed, without requiring an explicit `break` statement. If however, any case should actually fallthrough to the next case then the `fallthrough` keyword needs to be used before that case.

```
case 2, 3: ..
    fallthrough
case 4: ..
```

Every case though should have some statement, even if just a break alone.

Cases can match the `switch` variable to a range.
```
switch approximateCount {
case 5..<12:.. (This includes 5, but not 12)
```

They can even match tuples.
```
switch somePoint {
	case (0, 0):
	case (_, 0):
	case (-2...2, -2...2):
```

In fact in case of tuple switches, the values that are unknown can be even be bound to variables. This is known as `value binding`.

```
switch anotherPoint {
  case (let x, 0):
  case (0, let y)
  case let (x, y):
```

And further on, a case can even have where clauses.
```
case let (x, y) where x == y:
```

Multiple cases can be combined together. These are called `compound cases`. They too have value bindings. However all the patterns should include the same set of value bindings, and each binding has to get a value of the same type from all of the patterns in the compound case.
```
case (let distance, 0), (0, let distance):
```

In case of enum switch, there should be cases for all possible values (or a default there in the end).

###### Labels

Loops can even be given labels (i.e. names) and then while doing a break or continue later on in case of nested loops, it can be said that the break or continue applies to which loop.
```
gameLoop: while square != finalSquare {
	switch(someCondition)
	..
	break gameLoop
  // Here the label causes break from the while loop. Without the label, the break would have happened just to the switch.
```

###### where clause
There can be a `where` cause with for loops (but not with while loops?). Essentially only those elements are iterated for which the where clause returns a true.

```
for i in 0..<10 where i%2 == 0 {
   print(i, terminator: " ")
}
```

###### guard and defer conditionals

`guard` is another conditional like `if`. It needs an expression after that which should result in a boolean and then if the boolean is not true the else part executes. The `else` is mandatory and it must also exit the current scope, by using `return` in functions, `continue` or `break` in loops, or a `@noreturn` function like fatalError().

Any new optional bindings created in a `guard` statement’s condition are available for the rest of the function or block

```
guard consideredPlayer.name == "MSD" else {
	throw MakeCaptainError.captainFewMatches
}

guard a < 5 else { return }
```

`defer` allows the specified code to be executed only after the current block has executed. Its typically used for clean up activities after a function has executed. It cannot contain any code that explicitly transfers the control out, such as break or return.

Also defer actions are executed in reverse order of how they are specified, i.e. first `defer` executes after the second defer (try it, what does it exactly mean).

```
func giveCaptaincyTo(consideredPlayer :Player) throws -> Void {
	defer {
		print("Tried changing captain")
	}
	..
```
