#### Advanced Array functions

`forEach` - Runs the passed closure through all the elements of the array. The closure need not return anything. <br>
```
array.forEach { print($0 + " how is it going") }
```

`filter` - Creates another array matching the passed condition. The closure should return a boolean. <br>
```
let nonEmptyComponents = allComponents.filter { $0 != "" }
```
> Thankfully Swift 4 onwards, the `Set` version of `filter` produces a filtered `Set` instead of an `Array`.

`map` - Creates another array by performing the passed closure on each of the elements in the array. The closure should return some element. <br>
```
let lowercaseNames = cast.map { $0.lowercaseString }
```

`flatMap` - Applies a transform to every element of the array, each transform is expected to return an array itself. The function concatenates together all the arrays, thereby flattening the individual arrays by one level.

```
let array1 = [[1], [2, 3], [4]]
let array1a = array1.flatMap { $0 }   // Returns [1, 2, 3, 4]
```

`compactMap` - Applies a transform to every element of the array, if the transform returns `nil` that element is ignored, and if the transform returns anything else that is inserted in the new array.

```
let array1 = Array(0...6)
let array4 = array1.compactMap { ($0 % 2 != 0) ? $0*10 : nil }   // Returns [10, 30, 50]
```
`reduce` - Returns a single value after going through all the elements of the array.
```
let array1 = [3, 5, 9, 10]
array1.reduce(0, +)   // Gives the sum, i.e. 27
```

Actually the way it works is that it has to be given an initial value as the first argument and then a closure which gets two arguments, the previous result and the current element of the array. The closure should then return the new result.
```
return coupons.reduce(false, {$0 || ($1.isFeatured)!})
```
Here $0 is previous result and $1 is current element of the array.

`reduce(into:)` - Similar to `reduce` but allows the partial result to be modified (by making it an `inout` argument in the closure) and hence the entire operation becomes more efficient as the same partial result that initially got created, keeps getting updated (instead of new partial results being created every time). With this though the partial result has to be actually updated in the closure, a new value can't just be returned.

```
let arr1 = [2,4,5,6,8]
let value2 = arr1.reduce(into: 0) { $0 += $1 }
```

`prefix` - Returns the first n elements as a new array (as many as available, there is no crash if array has fewer elements).
```
let y = array1.prefix(20)
```

`prefix(through:)` - Returns the elements up to index n as a new array (there is crash if array length is lesser).
```
let y = array1.prefix(through: 4)
```

`suffix` - Does not cause a crash <br>
`suffix(from:)` - Can crash

`dropFirst(:)` - Returns a new array containing all but the first n elements. Does not crash. <br>
`dropFirst`, `dropLast`, `dropLast(:)` - None of them cause a crash <br>

`prefix(while:)` - Returns the initial elements as a new array until the passed condition is true. <br>
`drop(while:)` - Ignores elements until the passed condition is true and then returns the remaining elements as a new array. <br>
Both these methods are actually part of `Sequence` protocol (hence not just in Array alone) and are available only from Swift 3.1.

`removeAll(where:)` - Removes all elements that match the closure. Its an inverted version of `filter`.

`contains(where:)` - Tells if the array contains any element for which the passes closure returns a true. <br>
`allSatisfy(:)` - Tells if all elements satsisy the passed closure. <br>
`first(where:)` - Returns the first element for which the passed closure returns a true. If there is no matching element, it returns a nil. <br>
`last(where:)` - The opposite of `first(where:)`

`firstIndex(of:)` - Returns the first index where the passed element appears
`firstIndex(where:)` - Returns the first index where the element satisfying passed closure appears.
`lastIndex(of:)` - The opposite of `firstIndex(of:)
`lastIndex(where:)` - The opposite of `firstIndex(where:)

`removeLast` - Removes and returns the last element. Crashes if the array is empty.
`popLast` - Removes and returns the last element as an optional. Does not crash if the array is empty.

`swapAt(_:_:)` - Swaps elements in specified indices.

`partition(by:)` - Mutates the array so that all the elements satisfying the passed predicate are moved to the end.

`init(unsafeUninitializedCapacity:initializingWith:)` - A special initializer for Arrays. It was implemented in Swift 5.1 via [SE-0245](https://github.com/apple/swift-evolution/blob/master/proposals/0245-array-uninitialized-initializer.md). Allows arrays of a certain capacity to be created without having to assign initial values to all the elements. This is useful when array initialization is otherwise expected to be an expensive operation.
```
let randomNumbers = Array<Int>(unsafeUninitializedCapacity: 10) { buffer, initializedCount in
    for x in 0..<10 {
        buffer[x] = Int.random(in: 0...10)
    }
    initializedCount = 10
}
```

#### Advanced Sequence functions

`zip` - Takes two `Sequence` collections and creates a new `Sequence` with the same number of elements as in the shorter collection, where every element is a tuple with two elements (one from each collection).
```
let words = ["one", "two", "three", "four"]
let numbers = 1...4
let zippedTuples = zip(numbers, words)
// zippedTuples will now be [(1, "one"), (2, "two"), ..]
```
The resulting `Sequence` though is of type `Zip2Sequence` and does need to be converted into `Array`, etc. if needed.

`shuffle` - Can be used on Collections too. Shuffles the sequence/collection's contents.

#### Advanced Dictionary functions

`grouping:by:` initializer - It takes a `Sequence` and creates a dictionary whose keys are the unique things returned by a closure applied on every element of the sequence. The values are arrays where all the elements that returned the same item from the closure are grouped together (in the same order).

> Example in my playground `TestPlayground/11. Collections`

`uniqueKeysWithValues:` initializer - Creates a dictionary from a sequence of tuples (key-value pairs) where the keys must be unique (or else there is a runtime exception).

```
let names = ["Cagney", "Lacey", "Bensen"]
let dict = Dictionary(uniqueKeysWithValues: zip(names, 1...))
print(dict["Lacey"])    // Prints Optional(2)
```

`(_:uniquingKeysWith:) initializer` - Takes a sequence of key-value pair tuples as first argument and a closure as second argument. All unique keys across the two are merged and for any overlapping key, the passed closure is invoked to get the value for that key.

`mapValues(_:)` - Returns a new dictionary where values have been mapped as per the passed transform applied on existing values.

`compactMapValues(_:)` - Returns a new dictionary where values have been mapped as per the passed transform applied on existing values, and the entries for which the transform returns nil are skipped.

`filter(_:)` - Swift 4 onwards this thankfully returns a filtered dictionary, not an array.

`[:default:]` - Returns the default value if the passed key does not exist. Can also be used to change the value of a key if it does not exist.

```
var cart = [🍌: 1]
cart[🍤]                // Gives nil
cart[🍤, default: 0]    // Gives 0

for item in [🍌, 🍌, 🍞] {  
    cart[item, default: 0] += 1   // Can also be used for mutation
}
```

`merge(_:uniquingKeysWith:)` - Same as `(_:uniquingKeysWith:)` but merges an existing dictionary instead of creatinf a new one.
