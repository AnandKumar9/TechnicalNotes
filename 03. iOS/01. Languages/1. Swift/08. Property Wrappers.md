##### Property Wrappers

Property Wrappers offer a convenient syntax for what could also be achieved by getters and setters (i.e. computed properties).

Any enum, struct or class declared with a `@propertyWrapper` declarative, can later be used as a directive for any property. The property wrapper must have a property called `wrappedValue` which then serves as what the property actually corresponds to.

```
@propertyWrapper
struct TwelveOrLess {
    private var number = 0
    var wrappedValue: Int {
        get { return number }
        set { number = min(newValue, 12) }
    }
}

struct SmallRectangle {
    @TwelveOrLess var height: Int
    @TwelveOrLess var width: Int
}
```

Initial value too can be assigned to them using initializers of their own.

```
@propertyWrapper
struct SmallNumber {

init() {
    maximum = 12
    number = 0
}
init(wrappedValue: Int, maximum: Int) {
    self.maximum = maximum
    number = min(wrappedValue, maximum)
}
```

And property wrappers can also expose an alternate special value called `projectedValue` which can be accessed using `$`.

```
@propertyWrapper
struct SmallNumber {
  var projectedValue = false
  ...
}

struct SomeStructure {
    @SmallNumber var someNumber: Int
}

var someStructure = SomeStructure()
print(someStructure.$someNumber)   // Prints false
```
