#### What is it

`resultBuilder` is a new attribute introduced in Swift 5.4. It can be applied to struct, class, or enum.

So an entity can have that delcaration attribute (i.e. `@resultBuilder`), implement the required methods, and then some other property/closure can be qualified with that entity (using `@<entityName>`), which would then make any invocation of that property/closure go through those methods.

The code that uses the result builder can even include some of the ordinary Swift syntax, like `if` and `for` to handle conditionals or repeated pieces of code.

Because all of the result builder's functionality is exposed through static methods, you typically don't initialize an instance of that entity type itself.

> 👉 Essentially keep in mind that anytime there is a declaration such as `@something var xyz: ABC ...`, the 'something' is an attribute and need not always be a propertyWrapper attribute. It can easily be a resultBuilder attribute too. Look into the definition of that attribute to know more.

#### Sample snippets

For example,  over here this weird looking closure with no proper expressions is actually getting evaluated using a result builders named `all` , `any`., `either`, `or`. ([source](https://github.com/ApolloZhu/BoolBuilder))

```swift
let condition: Bool = all {
    any {
        8.isMultiple(of: 2)
        5.isMultiple(of: 2)
            .inverted

        either {
            4.isMultiple(of: 2)
        } or: {
            9.isMultiple(of: 2)
        }
    }
    10.isMultiple(of: 2)
},
```

Given a result builder named 'ArrayBuilder' like this

```swift
@resultBuilder
struct ArrayBuilder {
    typealias Component = [Int]
    typealias Expression = Int
    static func buildExpression(_ element: Expression) -> Component {
        return [element]
    }
}
```

When used to qualified a property like this

```swift
@ArrayBuilder var builderNumber: [Int] { 10 }
```

Gets the property to be exposed as if it was

```swift
var builderNumber = ArrayBuilder.buildExpression(10)
```

#### Requirements

The required methods - 

```swift
static func buildBlock(_ components: Component...) -> Component
```

OR both of these

```swift
static func buildPartialBlock(first: Component) -> Component

static func buildPartialBlock(accumulated: Component, next: Component) -> Component
```

There are more methods like `buildExpresson()`, `buildArray()`, `buildLimitedAvailability()`, etc.

There are also 3 generic associated types/`typealias` - `Expression` (input), `Component` (partial result), `FinalResult`. If the result building methods don't specify a type for `Expression` or `FinalResult`, they default to being same as `Component`.

#### Order in which methods are evaluated

> Creating a result builder type creates a custom attribute with the same name. You can apply that attribute in the following places <br><br>- On a function declaration, the result builder builds the body of the function. <br>- On a variable or subscript declaration that includes a getter, the result builder builds the body of the getter. <br>- On a parameter in a function declaration, the result builder builds the body of a closure that’s passed as the corresponding argument. <br>
