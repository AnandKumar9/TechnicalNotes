##### String and Character

The types are `String` and `Character`. <br>

A string literal is anything in quotes.
```
"Here is a string."
```

`""` can also however also indicate a `Character` when it contains only one character and the variable is already declared to be a `Character`.

`String` is a value type, so the value is always copied when passing around.

Characters in a string can be accessed by iterating over its characters property in a `for-in` loop (the characters property probably returns an array).

Multi-line strings can be specified using `"""`. (The indentation is supposed to begin from the point where last line's quotes start.)
```
let multilineString = """
    This is a multi-line string.
    You don't have to escape "quotes" in here.
    """
```
Inside a multi-line string, a newline can be escaped (i.e. not actually used by specifying a `\`). In below example, the string is actually one line.
```
let escapedNewline = """
    To omit a line break, \
    add a backslash at the end of a line.
		"""
```

Strings can infact also be specified using `#"` as the delimiter, these are known as Raw strings and are particularly convenient when the string needs to have plenty of `"` characters.
```
let rain = #"The "rain" in "Spain" falls mainly on the Spaniards."#
```

##### String interpolation

 It is the creation of `String` by combining constants, variables, literals and expressions.
 ```
 "\(Country) has won the World Cup \(n) times."
 ```
 The expressions written inside parenthesis cannot contain an unescaped backlash, i.e. `\`, a carriage return or a line feed.

 This is even customizable (from Swift 5.0). Its done using `appendInterpolation()` function. In below function wherever a User object is printed somewhere using string interpolation, it will actually print the overridden value. ([link](https://www.hackingwithswift.com/articles/163/how-to-use-custom-string-interpolation-in-swift))
 ```
 extension String.StringInterpolation {
    mutating func appendInterpolation(_ value: User) {
        appendInterpolation("My name is \(value.name) and I'm \(value.age)")
    }
}
 ```

##### Accessing characters of a string (String.index)

`String` is a `Collection` and hence collection methods such as `count` can be used on it.

As different characters take different amount of memory, it is not possible to access individual characters in a string by just using raw numbers (such as 0, 1, etc.) in subscript syntax. Instead first character is fetched using `startIndex` index and the character after last is represented by `endIndex` index.

If a String is empty, `startIndex` and `endIndex` are equal. There are also methods such as `index(before:)` and `index(after:)` to access indices before and after a given index. `index(_:offsetBy:)` represents an index at a given offset from another index. These indexes are of the type `String.index`.

```
let greeting = "Guten Tag!"
greeting[greeting.startIndex]  -- Represents G
```
Attempting to access an index outside of a string’s range or a Character at an index outside of a string’s range triggers a runtime error.

`characters.indices` property returns all of the indices of individual characters in a string.

```
for index in greeting.characters.indices {
    print("\(greeting[index]) ", terminator: "")
}
```

In fact all these index methods can be used on any type that conforms to `Collection` protocol. `String`, `Array`, `Set`, `Dictionary` all conform to it.

##### Built from Unicode scalar values

The `String` type is built from `Unicode scalar values`. A Unicode scalar is a unique 21-bit number for a character or modifier. Not all 21-bit Unicode scalars are assigned to a character, some scalars are reserved for future assignment.

String literals can include the following special characters - <br>

`\0` (null character), `\\` (backslash), `\t` (horizontal tab), `\n` (line feed), `\r` (carriage return), `\"` (double quote) and `\'` (single quote). _There is probably no difference between carriage return and line feed in modern operating systems, they both cause a new line._

An arbitrary Unicode scalar, written as `\u{n}`, where n is a 1–8 digit hexadecimal number with a value equal to a valid Unicode code point. `\u{24}` represents `$`. `\u{2665}` represents `♥`.

```
let dollarSign = "\u{24}"
```

Every instance of Swift’s `Character` type represents a single `extended grapheme cluster`. An `extended grapheme cluster` is a sequence of one or more Unicode scalars that (when combined) produce a single human-readable character.

Both of these represent `é`.
```
let eAcute: Character = "\u{E9}"                         // é
let combinedEAcute: Character = "\u{65}\u{301}"          
// e followed by count property gives the no. of characters in a string and it does take account of extended grapheme clusters, hence \u{E9} (i.e. é) is correctly treated as 1 character.
```

##### Comparing strings -

String values can be compared in 2 ways.
`Equal to (==)` and `Not equal to (!=)` operators

###### When are string values considered equal

Two String values (or two Character values) are considered equal if their extended grapheme clusters are canonically equivalent.
LATIN SMALL LETTER E WITH ACUTE (U+00E9) is canonically equivalent to LATIN SMALL LETTER E (U+0065) followed by COMBINING ACUTE ACCENT (U+0301). Both of these extended grapheme clusters are valid ways to represent the character é, and so they are considered to be canonically equivalent.

Conversely, LATIN CAPITAL LETTER A (U+0041, or "A"), as used in English, is not equivalent to CYRILLIC CAPITAL LETTER A (U+0410, or "А"), as used in Russian. The characters are visually similar, but do not have the same linguistic meaning.

##### Getting UTF8, UTF16 values -
Every string (rather character) also has a `utf8` property that returns its UTF8 value. Similarly there are `utf16` and unicodeScalars properties too.

##### String slices are represented by `Substring`

```
let comma = "Hi, there".index(of: ",")!
let substring = greeting[..<comma]
type(of: substring)       // Substring.Type
```

A `Substring` keeps the full String value it was created from alive. This can lead to accidental high memory usage when you pass a seemingly small Substring that holds on to a large String to other API. For this reason, most functions that take a string as an argument should continue to accept only String instances.

To convert a Substring back to a String, `String()` initializer can be used.
