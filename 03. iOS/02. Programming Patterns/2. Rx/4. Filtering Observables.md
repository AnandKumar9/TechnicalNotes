##### filter

`filter` emits the source observable's next event only if it meets the condition specified in the closure.

```
subscription1 = publishSubject1.filter {
    $0.contains("109")
}.subscribe {
    print("A \($0)")
}
```

##### distinctUntilChanged

Emits the first next event emitted by the source observable and the emits subsequent next events only if its distinct from the previous event that was emitted.

##### throttle and debounce

`throttle` emits only one event within the specified time duration, even if the source observable emits more in the meantime. And after the period, emits only the latest event it skipped in that period and not everything. However, it seems this can be controlled using the `latest` argument.

```
func throttle(_ dueTime: RxTimeInterval, latest: Bool = true, scheduler: SchedulerType) -> Observable<A>
```

`debouce` whereas propagates events from the source observable only if the specified time period has elpased without it propagating any event, and if so propagates only the latest event from the source observable.

```
func debounce(_ dueTime: RxTimeInterval, scheduler: SchedulerType) -> Observable<A>
```

> `throttle` propagates one event and then restricts, whereas `debounce` waits first and then propagates only if there was a period of silence.
