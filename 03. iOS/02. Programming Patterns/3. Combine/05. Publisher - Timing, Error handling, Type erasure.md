> So `Combine` throttle (unlike `Rx` throttle) does not give a way to drop any additional events that get emitted during the throttle period. Here is a custom publisher that can achieve that.

```
extension Publisher {
    func throttleToDrop<S: Scheduler>(for desiredInterval:S.SchedulerTimeType.Stride, scheduler: S) -> AnyPublisher<Output, Failure> {
        scan((lastSentAt: scheduler.now.advanced(by: -desiredInterval), send: nil)) { previousTuple, currentElement in
            guard previousTuple.lastSentAt.distance(to: scheduler.now) >= desiredInterval else {
                return (lastSentAt: previousTuple.lastSentAt, send: nil)
            }
            return (lastSentAt: scheduler.now, send: currentElement)
        }
        .compactMap(\.send)
        .eraseToAnyPublisher()
    }
}
```

#### Handling Errors

`func assertNoFailure(String, file: StaticString, line: UInt) -> Publishers.AssertNoFailure<Self>` - Raises a fatal error when its upstream publisher fails, and otherwise republishes all received input. <br>

####  Performing Type-Erasure

`func eraseToAnyPublisher() -> AnyPublisher<Self.Output, Self.Failure>` - Wraps the outputted value as `AnyPublisher` thereby erasing the underlying type from subscribers. `AnyPublisher` is a concrete implementation of Publisher that has no significant properties of its own, and passes through elements and completion values from its upstream publisher. Wrapping a `Subject` with `AnyPublisher` also prevents callers from accessing its send(_:) method. <br>
