##### EntwineTest

`Combine` does not have good built-in support for unit testing as of 2022, and a separate library named `EntwineTest` ([GitHub link](https://github.com/tcldr/Entwine/blob/master/Assets/EntwineTest/README.md)) needs to be used for it. It provides supports for a test scheduler (which obviates using `RunLoop.main` in tests) as well as virtual time (thereby speeding up tests).

This starts a scheduler with specified initial time.
```
let scheduler = TestScheduler(initialClock: 200)
```

Here the publihser will publish the two mentioned events at virtual time 20s, and 30s.
```
let relativeTimePublisher: TestablePublisher<String, Never> = scheduler.createRelativeTestablePublisher([
    (020, .input("Mi")),
    (030, .input("Fa")),
])
```

This is when the clock actually starts and the events are fired (right away in real time).
```
scheduler.resume()
```
