#### Collecting and Republishing the Oldest Unconsumed Elements from Multiple Publishers

`func zip<P>(P) -> Publishers.Zip<Self, P>` - Returns a publisher that starts publishing values only when each of its member publishers have published at least one value. After that it publishes a value every time each of the upstream publishers have published a new unaccounted value. The published value is a tuple with the earliest unaccounted value from each of the upstream publishers <br>

```
self.cancellable2_zip = numbersPassthroughSubjectA
    .zip(lettersPassthroughSubjectA)
    .sink { print("ZIP - \($0)") }

numbersPassthroughSubjectA.send(3)
lettersPassthroughSubjectA.send("B")

// Prints (1, "A") (2, "B") (3, "C") (4, "D")
```

#### Republishing Elements by Subscribing to New Publishers

`func flatMap<T, P>(maxPublishers: Subscribers.Demand, (Self.Output) -> P) -> Publishers.FlatMap<P, Self>` - Returns a publisher that can take the value published by the upstream publisher and create another pubisher from it in every invocation, and these publishers (the ones that get created, i.e. excluding the upstream publisher) together contribute to the returned publisher. The `maxPublishers` argument specifies how many publishers can be concurrently active. <br>

> Keep in mind that the closure in `flatMap` below returns a publisher, and yet the subsequent `sink` closure directly gets the value emitted by the publisher returned in the previous closure (a 'flattening' is automatically happening as a part of the publisher returned by flatMap).

```
self.cancellable2_flatMap_trivial = [1, 2, 3].publisher
    .flatMap(maxPublishers: .unlimited) { int in
        return (0..<int).publisher
    }
    .sink { print("FLAT-MAP (TRIVIAL) - \($0)") }

// Prints 0 0 1 0 1 2    
```

In the below snippet, only 2 created publisher are allowed to be active at a time. It starts with the first 2 created publishers (i.e. numbersPassthroughSubjectA and numbersPassthroughSubjectB). So any new event published by numbersPassthroughSubjectC will not be considered until one of numbersPassthroughSubjectA or numbersPassthroughSubjectB have finished.

```
self.cancellable2_flatMap_sophisticated = [1, 2, 3].publisher
    .flatMap(maxPublishers: .max(2)) { [unowned self] int -> PassthroughSubject<Int, Never> in
        switch int {
        case 1:
            return self.numbersPassthroughSubjectA
        case 2:
            return self.numbersPassthroughSubjectB
        case 3:
            return self.numbersPassthroughSubjectC
        default:
            return self.numbersPassthroughSubjectC
        }
    }
    .sink { print("FLAT-MAP (SOPHISTICATED) - \($0)") }

numbersPassthroughSubjectB.send(40)
numbersPassthroughSubjectC.send(50)
numbersPassthroughSubjectA.send(4)
numbersPassthroughSubjectA.send(5)
numbersPassthroughSubjectC.send(70)
numbersPassthroughSubjectA.send(completion: .finished)
numbersPassthroughSubjectC.send(80)
numbersPassthroughSubjectB.send(45)

// Prints 40 4 5 80 45
```
