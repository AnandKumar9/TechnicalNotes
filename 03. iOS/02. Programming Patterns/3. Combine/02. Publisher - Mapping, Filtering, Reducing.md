#### Mapping Elements

`func map<T>((Self.Output) -> T) -> Publishers.Map<Self, T>` - Returns a publisher that maps every value emitted by the upstream publisher to a new value as specified by the passed closure.
> To be precise the returned type is a struct `Publishers.Map`, which actually conforms to `Publisher` protocol itself.

`func tryMap<T>((Self.Output) throws -> T) -> Publishers.TryMap<Self, T>` - Like `map`, but the transform also has the ability to throw an error for any value, thereby giving the option to stop the publisher at any point.

`func mapError<E>((Self.Failure) -> E) -> Publishers.MapError<Self, E>` - The returned publisher does not do anything to emitted values, but allows to map emitted error.

`func replaceNil<T>(with: T) -> Publishers.Map<Self, T>` -

`func scan<T>(T, (T, Self.Output) -> T) -> Publishers.Scan<Self, T>` - Allows every emiited value to be aware of the previously emitted values. Like `Sequence reduce`. Returns a publisher that applies the passed transform to the values published by the upstream publisher, where the transform gets passed the previous value returned by the transform and the current value published by the upstream publisher.

```
self.cancellable1_scan = self.publisher1?
    .scan(Date().toString()) { initialString, notification in
        "\(initialString) : \(notification.userInfo?["time"] ?? "")"
    }
    .sink(....)
```


`func tryScan<T>(T, (T, Self.Output) throws -> T) -> Publishers.TryScan<Self, T>` - Like `scan` but the closure can throw an error and stop the publisher.

`func setFailureType<E>(to: E.Type) -> Publishers.SetFailureType<Self, E>` - Available for publishers whose error type is `Never`. Can be used for syntactic compatibility when it needs to be changed to a publisher of a certain error type.
> If the upstream publisher has an error type of its own, then `mapError()` should be used instead.

```
let cancellable = pub1
    .setFailureType(to: Error.self)
    .combineLatest(pub2)
    .sink(....)
```

#### Filtering Elements

`func filter((Self.Output) -> Bool) -> Publishers.Filter<Self>` - Returns a publisher that only emits those emitted values from the upstream publisher that satisfy the passed closure. <br>

`func tryFilter((Self.Output) throws -> Bool) -> Publishers.TryFilter<Self>` - Like `filter`, where the closure also has the ability to throw an error and stop the returned publisher. <br>

`func compactMap<T>((Self.Output) -> T?) -> Publishers.CompactMap<Self, T>` - Think of it as 'filter and then map'. The closure has the option of returning a mapped value which gets emitted by the returned publisher, or a nil which is not. <br>

`func tryCompactMap<T>((Self.Output) throws -> T?) -> Publishers.TryCompactMap<Self, T>` - Like `compactMap` which can also throw error. <br>

`func removeDuplicates() -> Publishers.RemoveDuplicates<Self>` -  Available when the Output type of upstream publisher conforms to `Equatable`. The returned publisher publishes only elements that are not same as the previously published element. <br>

`func removeDuplicates(by: (Self.Output, Self.Output) -> Bool) -> Publishers.RemoveDuplicates<Self>` - Like `removeDuplicates` where duplication check is performed by the passed closure. <br>

`func tryRemoveDuplicates(by: (Self.Output, Self.Output) throws -> Bool) -> Publishers.TryRemoveDuplicates<Self>` -  Like `removeDuplicates(by:)`, where the closure can throw error too. <br>

`func replaceEmpty(with: Self.Output) -> Publishers.ReplaceEmpty<Self>` - Can be used to provide a replacement element if the upstream publisher finishes without producing any elements <br>

`func replaceError(with: Self.Output) -> Publishers.ReplaceError<Self>` -  Replaces any errors in the stream with the provided element. <br>

#### Reducing Elements

`func collect() -> Publishers.Collect<Self>` - Collects all received elements, and emits a single array of the collection when the upstream publisher finishes. <br>

`func collect(Int) -> Publishers.CollectByCount<Self>` - Collects up to the specified number of elements, and then emits a single array of the collection. <br>

`func collect<S>(Publishers.TimeGroupingStrategy<S>, options: S.SchedulerOptions?) -> Publishers.CollectByTime<Self, S>` - Returns a publisher that emits a single value once its upstream publisher has emitted elements as per the passed strategy. `.byTimeOrCount` for instance constraints elements by count or within a specified time period (whichever happens sooner).

```
self.cancellable1_collectByTimeOrCount = Timer.publish(every: 1, on: .main, in: .default)
    .autoconnect()
    .collect(.byTimeOrCount(RunLoop.main, .seconds(5), 2))
//            .collect(.byTime(RunLoop.main, .seconds(5)))
    .sink(....)
```

`func ignoreOutput() -> Publishers.IgnoreOutput<Self>` - Ignores all upstream elements, but passes along the upstream publisher’s completion state. <br>

`func reduce<T>(T, (T, Self.Output) -> T) -> Publishers.Reduce<Self, T>` - Applies a closure that collects each element of a stream and publishes a final result upon completion. <br>

```
let numbers = (0...10)
cancellable = numbers.publisher
    .reduce(0, { accum, next in accum + next })
    .sink { print("\($0)") }
```

`func tryReduce<T>(T, (T, Self.Output) throws -> T) -> Publishers.TryReduce<Self, T>` - Like `reduce` but the closure can throw error too. <br>
