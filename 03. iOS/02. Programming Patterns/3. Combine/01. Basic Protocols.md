#### Basic protocols

Following are the basic protocols that together constitute `Combine` framework.

`Publisher` - Represents a type that can emits values over time, which can then be notified to other entitites (i.e. subscribers). Has associated types `Output`, and `Failure`. <br>

`Subject` - Represents a Publisher that allows outside callers to explicitly publish elements. Has associated types `Input`, and `Failure`. <br>

`Subscriber` - Represents a type that can received inputs from a publisher as it emits values. <br>

`Subscription` - Represents the connection between a publisher and a subscriber. <br>

`Cancellable` - Represents an activity that can be cancelled, Subscription too is a Cancellable. <br>

`Scheduler` - Represents an entity that can define when and how to run a closure. <br>

#### Some sample code snippets

In the below code snippet, `publisher1` is a Publisher that can emit values whenever a Notification with name `custom` is published. `sink(receiveCompletion:receiveValue:)` is called on this publisher, this function runs the provided closures whenever the publisher emits a completion or value and returns a cancellable which represents the subscription.

```
self.publisher1 = NotificationCenter.default.publisher(for: .custom1)

----

self.cancellable1_sink = self.publisher1?
    .sink(receiveCompletion: { completionType in
        print("\(Date().toString()) - \(completionType)")
    }, receiveValue: { notification in
        print("\(Date().toString()) - \(notification.name) - \(notification.userInfo?["time"] ?? "")")
    })


----

NotificationCenter.default.post(Notification(name: .custom1, userInfo: ["time": "\(Date().toString())"]))
```
