#### Publishers namespace

Typically all the return types for various Publisher functions (such as `Publishers.Map`, `Publishers.Collect`, etc.) are structs and also have a property named `upstream` that has the upstream publisher. These structs are typically all under the namespace `Publishers`([link](https://developer.apple.com/documentation/combine/publishers)).

#### AnyPublisher

A concrete implementation of `Publisher` which is used anytime the actual underlying type needs to be hidden from outside world. This done by erasing the actual publisher instance using `eraseToAnyPublisher()` operator. Wrapping a `Subject` with `AnyPublisher` also prevents callers from accessing its `send(_:)` method.

#### Convenience Publishers

`Future` is a publisher that eventually produces a single value and then finishes; or fails. The initializer takes a closure whose argument itself is a closure, referred to by the typealias `Promise`. `Promise` takes a `Result` and does not return anything. Whenever the Future is ready to emit something, it can invoke the promise with a value or with an error. Only the first thing passed to the promise matters, everything else is ignored.

```
let testFuture = Future<Int, CustomError> { promise in
    promise(.success(1))
//            promise(.failure(CustomError.generic))
}

let cancellable = testFuture.sink(receiveCompletion: { print($0) }, receiveValue: { print($0)} )
```

`Just` is a publisher that emits an output to each subscriber just once, and then finishes. It can't produce an error.

```
let testJust = Just(2)
let cancellable2 = testJust.sink(receiveCompletion: { print($0) }, receiveValue: { print($0)} )
```

`Deferred` is a publisher that (unlike `Future`) awaits subscription before running the supplied closure to create a publisher for the new subscriber. Like `Future` otherwise, can produce one value or an error.

```
let testFuture = Future<Int, CustomError> { promise in
    print("Closure1")
    promise(.success(1))
}

let testDeferred = Deferred {
    Future<Int, CustomError> { promise in
      print("Closure4")
      promise(.success(4))
    }
}

--- Prints Closure1. So Closure1 is printed even if testFuture has no subscriber whereas Closure4 is not printed as testDeferred has no subscrriber yet.
```

`Empty` is a publisher that never publishes any values, and optionally finishes immediately.

`Fail` is a publisher that immediately terminates with the specified error.

`Record` is a publisher that allows for recording a series of inputs and a completion, for later playback to each subscriber.
> Understand `Record` better.

#### Subjects

`Subject` is a Publisher that exposes a method for outside callers to publish elements.

`send(subscription: Subscription)` - Required function, sends a subscription to the subscriber.

`send(completion: Subscribers.Completion<Self.Failure>)` - Required function, sends a subscription to the subscriber. Sends a completion signal to the subscriber.

`send(Self.Output)` - Sends a value to the subscriber.

`send()` - Available when Output is Void. Sends a void value to the subscriber.

`CurrentValueSubject` is a built-in class that is a Subject which wraps a single value and publishes a new element whenever the value changes.

`PassthroughSubject` is a built-in class that is a Subject which broadcasts elements to downstream subscribers. Unlike `CurrentValueSubject`, it doesn’t have an initial value or a buffer of the most recently-published element. It drops values if there are no subscribers, or its current demand is zero.

```
let currentValueSubject = CurrentValueSubject<Int, Never>(9)
currentValueSubject.send(10)
cancellable6a = currentValueSubject.sink(receiveValue: { print($0)} )
currentValueSubject.send(11)

let passthroughSubject = PassthroughSubject<Int, Never>()
passthroughSubject.send(99)
cancellable6b = passthroughSubject.sink(receiveValue: { print($0)} )
passthroughSubject.send(100)

---- Prints 10 11 100 (drops 99)
```

> Its probbaly not possible to take a `Publisher` and somehow typecast/change it to a `Subject` and start publishing elements using the Subject.
