###### Capture image method -

Still image is captured using `AVCaptureStillImageOutput` object.

For actually capturing the image `captureStillImageAsynchronouslyFromConnection` should be called. It takes two arguments, the capture connection and a completion handler.

```
self.stillImageOutput.captureStillImageAsynchronouslyFromConnection(videoConnection) { (imageDataSampleBuffer, error) -> Void in
     dispatch_async(dispatch_get_main_queue()) {
          if let _ = imageDataSampleBuffer {
               let imageData = AVCaptureStillImageOutput.jpegStillImageNSDataRepresentation(imageDataSampleBuffer)
               let image = UIImage(data: imageData)!
               let portraitImage = UIImage(CGImage: image.CGImage!, scale: 1.0, orientation: UIImageOrientation.Right)
          }
          else {
               self.cameraButton.userInteractionEnabled = true
          }
     }
}
```

###### Output settings -

Before doing so, the `outputSettings` property can be used to specify some output settings.
```
stillImageOutput.outputSettings = [AVVideoCodecKey: AVVideoCodecJPEG]
```

On iOS the currently the only supported keys are `AVVideoCodecKey` and `kCVPixelBufferPixelFormatTypeKey`. The keys are mutually exclusive, only one may be present.` AVVideoCodecKey` relates to the compression settings of the output image.

A video codec is an electronic circuit or software that compresses or decompresses digital video. It converts raw (uncompressed) digital video to a compressed format or vice versa. In the context of video compression, "codec" is a concatenation of "encoder" and "decoder"—a device that only compresses is typically called an encoder, and one that only decompresses is a decoder.

Different devices support different image formats. You can find out what pixel and codec types are supported by a device using `availableImageDataCVPixelFormatTypes` and `availableImageDataCodecTypes` respectively. However on a 6s, `availableImageDataCodecTypes` just returned jpeg alone. 

Another codec is `AVVideoCodecH264`, but it is probably not supported by iOS.

Its as if the default outputSettings is `AVVideoCodecJPEG` codec.

With video captures, there is also something called pixel format and it has got something to do with the colors. On a 6S, there are 3 different pixel formats available.

###### Captured image as CMSampleBuffer -

In the completion handler, the captured image is made available as a `CMSampleBuffer` object. It is an implicitly unwrapped optional and should actually not be assumed to be not nil. It was nil for me sometimes when the incoming video feed was frozen on app reactivation.

The `CMSampleBuffer` object can contain metadata too (such as an EXIF dictionary). 

`EXIF` - Computer Definition. (EXchangeable Image Format) Descriptive data (meta-data) in an image file that include the date the photo was taken, resolution, shutter speed, focal length and other camera settings.
```
let exifAttachments = CMGetAttachment(imageDataSampleBuffer, "{Exif}" , nil)
```
