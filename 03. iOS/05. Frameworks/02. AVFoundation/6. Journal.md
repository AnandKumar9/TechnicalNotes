###### Making changes in a running session

If changes are needed a running session, then they need to be encapsulated in `beginConfiguration` and `commitConfiguration` methods. 
```
session.beginConfiguration()
.. Remove an existing capture device, add a new capture device, reset the preset, etc.
session.commitConfiguration()
```

> However when I tried changing the preset this way it worked but there was a wobble on the UI. And even if I change it directly, i.e. without using this begin/commit way the change still takes effect with the same wobble. Now [this](http://stackoverflow.com/a/19717593/1135417) link says to not even use begin/commit but use a different API.

##### Requesting camera access for the app

Access is requested using requestAccessForMediaType method of AVCaptureDevice and the user’s decision reported in a completion handler.
authorizationStatusForMediaType gives the currently allowed access when it is invoked. There are 4 different authorization values - Authorized, NotDetermined (when the user has not even been asked), Denied, Unknown

```
let cameraPermissionStatus = AVCaptureDevice.authorizationStatusForMediaType(AVMediaTypeVideo)
if cameraPermissionStatus == .Authorized {
     self.setUpCaptureDevice()
} else if cameraPermissionStatus == .NotDetermined {
     AVCaptureDevice.requestAccessForMediaType(AVMediaTypeVideo, completionHandler: { (granted) -> Void in
          dispatch_async(dispatch_get_main_queue()) {
               if granted {
                    self.setUpCaptureDevice()
            ¯   }
          }
     })
}
```
