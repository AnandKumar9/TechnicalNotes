###### captureSession

A preview layer is initialized with a capture session.

```
guard let previewLayer = AVCaptureVideoPreviewLayer(session: captureSession)
     else { return }
previewLayer.frame = CGRectMake(0, 0, previewView.frame.size.width, previewView.frame.size.height)
previewLayer.videoGravity = AVLayerVideoGravityResizeAspectFill
previewView.layer.addSublayer(previewLayer)
```

In general, the preview layer behaves like any other CALayer object in the render tree (see Core Animation Programming Guide). You can scale the image and perform transformations, rotations, and so on just as you would any layer.

###### videoGravity

A video input is always bringing the entire feed (which by default is 1.333?) captured by the camera. How all that gets rendered on the preview layer depends upon the videoGravity of the preview layer.

1. `AVLayerVideoGravityResize` - In this the entire feed is shown and it also fills the entire preview layer. Consequently, the feed may lose its shape. <br> <br>
2. `AVLayerVideoGravityResizeAspect` - The default. In this the input feed’s aspect ratio is maintained and fit within the preview layer. Consequently, the entire feed will be displayed while maintaining its shape but the entire preview layer may not be filled. <br> <br>
3. `AVLayerVideoGravityResizeAspectFill` - In this the input feed’s aspect ratio is maintained and filled within the preview layer. Consequently, the entire preview layer will have a feed displayed while maintaining the feed’s shape but the entire feed may not be displayed.


###### connection

The preview layer has a `connection` property for the capture connection it is tied to. The capture connection in turn has properties such as videoMirroring, videoConnection, etc. None of this affects the output (such as still image) though.

By default, `automaticallyAdjustsVideoMirroring` is true and in such a case where needed and possible mirroring is automatically done (but why should it be needed).
If this is explicitly set to false, then mirroring can be controlled. If mirroring is set to true, a mirror reflection kind of feed is shown in the preview layer. The captured image though is still the actual image and not mirrored.

```
if previewLayer.connection.supportsVideoMirroring == true {
    previewLayer.connection.automaticallyAdjustsVideoMirroring = false
    previewLayer.connection.videoMirrored = true
}
```

###### videoOrientation

`videoOrientation` property allows to decide with what orientation should the captured feed be displayed on a preview layer. The feed is always captured in orientation mode but it can be rendered differently if needed. 

```
if previewLayer.connection.supportsVideoOrientation == true {
     previewLayer.connection.videoOrientation = .LandscapeLeft // Portrait
}
```

The default is portrait.
