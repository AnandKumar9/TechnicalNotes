AVCaptureAudioFileOutput (Output to an audio file)
AVCaptureMovieFileOutput (Output to a movie file)

Saving movie files -

While capturing a movie file, various aspects can be configured. These include things such as maximum duration of recording, maximum file size, minimum free disk space left limit, etc.
Movie recording can be started using the method startRecordingToOutputFileURL:recordingDelegate:. The delegate should conform to AVCaptureFileOutputRecordingDelegate protocol and must implement  captureOutput:didFinishRecordingToOutputFileAtURL:fromConnections:error: method.  Metadata can be added to a movie file, even while recording. The metadata item is a AVMetadataItem or AVMutableMetadataItem object.
Capturing video frames -
AVCaptureVideoDataOutput object uses delegation to vend video frames. The delegate is specified using setSampleBufferDelegate:queue: and the queue passed must be a serial queue. The frames are presented in the delegate method, captureOutput:didOutputSampleBuffer:fromConnection:, as instances of the CMSampleBufferRef opaque type.
Also for performance considerations, the session output should be set to lowest practical resolution.

Capturing still images -

AVCaptureStillImageOutput is used for capturing still image along with accompanying metadata. Different devices support different image formats. You can find out what pixel and codec types are supported by a device using availableImageDataCVPixelFormatTypes and availableImageDataCodecTypes respectively.
The capturing is done using captureStillImageAsynchronouslyFromConnection:completionHandler: method.

Monitoring audio output -

AVCaptureAudioChannel is used to monitor the average and peak power levels in an audio channel in a capture connection. An AVCaptureConnection object from an input producing audio to an output receiving audio exposes an array of AVCaptureAudioChannel objects, one for each channel of audio available. AVCaptureAudioChannel instances should not be created directly. Also, it is not key value observable and must instead be checked regularly for monitoring to happen.

High frame rate video capture and playback -

iOS 7 onwards there is also high frame rate video capture support (known as SloMo video) on some devices. It requires very high frame rate content. The capabilities of the device can be checked using AVCaptureDeviceFormat class. It has methods that return the supported media types, frame rates, etc.

AVPlayer is a class used for implementing controllers and user interfaces for single or multiple item playback. It works with local as well as remote media files.

AVMutableComposition is used for creating new composition from existing assets. It can be sued to add and remove tracks, scale time range, etc.

AVAssetExportSession is used for coding the contents of an AVAsset source object to an output of the form described by a specified export preset. This is the class used for exporting 60 fps video.

AVCaptureMovieFileOutput is used to capture data to QuickTime movie. It can be used for recording and it automatically supports high frame rate recording.
