MSL is based on C++14. Most of the data types are represented in floats. There are data types for vectors and matrices.

float3 - A 3 dimensional vector represented in float
float4 - A 4 dimensional vector represented in float

floatNxM - A matrix with M rows and N columns represented in float, such as float4x4

Many functions are common to both MSL and GLSL, such as dot(), normalize().


Shaders tie into render command encoder (through the render pipeline state) which also already has the vertex buffer and the primitives drawing instructions fed to it. So its almost as if the shaders come into play in the end and have a final say on what get rendered (on top of the primitives included in the render command encoder).

setVertexBuffer(_ :offset:index:) method of MTLRenderCommandEncoder essentially sets a buffer for the shader in the argument table.
