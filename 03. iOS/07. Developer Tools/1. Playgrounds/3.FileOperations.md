###### Testing data persistence

Its possible to even test file read/write and hence some persistence at that level.

`playgroundSharedDataDirectory` returns a special directory where data can be persisted across app lunches and even shared across all Playgrounds.

It corresponds to the Finder location `~/Documents/Shared Playground Data/` and actually needs to be created manually before using. Xcode does not create it for your automatically.

```
mkdir ~/Documents/Shared\ Playground\ Data
playgroundSharedDataDirectory
```

And then it can be used for various file operations.

```
let fileURL = playgroundSharedDataDirectory.appendingPathComponent("FileA.txt")

do {
  try filterNamesString.write(to: fileURL, atomically: true, encoding: .utf8)
  ```
