There are various services in a device which the user can selectively enable or disable for an app (or in some cases for all apps at a device level). These services include things such as location, photos, music and other media assets, contacts, calendar, reminders, bluetooth peripherals, microphone and camera. There is separate api for each of them for checking if an app has access to them. For example, in case of bluetooth centrals it is state property of CBCentralManager.

The complete list is in ‘App Programming Guide for iOS’ -> ‘Supporting user privacy’ (pages 18-19).
