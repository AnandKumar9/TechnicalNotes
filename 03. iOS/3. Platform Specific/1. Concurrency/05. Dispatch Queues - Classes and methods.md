```
dispatch_queue_create (For creating a serial dispatch queue.)
dispatch_get_global_queue (For getting a global queue of specified priority level.)
dispatch_get_main_queue (For getting the dispatch queue associated with the application's main thread.)

dispatch_get_concurrent_queue (For getting any of the shared concurrent queues.)

dispatch_queue_set_specific (To set a key-value data for a dispatch queue.)

dispatch_suspend (For suspending a dispatch queue)
dispatch_resume (For resuming a dispatch queue)

dispatch_group_wait (For waiting until the tasks in the group's queue are completed)

dispatch_set_target_queue (For setting target queue of a dispatch queue)

Calling this function from inside a block object returns the queue to which the block was submitted, i.e. on which it is now likely running). Calling it from outside the block, returns the default concurrent queue of the application. 
```

With Swift a lot of this API changed (and became simpler). Here is the new API. Another thing to note is that all these functions anyway return the concerned queue as well.

```
dispatch_queue_create - DispatchQueue(label:, attr:)
dispatch_get_global_queue - DispatchQueue.global(qos:)
dispatch_get_main_queue - DispatchQueue.main

dispatch_set_target_queue - setTarget(queue:)
dispatch_barrier_async ~ async(group:qos:flags:execute:)
dispatch_barrier_sync ~ sync(flags:execute:)
```

Actually `dispatch_queue_create` can be used to create not just a private serial queue, but even a private concurrent queue. If its second argument is specified as `DISPATCH_QUEUE_SERIAL` or `NULL`, a serial queue is created. If however `DISPATCH_QUEUE_CONCURRENT` is specified, a concurrent queue is created.

#### Code Snippets

Getting a global concurrent dispatch queue - 
```
dispatch_queue_t queue = dispatch_get_global_queue(DISPATCH_QUEUE_PRIORITY_DEFAULT, 0);
```

Creating a serial dispatch queue -
```
dispatch_queue_t queue = dispatch_queue_create("com.example.MyQueue", NULL);
```

Putting a task asynchronously in a dispatch queue -
```
dispatch_async(queue, ^{//block});
```

Working with context information in dispatch queue -
```
dispatch_queue_t globalQueue = dispatch_get_global_queue(DISPATCH_QUEUE_PRIORITY_DEFAULT, 0);
static void *globalQueueKey = @"Global Queue key";
dispatch_queue_set_specific(globalQueue, globalQueueKey, (void *)globalQueueKey, NULL);
if (dispatch_get_specific(globalQueueKey)) { // .. In the task block
```

Working with dispatch_apply as a replacement for for loop -
```
dispatch_queue_t queue = dispatch_get_global_queue(DISPATCH_QUEUE_PRIORITY_DEFAULT, 0);
dispatch_apply(count, queue, ^(size_t i) {
    printf("%u\n",i);
});
```
