Binary data can be wrapped inside `Foundation` and `Core Foundation` data objects which provide object-oriented behaviors for manipulating the data.

(Probably buffers that represent data objects shouldn’t have any pointers embedded in them.)

The size of data that an instance of `NSData` or `NSMutableData` can wrap depends upon the platform. When the data size is more than a few memory pages, the object uses virtual memory management.

Data objects provide a OS-independent way and use something called copy-on-write technique which means that when data is copied through a virtual memory copy, an actual copy of the data is not made unless an attempt is made to modify it.

`NSData` as well as `NSMutableData` are actually class clusters.

Usually class methods such as `+dataWithBytes:length:` makes a copy of the original bytes and releasing the data object only frees up the copied bytes, not the original bytes.

With methods such as `+dataWithBytes:noCopy:`, bytes are not copied however and are freed when the data object is freed. In case of `NSMutableData` though, the bytes are copied anyway.

Using `dataWithBytesNoCopy:length:freeWhenDone:` with `freeWhenDone` passed as `NO` ensures that the bytes are not freed when the object is released.

The primitive methods of `NSData` are `bytes` and `length`. `bytes` method returns a pointer to the bytes contained in the data object. `length` method returns the number of bytes contained in the data object.

The primitive methods of `NSMutableData` are `mutableBytes` and `setLength:`. `setLength:` method allows to truncate or extend the length of a mutable data object.

Bytes or data can be appended to a `NSMutableData` instance using `-appendBytes:length:` or `-appendData:`

Also, a range of bytes in a `NSMutableData` instance can be replaced with zero or other bytes using `-resetBytesInRange:` or `replaceBytesInRange:withBytes:`.

###### NSData

```
+dataWithBytes:length:
+dataWithBytes:noCopy:
+dataWithBytesNoCopy:length:freeWhenDone:

+dataWithContentsOfFile:

-bytes
-length
-getBytes:length: (copies bytes into a buffer)
-getByts:range: (copies a range of bytes into a buffer)
-subdataWithRange:

-copy (creates a read-only copy)
-mutableCopy (creates a mutable copy)

-writeToFile:atomically:
-writeToURL:atomically:

-isEqualToData: (to check if two data objects are equal using byte-to-byte comparison)
```
