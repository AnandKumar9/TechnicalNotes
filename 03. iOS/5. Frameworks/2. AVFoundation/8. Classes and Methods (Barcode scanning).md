```
AVCaptureSession (Coordinates the flow of data from AV input devices to outputs)
AVCaptureVideoPreviewLayer (A subclass of CALayer used to display video as it is being captured by an input device)
AVCaptureDevice (Represents a physical capture device, i.e. the input device. Such as camera or microphone.)
AVCaptureDeviceInput (Represents an input data source for AVCaptureDevice)
AVCaptureMetadataOutput (Intercepts the metadata emitted by a capture connection and forwards it to the delegate)
AVCaptureConnection (Represents a connection between capture input and capture output objects associated with a capture session. Not needed much.)
```

```
AVCaptureDevice -> +defaultDeviceWithMediaType: (Returns the default device used to capture the passed media type)
AVCaptureDeviceInput -> +deviceInputWithDevice:error: (Returns an input initialized to use a specified device)
AVCaptureMetadataOutput -> -setMetadataObjectsDelegate:queue: (Sets the delegate and dispatch queue to handle output callbacks)
AVCaptureMetadataOutput -> metadataObjectTypes: (An array that specifies the types of metadata objects the output can process. Only the received output satisfying these types are forwarded to the delegate. The values in this array are AVMetadataObjectTypeCode128Code, AVMetadataObjectTypeQRCode, etc.)
AVCaptureMetadataOutput -> availableMetadataObjectTypes (An array identifying the types of metadata objects that can be captured. metadataObjectTypes elements must be one of these else an exception is thrown.)

AVCaptureSession -> -addInput: (Adds an input to a session)
AVCaptureSession -> -addOutput: (Adds an output metadata object to a session)
AVCaptureSession -> -startRunning (To start the capture process)
AVCaptureSession -> -stopRunning (To stop the capture process)

AVCaptureVideoPreviewLayer -> -initWithSession: (Initializes the preview layer with the passed AVCaptureSession object)
AVCaptureVideoPreviewLayer -> videoGravity (Indicates how the video is displayed within a player layer’s bounds rect. One possible value is AVLayerVideoGravityResizeAspectFill.)

CALayer -> -removeFromSuperlayer (Detaches the layer from its parent layer)

AVCaptureMetadataOutputObjectsDelegate -> -captureOutput:didOutputMetadataObjects:fromConnection: (Called when the capture output object emits new metadata objects. The AVCaptureOutput and AVCaptureConnection objects are also passed.)

AVLayerVideoGravityResizeAspectFill (The preview layer should preserve the video’s aspect ratio and fill the layer’s bounds)

UIView.layer -> -addSublayer: (To finally add the preview layer to the required view)
```
