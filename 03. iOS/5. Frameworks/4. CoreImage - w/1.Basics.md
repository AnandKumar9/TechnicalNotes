Filter, Context, CIImage, etc. -

A filter has a number of inputs and outputs and performs some kind of transformation. A filter graph is a network of filters chained together.

There are scores of system provided filters. However custom filters can also be created. Some of the system provided filters are CIColorDodgeBlendMode, CIGaussianBlur, CIPhotoEffectTonal, CIAdditionCompositing, etc. There is probably even a filter for cropping.

Everything happens with something called core image contexts (CIContext) and they should be created very frugally. Also the CIFilters need input image to be of a specific format, i.e. CIImage.

So these are the basic classes.
CIContext
CIImage

The usual steps for creating a filter and applying it to an image -

1. Create a CIFilter using init(name:).
2. Configure the filter using KVC.
3. Have the input image(s) as CIImage. Converting UIImage to CIImage is simple.
4. Set the input image to filter using KVC.
5. Create a CIContext using init(options:).
6. Get the filtered CGImage using createCGImage(_:from:) method of CIContext. (There are other methods too). This method is synchronous and takes time. It should not be run in the main thread.
7. Create a UIImage from the created output CGImage.
