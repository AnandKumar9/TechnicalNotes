Target -> Info, Build Settings, Build Phases, Build Rules. <br>
Builds a product based on settings, phases, etc. <br>

Scheme -> Defines a set of actions that can be performed on target. Different actions have different  things. Typical actions for a product scheme - Build, Run, Test, Profile, Analyze, Archive. <br>

Config -> Configuration options for building. Specified in a scheme's action. <br>
