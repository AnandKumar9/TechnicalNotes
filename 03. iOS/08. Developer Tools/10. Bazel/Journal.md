#### Installing Bazel using Homebrew

([Reference](https://bazel.build/install/os-x))

Need to have Xcode Command Line Tools installed too.

```
brew install bazel
bazel --version
brew upgrade bazel
```

#### Basics

`workspace` - A folder that contains the source files, and importantly also a `WORKSPACE` file and `BUILD` files. These files contain the instructions that Bazel uses. The workspace may also contain symbolic links to output directories. Every workspace must have the text file named `WORKSPACE`.

#### Basic iOS app

([Reference](https://github.com/bazelbuild/rules_apple/blob/master/doc/tutorials/ios-app.md#update-the-workspace-file))

##### Create workspace file

In case of products meant for [Apple platform](https://github.com/bazelbuild/rules_apple/blob/master/doc/tutorials/ios-app.md#update-the-workspace-file), Bazel pulls the [Apple build rules](https://github.com/bazelbuild/rules_apple) from Bazel's GH repo. For that to happen, that has to be specified in the `WORKSPACE` file.

```
load("@bazel_tools//tools/build_defs/repo:http.bzl", "http_archive")

http_archive(
    name = "build_bazel_rules_apple",
    sha256 = "34c41bfb59cdaea29ac2df5a2fa79e5add609c71bb303b2ebb10985f93fa20e7",
    url = "https://github.com/bazelbuild/rules_apple/releases/download/3.1.1/rules_apple.3.1.1.tar.gz",
)

load(
    "@build_bazel_rules_apple//apple:repositories.bzl",
    "apple_rules_dependencies",
)

apple_rules_dependencies()

load(
    "@build_bazel_rules_swift//swift:repositories.bzl",
    "swift_rules_dependencies",
)

swift_rules_dependencies()

load(
    "@build_bazel_rules_swift//swift:extras.bzl",
    "swift_rules_extra_dependencies",
)

swift_rules_extra_dependencies()

load(
    "@build_bazel_apple_support//lib:repositories.bzl",
    "apple_support_dependencies",
)

apple_support_dependencies()
```

##### Add source files

In a folder named Sources, add a Swift file that can be the entry point to the app (a simple SwiftUI file works too).

##### Create build file

Create `BUILD` file with these contents. It loads appropriate rules, and then has project specs in `xcodeproj` part. There are also `swift_library` and `ios_application` rules to configure those parts.

```
load(
    "@rules_xcodeproj//xcodeproj:defs.bzl",
    "top_level_target",
    "xcodeproj",
)

xcodeproj(
    name = "xcodeproj",
    build_mode = "bazel",
    project_name = "iOSApp",
    tags = ["manual"],
    top_level_targets = [
        ":iOSApp",
    ],
)

load("@build_bazel_rules_apple//apple:ios.bzl", "ios_application")
load("@build_bazel_rules_swift//swift:swift.bzl", "swift_library")

swift_library(
    name = "lib",
    srcs = glob(["Sources/*.swift"]),
)

ios_application(
    name = "iOSApp",
    bundle_id = "build.bazel.rules-apple-example",
    families = [
        "iphone",
        "ipad",
    ],
    infoplists = ["Resources/Info.plist"],
    minimum_os_version = "17.0",
    visibility = ["//visibility:public"],
    deps = [":lib"],
)
```

##### Build and run the app

```
bazel build //:iOSApp
bazel run //:iOSApp
```
