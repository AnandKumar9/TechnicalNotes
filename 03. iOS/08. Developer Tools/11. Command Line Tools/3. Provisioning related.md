##### Checking the entitlement keys in an ipa

> Sample code - verify-ipa-entitlements.sh

`security` can be used to extract the provisioning profile into a plist format. <br>`PlistBuddy` can be used to extract the entitlement keys from a plist

```shell
#Extract the provisioning profile as a plist file
TEMP_PLIST_FILE=$(mktemp "$UNZIPPED_IPA_DIR/ipa_plist_XXXX.plist")

security cms -D -i "$PROVISIONING_PROFILE" > "$TEMP_PLIST_FILE"

#Inspect the plist file, Save its entitlements in a multi-line string
EXISTING_ENTITLEMENTS_MULTI_LINE_STRING=$(/us/Libexec/PlistBuddy -c "Print :Entitlements" "$TEMP_PLIST_FILE" | \
    grep " = " \ |
    awk -F' = ' '{print $1}' | \
    sort)
```
