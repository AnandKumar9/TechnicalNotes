`xcrun` basically finds the specified Xcode command line tool in active developer directory and runs it. The active developer directory can be set using `xcode-select`, or via the `DEVELOPER_DIR` environment variable.

#### xcrun swift

`xcrun swift` is basically the REPL for Swift. It can run a Swift program. All the options can be found using `xcrun swift -help`. ([SO link](https://stackoverflow.com/a/57777235))

`xcrun swift -version` - Gives the exact Swift version (like `swift-driver version: 1.90.11.1 Apple Swift version 5.10`), and this probably corresponds to the latest Swift version of the default Xcode in the system.

#### xcrun swiftc

`xcrun swiftc` is basically the Swift compiler. It has various options that can be used to performa variety of Swift compiler related tasks. For example `xcrun swiftc -dump-ast` will print the AST (abstract syntax tree).

All the options can be found using `xcrun swiftc -help`.

#### xcrun simctl

`xcrun simctl` is the command line tool to control the Simulator. For example, `xcrun simctl list` returns a list of all the available simulators.
