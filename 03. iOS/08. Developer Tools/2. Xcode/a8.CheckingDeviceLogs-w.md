iOS Crash Logs -
When an iOS device is synced with a Mac, its crash logs are stored in below location.
/Users/<Username>/Library/Logs/CrashReporter/MobileDevice

The crash logs have the file extension .crash.

Device Console Logs -
They can be accessed using iPhone Configuration Utility.

Stackshot Logs -
They are stored in the same location in a Mac as crash logs.

Stackshots can be captured by pressing the home button and one of the volume buttons at the same time.
