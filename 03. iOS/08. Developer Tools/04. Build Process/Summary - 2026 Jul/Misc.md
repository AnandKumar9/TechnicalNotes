> Relevant Notes on theory of compiled vs interpreted languages - <br>01. Programming Languages/1. Theory/1. Code Execution (Compiled vs Interpreted).md
>
> Remember that compiled languages are already converted to machine code at the end of compilation. Object files too are in machine code after all, ts just that they get fully resolved only after the subsequent linking.
>
> That is why programming languages theory (and the note above) takes the liberty to mention that compilation produces machine code and doesn't then say (but should) that linking may be needed still.
