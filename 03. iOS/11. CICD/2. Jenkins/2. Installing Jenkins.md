##### Installing using Homebrew

Ensure Java is installed in Homebrew, Install Jenkins, Start Jenkins. That's it.

```
brew --version														---- CHECK IF HOMEBREW IS INSTALLED
brew install openjdk@21 ; java -version   ---- INSTALL JAVA, VERIFY

brew install jenkins-lts                  ---- INSTALL JENKINS
brew services start jenkins-lts           ---- START JENKINS, THEN ACCESSED AT http://localhost:8080 
```

Then in the website, install suggested plugins, and create admin user.

##### Misc.

There were some oddities that later happened while running, turns out that is because Homebrew installs them as something called **brew keg** which deliberately does not set up some symlinks to be sure. So those need to be set so that shell is able to find Jenkins.

```
sudo ln -sfn /opt/homebrew/opt/openjdk@21/libexec/openjdk.jdk \
  /Library/Java/JavaVirtualMachines/openjdk-21.jdk

echo 'export PATH="/opt/homebrew/opt/openjdk@21/bin:$PATH"' >> ~/.zshrc
echo 'export JAVA_HOME="/opt/homebrew/opt/openjdk@21"' >> ~/.zshrc
```
