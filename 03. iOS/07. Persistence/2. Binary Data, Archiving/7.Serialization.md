Serializations store a simple hierarchy of value objects, i.e. dictionaries, arrays, strings and binary data. They do not maintain the mutability of objects and also have some limitations such as multiple references to the same value object might result in multiple objects when deserialized. plist is an example of something fit for serialization. Hence, in comparison coding (i.e. archiving) is generally the preferred persistence mechanism. Its only benefit is that it is very quick.

`NSPropertyListSerialization` class provides methods to convert plist objects between an xml and an optimized binary data format. The generated binary data probably needs to be written to the file system using other `NSFileManager` methods.

###### Classes and Methods
```
NSPropertyListSerialization

+dataFromPropertyList:format:errorDescription: (creates data from passed dictionary)
+propertyListFromData:mutabilityOption:format:errorDescription: (creates dictionary from passed data)

NSPropertyListImmutable
NSPropertyListXMLFormat_v1_0
```

###### Code snippets

```
// Serialization
NSDictionary *propertyList= @{ @"FirstNameKey" : @"Edmund",
                               @"LastNameKey" : @"Blackadder" };

NSData *dataRep = [NSPropertyListSerialization dataFromPropertyList:propertyList
                format:NSPropertyListXMLFormat_v1_0
                errorDescription:&errorStr];


// Retrieval
NSDictionary *propertyList = [NSPropertyListSerialization propertyListFromData:dataRep mutabilityOption:NSPropertyListImmutable format:NULL errorDescription:&errorStr];
```
