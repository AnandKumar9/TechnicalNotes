##### Animations can be done at 'layer' or at 'view' level

The first thing to keep in mind is that animation can be done on the layer as well as the view (of course the methods to be used for both are different). What animation means is that the layer’s/view’s concerned properties animate. Of course, not every property of CALayer or UIView are animatable, but several are.

Animating at layer level is typically done using **CAAnimation** objects (i.e. CoreAnimation objects) and using methods such as `addAnimation(_:forKey:)`.

Animating at UIView level is done using **UIView class methods** such as `animate(withDuration:animations:)` which are block based. Prior to iOS4 these block based methods were not available and animations were done using methods such as `beginAnimations:context:`. These old methods are still available, but some of them are buggy and not recommended. In general, the block based methods should be used for animations at UIView level.
