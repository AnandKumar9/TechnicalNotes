#### CAAnimationGroup

**CAAnimationGroup** can be used to combine several animation together and add them to a layer as a single entity. The animations to be added are specified in the **animations** property and the duration is specified in **duration** property.

The duration of the grouped animations are are clipped to the duration of the animation group. For example, a 10 second animation grouped within an animation group with a duration of 5 seconds will only display the first 5 seconds of the animation.

All animations can be be put in an animation group, i.e. basic, keyframe or even spring animation.

```swift
let animationGroup = CAAnimationGroup()
animationGroup.animations = [animation1, animation2, animation3]
animationGroup.duration = 3
self.l1.addAnimation(animationGroup, forKey: "Animation Group 1")
```

Model layer tree

CALayer - presentationLayer, modelLayer

#### CoreAnimation delegate methods

The core animations also have a delegate which has some callback methods. Technically a core animation object's delegate methods are a part of a NSObject protocol extension.

**animationDidStop(_:finished:)** is one of CoreAnimation delegate methods.  It is called when the CAAnimation is completed or is removed from the object it was attached to.

#### Misc.

In standalone layers (i.e. ones not backed by a UIView), when an animatable layer property is changed the system itself does a brief animation. However, in case of layer backing a view this does not happen and straight away the change is made. This is because the UIView class disables layer animations by default but reenables them inside animation blocks (and probably also in CAAnimation objects added to the layers).
