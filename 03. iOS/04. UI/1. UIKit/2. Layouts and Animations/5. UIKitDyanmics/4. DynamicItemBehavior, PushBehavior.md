#### Dynamic item behavior

A dynamic item behavior seems to be something rather unique in the sense that it allows to configure some particular physical properties of dynamic items (i.e. the things to which a behavior is attached, such as UIView). It has properties for things such as elasticity, allowsRotation, angularVelocity, etc. and a default value as well for all of them.
elasticity implies how much the item bounces when colliding with something else. A value of 1.0 implies it bounces a lot.

Setting anchored as true means the item will just not move, not even from any other behavior.
Charge determines the degree to which the item interacts with electric and magnetic fields. The default is 0.0. It matters in UIFieldBehavior.

One notable and common use of a dynamic item behavior is to confer a velocity to a dynamic item to match the ending velocity of a user gesture. (What does this statement imply, need to try.)

#### Push behavior

A push behavior applies a force in the specified direction.

This push can either be continuous or instantaneous (i.e. just a one time push and not always present) and can be configured using mode property. With continuous mode a force is always being applied and hence the velocity of the dynamic items keeps increasing (i.e. they accelerate). With instantaneous mode the force is applied only once and the velocity remains the same (i.e. the items do not accelerate).
mode : UIPushBehaviorModeContinuous, UIPushBehaviorModeInstantaneous

The force is specified in terms of magnitude and radian angle (or pushDirection i.e x and y values).

The default magnitude of a push behavior’s force vector is nil, equivalent to no force. A continuous force vector with a magnitude of 1.0, applied to a 100 point x 100 point view whose density value is 1.0, results in view acceleration of 100 points / second² in the direction of the vector. This value is also known as the UIKit Newton.

For each dynamic item that is associated with the push, the force is applied at the item center or at a specified offset from the center in item-relative coordinates. For applying the force at an offset, 
setTargetOffsetFromCenter(_:forItem:) method is used.

After enabling a push behavior, it can also be activated or deactivated using the active property.

In both gravity behavior and continuous push behavior the items are always under a force and accelerate. However the difference probably is that, with gravity behavior the acceleration is constant and the item’s mass etc do not matter (as in Physics) whereas with push behavior it matters and an item with more mass moves less quicker than an element with more mass.

Once an instantaneous push has dissipated it can be exercised again just by setting active property to YES. It probably turns to NO automatically once the instantaneous push has been applied.
