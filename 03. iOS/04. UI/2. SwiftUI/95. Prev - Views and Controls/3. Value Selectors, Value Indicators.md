### Slider

```
struct Slider<Label, ValueLabel> where Label : View, ValueLabel : View
```

There are two associated types, `Label` and `ValueLabel`. `Label` is supposed to show a description view but its [buggy](https://stackoverflow.com/questions/64820326/swiftui-sliders-label-visibility) and doesn't always show up inspite of being specified. ValueLabel views can be specified to provide views for min and max values.

Slider with `onEditingChanged` closure | Slider with step, minimumValueLabel, maximumValueLabel
--- | ---
![](assets/Misc-b05d4b32.png) | ![](assets/Misc-570e17fb.png)

`onEditingChanged` closure is called when user starts and ends sliding. Step can also be used to specify fixed quantumns of changes.

It has a bunch of initializers, all of which basically provide some combinations of its various allowed labels, step, and closures.

### Label

It shows an icon and a text together (well actually as per specs below, any two views).

```
struct Label<Title, Icon> where Title : View, Icon : View
```

![](assets/Misc-46d11d43.png)

Creating a Label from Text and an Image | Creating a Label from a Configuration
--- | ---
![](assets/Misc-6b3db2f9.png) | ![](assets/Misc-a60b1418.png)

Its possible to show just the icon, or just the text, or specify that both always be shown.
```
Label("Lightning", systemImage: "bolt.fill")
    .labelStyle(TitleOnlyLabelStyle())
```

### ProgressView

Its a View that can show the progress of a task. It looks like a Slider but is not, the thumb can be slid by the user.

```
struct ProgressView<Label, CurrentValueLabel> where Label : View, CurrentValueLabel : View
```

![](assets/Misc-b0a6cdef.png)

In fact it can even be used to show a simple activity indicator by initializing it without a current value, i.e. simply as `ProgressView()`.
