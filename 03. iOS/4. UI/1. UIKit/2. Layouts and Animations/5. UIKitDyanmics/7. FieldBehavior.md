A field behavior applies Physics related fields to dynamic items. It define an area where the field must be applied and other necessary field attributes such as magnitude. There is also a position property which probably tells the point from where the field emanates.

There are several different kinds of field behaviors.
dragField, springField, velocityField, electricField, magneticField, radialGravityField, linearGravityField, vortexField, noiseField, turbulenceField

A radial gravity seems to be something that keeps pulling a dynamic item towards a specified point. Once the dynamic item reaches that point, it goes past as it has some velocity but then its pulled back again and keeps on oscillating this way overtime losing some of the speed and eventually resting at that point.

```
let radialGravity: UIFieldBehavior = UIFieldBehavior.radialGravityFieldWithPosition(self.center)
radialGravity.region = UIRegion(radius: 300.0)
radialGravity.strength = 1.5
radialGravity.falloff = 4.0
radialGravity.minimumRadius = 50.0
```

A vortex field causes the dynamic item to rotate in a circle around the center point of the field. Items entering the field are pushed perpendicular to the imaginary line between the item and the center of the field. This field combined with a radial gravity field causes the items to be pulled into a spinning vortex. (Need to see these happening, i.e. a vortex field causing an item to move in a circle and also how combining it with radial gravity field actually causes a spinning circle.)

```
let vortex: UIFieldBehavior = UIFieldBehavior.vortexField()
vortex.position = self.center
vortex.region = UIRegion(radius: 300.0)
vortex.strength = 0.005
```

The minimumRadius property (CGFloat) indicates the minimum distance at which to start calculating new values for the field.

The falloff property (CGFloat) indicates how quickly the field strength diminishes as the distance from the field’s center increases.
Its also possible to create a custom field behavior (i.e. not to use any of the pre-canned methods which give magnetic, electric, etc. fields). It needs to be initialized with a field evaluation block that takes as input position, velocity, mass, charge and time and then returns a force (the return type is CGVector but how can that represent a force as CGVector has only got components for direction and not for magnitude.). The system then calls this method using several sample input values to get the field details. This method should return quickly.

```
fieldWithEvaluationBlock(_ block: (UIFieldBehavior,
                                   CGPoint,
                                   CGVector,
                                   CGFloat,
                                   CGFloat,
                                   NSTimeInterval) -> CGVector) -> Self
````
