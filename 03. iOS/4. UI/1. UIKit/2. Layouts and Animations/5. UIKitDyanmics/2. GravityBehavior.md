A UIGravityBehavior object applies a gravity-like force to all of its associated dynamic items. The magnitude and direction of the gravity force are configurable and are applied equally to all associated items. In layman terms, gravity behavior makes a view move in straight lines. The magnitude property indicates how strong the pull is and properties such as gravityDirection or angle specify in which direction the pull is.

#### direction and magnitude -

gravityDirection is represented as a CGVector and angle is represented in radians (i.e. CGFloat). Both these properties are of course related and changing one automatically updates the other. The default gravityDirection is downwards, i.e. dx = 0 and dy = 1.0. (Also just for reference, Degree = Radian*180/3.14)

magnitude is represented as CGFloat. A value of 1.0 for magnitude imparts the standard UIKit gravity, which corresponds to an acceleration of 1000 points / second² in the direction of the given axis. Higher magnitude makes the dynamic item go faster.

Interestingly even direction and magnitude are related and changing one automatically creates a value for another (if it did not have any). However, the other property can then be explicitly configured. For example, changing gravityDirection sets a magnitude as well. But the magnitude can then be explicitly set as well and it does not change the already set gravityDirection.
setAngle:magnitude: is the method that can be used to set a gravity direction and magnitude at the same time.

Some samples on how direction affects magnitude -

```
Direction dx: 0.5, dy: -1.00     Magnitude 1.118
Direction dx: -0.5, dy: 1.0      Magnitude 1.118
Direction dx: -0.5, dy: -1.0     Magnitude 1.118
Direction dx: 5.0, dy: 0         Magnitude 5.0
Direction dx: 55.0, dy: 0        Magnitude 55.0
Direction dx: 0, dy: 1.0         Magnitude 1.0
Direction dx: 0.1, dy: 1.0       Magnitude 1.004
Direction dx: 0.5, dy: 1.0       Magnitude 1.118
Direction dx: 0.9, dy: 1.0       Magnitude 1.345
Direction dx: 5.0, dy: 1.0       Magnitude 5.099
Direction dx: 55.0, dy: 1.0      Magnitude 55.09
```

Its not very clear. If the direction is vertical, the magnitude is 1. And then if any horizontal component comes in, it only increases. And the magnitude remains same no matter which direction the vector eventually points to. 

Its as if a certain vertical acceleration (upwards or downwards) should always be maintained and the more horizontal component is there in the vector, the more force obviously needs to be exerted. Hence magnitude increases with horizontal component.

Code snippets -
```
self.dynamicAnimator = UIDynamicAnimator(referenceView: self.view)
self.gravityBehavior = UIGravityBehavior(items: [self.view1])
self.gravityBehavior.gravityDirection = CGVector(dx: 5.0, dy: 1.0)
self.dynamicAnimator.addBehavior(self.gravityBehavior)
```
