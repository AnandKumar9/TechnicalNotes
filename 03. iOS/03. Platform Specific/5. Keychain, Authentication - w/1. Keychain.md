Keychain is a central place where all apps have some space for themselves. Keychain access can also be shared across apps, typically same company apps.

iOS keychain is only UTF8 compliant. Hence, it is better to perform a UTF8 encoding on the strings to be stored in them as that eliminates the chance of any threat from unallowed special characters.

A keychain is an encrypted container that holds passwords for multiple applications and secure services.
In iOS each application always has access to its own keychain items, the user (actually the application code) is never asked to unlock the keychain. However, in OS X the keychain is locked and the user needs to unlock the keychain by entering a single master password. Also, in iOS an application can only access its own keychain item whereas in OS X any application can access any keychain item provided the user gives permission.

In addition to passwords, keychains can also store cryptographic keys and certificates (in Mac OS that is?).

The keychain services API provides all functions to manipulate keychain items in iOS.

Each keychain item contains data and a set of associated attributes. The attributes associated with the the keychain item depends upon the type of the item. The protected items (such as passwords) are encrypted.

iOS generates its own password for keychain and stores the key on the device in such a way that it is not accessible to any application. When a user backs up iPhone data, the keychain data is backed up but the secrets in the keychain items remain encrypted and also the keychain password is not included in the backup.

secItemAdd(CFDictionaryRef attributes, CFTypeRef *resull t) - Adds one or more items to the keychain. The first argument is a dictionary which has key value pairs to specify the keychain item type as well as values of various attributes. This dictionary is probably what is called as 'search dictionary'in Keychain parlance and is used throughout the API.

Typically a search dictionary contains keys for these - item class (kSecClass), attributes (kSecAttrAccount, kSecAttrService, ..), search attributes (kSecMatchInsensitive, ..), return type (kSecReturnData, ..).

Following are the common functions of iOS Keychain API -
SecItemAdd - Adds an item to keychain.
SecItemUpdate - Modifies an existing item in keychain.
SecItemCopying - Finds a keychain item and extracts information from it.
