WebNFC is basically browsers having access to device's NFC and being programmable using JS interfaces. Chrome allows it on Android devices.  Wayne's article ([link](https://www.capitalone.com/tech/software-engineering/web-nfc-for-authentication-android/))

> Web NFC extends the capabilities of NFC to the web. Web NFC is available on browsers built on Google’s open-source Chromium project. The Web NFC API can be invoked via JavaScript and allows the reading and writing of NDEF tags to/from nearby NFC devices.

As of 2024, WebNFC  is not available on iOS devices.
