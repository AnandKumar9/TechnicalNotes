##### timer

Creates an observable that emits events at regular intervals with the value being the event number (beginning from 0). The first event can also be made to emitt after a specified initial wait time.

```
static func timer(_ dueTime: RxTimeInterval, period: RxTimeInterval? = nil, scheduler: SchedulerType) -> Observable<Int>
```

```
let sequence1 = Observable<Int>.timer(DispatchTimeInterval.seconds(Int(1.0)), period: DispatchTimeInterval.seconds(Int(2.0)), scheduler: MainScheduler.instance)
```
