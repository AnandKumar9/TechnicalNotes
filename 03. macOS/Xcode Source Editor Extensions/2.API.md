###### XCSourceEditorExtension

An extension conforms to `XCSourceEditorExtension` protocol. <br>

`extensionDidFinishLaunching` is the function called when any command in the extension gets invoked for the first time.

Xcode asks the extension for its commands, and its commands can come from either of these sources. <br>
1. The commands listed in `NSExtensionAttributes` dictionary in the extension's info.plist.
2. The commands provided by `commandDefinitions` property of the extension class. If implemented, this overrides the commands listed in the Info.plist key.
> So probably `commandDefinitions` can be used to decide what extension commands to enable for a project. But then again this cannot be used to dynamically decide whether a extension command should be enabled for a certain kind of file, etc.

```
optional func extensionDidFinishLaunching()
optional var commandDefinitions: [[XCSourceEditorCommandDefinitionKey : Any]] { get }
```

###### XCSourceEditorCommand, XCSourceEditorCommandInvocation

Every command is a class that conforms to `XCSourceEditorCommand` protocol.

`perform(with:completionHandler:)` - The function that gets called every time the command is run, and this is the single where all the code gets in.

```
func perform(with invocation: XCSourceEditorCommandInvocation, completionHandler: @escaping (Error?) -> Void) {
```

`cancellationHandler` - The closure property that gets called to indicate the invocation has been cancelled by the user. This must be dealt with (how?).

`XCSourceEditorCommandInvocation` packages up all of the data and metadata that command needs to do its work. It gives access to the current source file as well as any selections in it. <br>
The completion handler needs to be called once the command has done its work.

###### XCSourceTextBuffer

The content of the source code can be accessed by the `buffer` property. Its of type `XCSourceTextBuffer` and has these properties.

`contentUTI` - Can tell the type of the text, i.e. swift, xml, .h , etc.

`completeBuffer` - Represents the entire text as a single stream. This is useful if there is a need to process the entire text as a single stream, say by piping it to a command line tool. So this pretty much gives the entire file as a single string.

`lines` - Repressents each line using a `NSMutableArray` property. Far better for small tweaks in isolated lines. Every element can be casted as a String.

`selections` - Represents the existing selectons using a `NSMutableArray` property. There is always at least one element in it, which is the interaction point. Keep in mind that there can be multiple simultaneous selections (Xcode allows it). Every element is a `XCSourceTextRange` (verify this).

###### XCSourceTextRange and XCSourceTextPosition

`XCSourceTextRange` is a half-open range and represents a selection.

`XCSourceTextPosition` reprsents a zero-based position, defined by a line number and a column number.

#### Misc.

###### Text is locked for user while command runs

In order to prevent any race conditions between the extension and the user, Xcode
actually locks out changes to the document that the user is working with when they invoke an extension.

###### Use can cancel if command takes too long

If the extension command is taking too long, Xcode shows a cancellation banner to the user and gives them an option to cancel the command. If user opts to cancel the command, Xcode cancels it and informs the command by calling the command invocation's  `cancellationHandler` property. The command should handle the cancellation itself as well, as until then it will not be available again.
