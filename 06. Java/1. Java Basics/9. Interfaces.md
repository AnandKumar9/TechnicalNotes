##### What is an Interface

`Interface` is like protocols in Objective-C and Swift. It then needs to be adopted by a class if it specified that using `implements`. A class can implement multiple interfaces.

```
interface PolygonCompliance {
    double area();
}

class Rectangle extends Polygon implements PolygonCompliance {
  ...
  public double area() {
    return this.height * this.width;
}
```

Interface is a reference type, and a full-fledged type of its own. It can contain only constants, method signatures, default methods, static methods, and nested types. It cannot be instantiated, it can only be implemented by classes or extended by other interfaces.

The interface body can contain abstract methods, default methods, and static methods.  
An abstract method is just a term for the most common thing in an interface, i.e. a method that is declared without an implementation. Default methods are defined with the `default` modifier, and static methods with the `static` keyword.

All abstract, default, and static methods in an interface are implicitly `public`.

Interfaces can also contain constant declarations. All constant values defined in an interface are implicitly `public`, `static`, and `final`. Hence these modifiers can be omitted.

###### Extending Interfaces

An interface can extend other interfaces, just as a class subclass or extend another class. However, whereas a class can extend only one other class, an interface can extend any number of interfaces.

```
public interface GroupedInterface extends Interface1, Interface2, Interface3 {
```

###### Adding methods to an existing Interface

For adding additional methods to an interface, there are several options.

There can  be a new interface that `extends` another interface.
```
public interface DoItPlus extends DoIt {
   boolean didItWork(int i, double x, String s);
}
```

Or the new methods can be defined as default methods using the `default` keyword.
```
public interface DoIt {
   void doSomething(int i, double x);
   default boolean didItWork(int i, double x, String s) {
       // Method body
   }

}
```

When an interface having a default method is extended, the following can be done.
1. The default method is not mentioned at all, which allows the extended interface to inherit the default method.

2. The default method can be redeclared, which makes it abstract.

3. The default method can be redefined, which overrides it.

A static method too can be implemented. It too is public by default.

###### Functional Interface

A functional interface is any interface that contains only one abstract method.
An abstract method is a method that is declared without an implementation (without braces, and followed by a semicolon).
```
abstract void moveTo(double deltaX, double deltaY);
```
