Length of an array is fixed at the time of creation.

Declaring an array is done like this. The brackets can even be placed after the array name.
```
type[] arrayName;
type arrayName[];
```

Array can be created using `new`.

```
int[] array1;
array1 = new int[2];
array1[0] = 5;
array1[1] = 2;
```

And also using the 'shortcut syntax', which also populates the array.
```
int[] array2 = {
  6, 9
};
```

Multi-dimensional arrays too can be specified. Interestingly though, rows (or a dimension for that matter) are allowed to have different lengths.
```
int[][] array3 = {
        {1, 2, 6},
        {3, 4}
};
```

`.length` gives the length of an array.
```
System.out.println(array1.length);
System.out.println(array3[0].length);
```

`arraycopy()` is an efficient way to copy data from one array to another.

Here arr1 is the source and arr2 is the destination array. 2nd index specifies source array's starting index and 4th index specifies destination array's index to which the elements should be copied. Number of elements to be copied are specified in the last index.
```
System.arraycopy(arr1, 2, arr2, 0, 7);
```

Common array manipulation methods are in `java.utils.Arrays` class.
