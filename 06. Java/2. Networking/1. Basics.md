##### Basic Concepts

`TCP` - `Transmission Control Protocol`. A transport layer communication protocol used for guranteed delivery and order of data.

`UDP` - `User Datagram Protocol`. A  transport layer communication protocol used when the delivery and order of transmitted data need not be guranteed (and hence retriable). Is consequently also faster than TCP.

Both TCP and UDP use ports to map incoming data to a particular parocess that is running on the system. ports 0-1023 are restricted for HTTP, FTP, etc. and should not be used by normal applications.

`Socket` means different things in programming and networking. In programming it usually implies just the combination of `IP Address + port` (i.e. one endpoint) on a system.  Whereas in networking, it means a connection between a pair of endpooints (i.e IP address + port).
