### Object references and copying

Primitive values are always copied by value, whereas Objects are copied by reference. Hence if an object is assigned to another variable and that variable then modifies a property, its refelected while accessing the initial object too.

#### Equality of objects

Two objects are equal only if they are the same object.
```
let a = {};
let b = a;

alert( a == b ); // true
alert( a === b ); // true
```

```
let a = {};
let b = {}; // two independent objects

alert( a == b ); // false
```

#### Creating an object's true copy

Every property needs to be copied over individually.

```
let clone = {};

for (let key in user) {
  clone[key] = user[key];
}
```

`Object.assign()` function can be used too.

```
Object.assign(dest, [src1, src2, src3...])
```

The first argument `dest` is a target object, and further arguments `src1`, ..., `srcN` are source objects. It copies the properties of all source object into destination object and returns the destination object.

```
let user = { name: "John" };
let permissions1 = { canView: true };
let permissions2 = { canEdit: true };

Object.assign(user, permissions1, permissions2);
```

If the copied property name already exists, it gets overwritten.

>If an object's property is an object itself, either recursion needs to be done or [_.cloneDeep(obj)](https://lodash.com/docs#cloneDeep) from the JavScript library `lodash` can be used.

> An important side effect of storing objects as references is that an object declared as const can have its properties modified.

### Garbage Collection

`Reachable` values are those that are accessible or usable somehow. They are guaranteed to be still stored in memory.

There’s a base set of inherently reachable values (such as  currently executing function, its local variables and parameters, global variables), that cannot be deleted. These values are called `roots`. Any other value is considered reachable if it’s reachable from a root by a reference or by a chain of references.

There’s a background process in the JavaScript engine called `garbage collector` which monitors all objects and removes those that have become unreachable.

The basic garbage collection algorithm is called `mark-and-sweep`.
