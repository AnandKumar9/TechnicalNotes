#### Map

`Map` is a collection of keyed data items, just like an `Object` but `Map` allows keys to be of any type.

```
let map = new Map();

map.set('1', 'str1');   // a string key
map.set(1, 'num1');     // a numeric key

alert( map.get(1)   ); // 'num1'
alert( map.size ); // 3
```

Map can also use objects as keys. To test keys for equivalence, Map uses the algorithm SameValueZero. It is roughly the same as strict equality `===`, but the difference is that `NaN` is considered equal to `NaN`. So NaN can be used as the key as well.

Every `map.set` call returns the map itself.

`map.keys()` – Returns an iterable for keys. <br>
`map.values()` – Returns an iterable for values. <br>
`map.entries()` – Returns an iterable for entries `[key, value]`, it’s used by default in `for..of.`. <br>

The iteration goes in the same order as the values were inserted. `Map` preserves this order, unlike a regular `Object`.

`Map` also has a built-in `forEach` method, similar to `Array`.
```
// Runs the function for each (key, value) pair
recipeMap.forEach( (value, key, map) => {
  alert(`${key}: ${value}`); // cucumber: 500 etc
});
```

`Object.entries` returns the array of key/value pairs and can also be used to initialize a Map.
```
let obj = {
  name: "John",
  age: 30
};

let map = new Map(Object.entries(obj));
```

`Object.fromEntries` does the reverse: given an array of [key, value] pairs, it creates an object from them.
```
let prices = Object.fromEntries([
  ['banana', 1],
  ['orange', 2],
  ['meat', 4]
]);

alert(prices.orange); // 2
```

#### Set

```
new Set(iterable)
set.add(value)
set.delete(value)
set.has(value)
set.clear()
set.size

set.keys() - Returns an iterable object for values
set.values() - Same as set.keys(), for compatibility with Map
set.entries() - Returns an iterable object for entries `[value, value]`, for compatibility with Map.
```

```
let set = new Set();

set.add(john);
set.add(pete);

alert( set.size );

for (let user of set) {
  alert(user.name);
}
```
