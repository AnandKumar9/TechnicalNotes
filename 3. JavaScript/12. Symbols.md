### Symbol

`Symbol` is a way to get a unique identifier. It can be given a description, but that doesn't mean that symbols with same description have same values, the values are still unique. It is considered a primitive type.

```
let id = Symbol();

let id1 = Symbol("id");
let id2 = Symbol("id");

alert(id1 == id2); // false
```

Symbols also don’t auto-convert to a string. A `.toString()` or `.description()` has to be called on it.

##### Hidden properties

Symbols give a way to create hidden properties of an object, that no other part of code can accidentally access or overwrite.

```
let user = { // belongs to another code
  name: "John"
};

let id = Symbol("id");
user[id] = 1;
```

##### Symbol in an object literal

If a symbol is used in an object literal (`{...}`), square brackets are needed around it.
```
let id = Symbol("id");

let user = {
  name: "John",
  [id]: 123 // not "id": 123
};
```

##### Skipped in iteration and `keys`, but not in `assign`

Also, any Symbol property is skipped in a `for … in` iteration of an object. They are even not there in `.keys()`.

However, `Object.assign` copies both string and symbol properties.

##### Global symbols

There is a ` Global Symbol Registry` thate exists which guarantees that repeated accesses by the same name return exactly the same symbol. In order to read (or create if none) a symbol from the registry, `Symbol.for(key)` is used.

```
// read from the global registry
let id = Symbol.for("id"); // if the symbol did not exist, it is created

// read it again (maybe from another part of the code)
let idAgain = Symbol.for("id");

// the same symbol
alert( id === idAgain ); // true
```

##### Symbol.keyFor

For global symbols, `Symbol.for(key)` returns a symbol by name, and then there’s also a reverse call `Symbol.keyFor(sym)` to get a symbol using the identifier.

##### System symbols

There are many `System symbols` that JavaScript uses internally, which can also be used to fine-tune various aspects of custom objects.

```
Symbol.hasInstance
Symbol.isConcatSpreadable
Symbol.iterator
Symbol.toPrimitive
....
```

A more comprehensive table is available [here](https://tc39.es/ecma262/#sec-well-known-symbols).
