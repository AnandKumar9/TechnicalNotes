#### if-else

```
if (year >= 2015) {
  alert( "That's correct!" );
  alert( "You're so smart!" );
} else {
  alert( "Something else" );
} else {
  alert( 'Exactly!' );
}
```

#### Conditional operator `?`

```
let accessAllowed = (age > 18) ? true : false;
```

The parenthesis is not mandatorily required, but is usually recommended for readability.

Many `?` can also be chained together, and its actually not that complicated. If left most condition fails, it goes to the next condition, and so on.

```
let age = prompt('age?', 18);

let message = (age < 3) ? 'Hi, baby!' :
  (age < 18) ? 'Hello!' :
  (age < 100) ? 'Greetings!' :
  'Hi!';
```

Its also possible to use `?` for statements instead of assignments, but is not recommended.
```
(company == 'Netscape') ? alert('Right!') : alert('Wrong.');
```

#### Nullish coalescing operator `??`

Just like Swift's nil coalescing operator. `a ?? b` means if a is defined use that, else use b. 'Defined' means anything that is not `null` or `undefined`.

Due to safety reasons, JavaScript forbids using ?? together with && and || operators, unless the precedence is explicitly specified with parentheses.

```
let x = 1 && 2 ?? 3; // Syntax error
let x = (1 && 2) ?? 3; // Works
````

`??` has a very low precedence, only a bit higher than `?` and `=`, its hence better to add parentheses when using it in an expression.

#### while loop

```
let i = 0;
while (i < 3) { // shows 0, then 1, then 2
  alert( i );
  i++;
}
```

#### do...while loop

```
let i = 0;
do {
  alert( i );
  i++;
} while (i < 3);
```

#### for loop

```
for (let i = 0; i < 3; i++) { // shows 0, then 1, then 2
  alert(i);
}
```

Inline declaration of the counter variable is allowed too.
```
for (let i = 0; i < 3; i++) {
```

Any part of `for` (i.e. begin, step, condition) can be skipped.
```
for (; i < 3; i++) { // no need for 'begin'
for (; i < 3;) { // no 'step'
for (;;) { // everything skipped
```

#### break and continue

`break` and `continue` do just what is expected of them. Labels are supported for break and continue. A label is an identifier with a colon before a loop.

```
labelName: for (...) {
```

```
outer: for (let i = 0; i < 3; i++) {
  for (let j = 0; j < 3; j++) {
    if (!input) break outer; // (*)..
  }
}
```

#### switch

```
switch (a) {
  case 4:
    ...
    break;
  case 5:
    ...
  default:
    ...
}
```

If there is no `break` then the execution continues with the next case without any checks.

Both switch and case allow arbitrary expressions.
```
switch (+a) {
```

Cases can be grouped together.
```
  case 4:
  case 5:
    ...
```

The equality check is always strict. The values must be of the same type to match.
