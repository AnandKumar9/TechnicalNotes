Its like classes in other languages, which in other words is like a dictionary.

#### Creating an Object

Creating an empty object -
```
let user = new Object();
let user = {};
```

Creating an object with properties (i.e. keys) -
```
let user = {
    name: "John",
    age: 30,
    "likes birds": true // multiword property name are allowed but must be quoted
};
```

Its possible to add new properties after the object has been created. Just simply assign it a value as if it always existed.
```
user.isAdmin = true;
```

In fact its then even possible to delete a property.
```
delete user.isAdmin;
```
