#### Functions

```
function name(parameter1, parameter2, ... parameterN) {
  ...body...
}
```

A function can access an outer variable as well. Outer variables are known as global variables in JavaScript, and are usually avoided. The outer variable is only used if there’s no local one.

A function always gets a copy of the values passed to it.

If a function is called, but an argument is not provided, then the corresponding value becomes `undefined`.

Default argument values can be specified in function declaration using `=`.
```
function showMessage(from, text = "no text given") {
```

A function with an empty `return` or without it returns `undefined`. A newline should not be given between `return` and the value, as its interepreted as an `undefined` being returned.

Functions that are used very often may sometimes have ultrashort names. For example, the jQuery framework defines a function with `$`, but usually its better to not name functions like that.

A function can be called earlier than it is declared and defined.

#### Function Expressions

Functions as variables.

```
let sayHi = function() {
  alert( "Hello" );
};
```

When functions are passed as argumentto another function, those functions are termed as `callback` functions.
```
function ask(question, yes, no) {
  if (confirm(question)) yes()  // Why no ; here?
  else no();
}

ask(
  "Do you agree?",
  function() { alert("You agreed."); },
  function() { alert("You canceled the execution."); }
);
```

In strict mode, when a function declaration is within a code block, it’s visible everywhere inside that block. But not outside of it.

#### Arrow Functions

Its another way to create functions.
```
let func = (arg1, arg2, ..., argN) => expression;
```

```
let sum = (a, b) => a + b;
```

If there are no arguments, parentheses will be empty but they should be present.
```
let sayHi = () => alert("Hello!");
```

Multiline arrow functions are possible too.
```
let sum = (a, b) => {  // the curly brace opens a multiline function
  let result = a + b;
  return result; // With curly braces, an explicit return is needed
};
```
