#### Constructor functions

Objects can be given names and then multiple similarly structured objects can be created using `Construction function` and the `new` operator.

`Constructor functions` are regular functions but by convention are named with a capital letter first, and should be run only with `new` operator.

```
function User(name) {
  this.name = name;
  this.isAdmin = false;
}

let user = new User("Jack");
```

> So here an object was declared just using a function. That's it, no curly braces or `new Object()`. are needed.

Inside a function, it can be checked whether it was called with `new` or without it, using a special `new.target` property.

```
function User() {
  alert(new.target);
}

User(); // Without "new" - undefined

new User(); // With "new" - function User { ... }
```

We can also make both new and regular calls to do the same thing. This approach is sometimes used in libraries to make the syntax more flexible.
```
function User(name) {
  if (!new.target) {
    return new User(name);
  }
  this.name = name;
}
```

Usually, constructors do not have a `return` statement. But if there is a `return` statement, then whatever return returns is what gets returned.

```
function BigUser() {
  this.name = "John";
  return { name: "Godzilla" };
}

alert( new BigUser().name );  // Godzilla
```

```
function SmallUser() {
  this.name = "John";
  return;
}

alert( new SmallUser().name );  // John
```

While invoking a constructor function, if there are no arguments to be given the parenthesis can be omitted.
```
let user = new User;
```

#### Optional Chaining

Optional chaining (`?.`) stops the evaluation if the value before `?.` is `undefined` or `null` and returns `undefined`. Its a newer feature of JavaScript and may not be available in older environments.

```
let user = {};
alert( user?.address?.street ); // undefined (no error)
```


Optional chaining is not an operator, but a special syntax construct, that also works with functions and square brackets.
```
let userAdmin = {
  admin() {
    alert("I am admin");
  }
};
userAdmin.admin?.(); // I am admin

let userGuest = {};
userGuest.admin?.(); // nothing (no such method)
```

```
let key = "firstName";
let user1 = {
  firstName: "John"
};
let user2 = null;

alert( user1?.[key] ); // John
alert( user2?.[key] ); // undefined
```

It can also be used with `delete`, but it can actually not be used for writing.
```
delete user?.name;

user?.name = "John"; // Error
```

####  Object.keys, values, entries

These 3 methods are supported by `Map`, `Set`, as well as `Array`. Its almost implied that if there is any data structure, it should support these methods.

Plain objects support them too. <br>
`Object.keys(obj)` – Returns an array of keys. <br>
`Object.values(obj)` – Returns an array of values. <br>
`Object.entries(obj)` – Returns an array of [key, value] pairs. <br>

Its important to note that compared to somehting like `Map`, the methods here are `Object.keys(obj)` and not `obj.keys()`. Also, that it returns an iterable and not a real array.

Objects lack many methods that exist for arrays, e.g. `map`, `filter` and others. But `Object.entries` and `Object.fromeEntries` can be used together to achieve the same effect.
