#### Global object

The `global object` provides variables and functions that are available anywhere. By default, those that are built into the language or the environment.

In a browser environment it is named `window`, for `Node.js` it is `global`. `globalThis` has recently been added to the language, as a standardized name for a global object, that should be supported across all environments. It’s supported in all major browsers.

In a browser environment, `alert("Hello");` is the same thing as `window.alert("Hello");`.

For some compatibility reasons, any global functions and variables declared with `var` (not `let`/`const`) become the property of the global object. However when scripts use JavaScript modules, that does not happen. Its hence not to rely on this behavior.

If a value needs to be made available globally, its better to declare it  directly as a property. However, in general using global variables are not advisable and should be minimal.
```
window.currentUser = {
  name: "John"
};
```

Global objects are usually used for checking support for modern language features.
```
if (!window.Promise) {
  alert("The browser is dated.");
}
```

>`Polyfills` is the term used for creating equivalent functions for older environments when a standard function does not exist there. It often uses the above syntax to check.
