When JavaScript is run in a browser, the browser provides a lot of API to any JavaScript running code to interface with itself. This is usually known as `Web API`.

[Here](https://developer.mozilla.org/en-US/docs/Web/API) is the full API.
> Where exactly does the DOM api fit in, need to understand that. [link](https://developer.mozilla.org/en-US/docs/Web/API/Document_Object_Model)

###### EventTarget

One of the interfaces is `EventTarget`. It is implemented by several different objects (such as `document`, `element`, `window`, `XMLHTTPRequest`, etc.) and can be used to listen to various events.


In the below example, the listener (i.e. the 2nd argument which is a callback) is added  to the list of listeners of the specified target's (i.e. the document here) specified event (i.e. 1st argument which is `DOMContentLoaded` here). So when the event does happen, the listener is fired.

```
document.addEventListener('DOMContentLoaded', () => { .. });
```
So there are 3 things - event target, event, listener <br>
[Here](https://developer.mozilla.org/en-US/docs/Web/Events) is the full list of all events.


###### HTML DOM events -

These are the events associated with the page's DOM.

`DOMContentLoaded` - When the page's DOM has fully loaded. This is distinct from the images, etc. also getting loaded.

`load` - When all the page's resources have been loaded too.

`click` - When a click happens.

Events also have properties attached to them. For example, click event has properties such as `screenX` and `screenY`.


###### HTML element events -

Various html elements have their own events. The `HTMLSelectElement` (i.e. drop-downs) for example have an event called change which is triggered whenever a new item gets selected. <br> [link](https://developer.mozilla.org/en-US/docs/Web/Events/change)
