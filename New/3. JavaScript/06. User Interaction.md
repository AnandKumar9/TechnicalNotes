##### alert, prompt, confirm

`alert` shows a message in a modal window and waits for the user to press 'OK'.

```
alert("Hi");
```

`prompt` shows a modal window with a text message, an input field for the visitor, and the buttons OK/Cancel. `title` is the text to show the visitor, and `default` is an optional second parameter that specifies the intial value for the field. Whatever user enters becomes avaliable in result.

```
result = prompt(title, [default]);
```

`confirm` shows a modal window with a question and two buttons: OK and Cancel.

The exact location of the modal window is always determined by the browser. Usually, it’s in the center. The exact look of the window also depends on the browser and can’t be modified.
