#### if statements

In `if`, there can be zero or more `elif` parts, and the `else` part too is optional.
```
if x < 0:
    x = 0
    print('Negative changed to zero')
elif x == 1:
    print('One')
else:
    print('More')
```

#### for loop

```
words = ['cat', 'window', 'defenestrate']
for w in words:
    print(w, len(w))
```

Loop statements may have an `else` clause; it is executed when the loop terminates through exhaustion of the iterable (with for) or when the condition becomes false (with while), but not when the loop is terminated by a break statement.

#### break and continue statements

`break` statement, like in C, breaks out of the innermost enclosing for or while loop.

`continue` statement, also borrowed from C, continues with the next iteration of the loop

#### pass statement

The `pass` statement does nothing. It can be used when a statement is required syntactically but the program requires no action. This is commonly used for creating minimal classes.
```
class MyEmptyClass:
    pass
```

#### while loop

Syntax of `while` loop -
```
while a < 10:
    print(a)
    a, b = b, a+b
```

#### range

Used to iterate over a sequence of numbers. The given end point is never part of the generated sequence (the below example prints till 4).
```
for i in range(5):
  print(i)
```

It is also possible to let the range start at another number, or to specify a different increment (even negative; sometimes this is called the 'step').
```
>>> list(range(5, 10))
[5, 6, 7, 8, 9]

>>> list(range(0, 10, 3))
[0, 3, 6, 9]
```

#### Enums

The way to have enums in Python is slightly indirect. A package/module named `enum` first needs to be imported, and then a class created whose baseclass is `enum`, with its attributes being the various cases. They all also need to be given some raw values, and if raw values do not really matter they should each be assigned as `auto`.

```
from enum import Enum

class MerchantCategory(Enum):
    Groceries = 'Groceries'
    Meal = 'Meal'
    xyz = enum.auto # If there is no raw value that is needed semantically
```

Iterating over all cases of an enum is as simple as doing a `for in <className>:`.

#### match

Its the Python version of case.

default is specified using `case _`. <br>
Multiple conditions can be combined using `|` (`case 401 | 403 | 404:`). <br>

The patterns can also be used to bind new variables that can then be used in that case's handling. <br>
```
match status:
     case 400:
         return "Bad request"
     case 404:
         return "Not found"
     case 418:
         return "I'm a teapot"
     case _:
         return "Something's wrong with the internet"
```

```
# point is an (x, y) tuple
match point:
    case (0, 0):
        print("Origin")
    case (0, y):
        print(f"Y={y}")
    case (x, 0):
        print(f"X={x}")
    case (x, y):
        print(f"X={x}, Y={y}")
    case _:
        raise ValueError("Not a point")
```

More conditions can also be added to various cases, these are termed as 'guard'.
```
 case Point(x, y) if x == y:
```

Subpatterns may be captured using the as keyword:
```
case (Point(x1, y1), Point(x2, y2) as p2): ...
```
will capture the second element of the input as p2 (as long as the input is a sequence of two points)

#### Misc.

The conditions used in `while` and `if` statements can contain any operators, not just comparisons (need an example).

The comparison operators `in` and `not in` check whether a value occurs (does not occur) in a sequence.

The operators `is` and `is not` compare whether two objects are really the same object.

Comparisons can be chained. For example, a < b == c tests whether a is less than b and moreover b equals c.

Comparisons may be combined using the Boolean operators `and` and `or`, and the outcome of a comparison (or of any other Boolean expression) may be negated with `not`. `and` and `or` are so-called short-circuit operators, their arguments are evaluated from left to right, and evaluation stops as soon as the outcome is determined.

Assignment inside expressions must be done explicitly with the `walrus operator` `:=`. This avoids a common class of problems encountered in C programs: typing `=` in an expression when `==` was intended.
```
while chunk := fp.read(200):
   print(chunk)
```
