#### List functions

`append(x)` <br>
`extend(iterable)` - Extend the list by appending all the items from the iterable argument. <br>
`insert(i, x)` - Insert an item at a given position. <br>

`remove(x)` - Remove the first item from the list whose value is equal to x. It raises a `ValueError` if there is no such item. <br>
`pop([i])` - Remove the item at the given position in the list, and return it. If no index is specified, a.pop() removes and returns the last item in the list. The square brackets around the i in the method signature denote that the parameter is optional (is it just a notational thing and not a real syntax?). <br>
`clear()` - Remove all items from the list. <br>

`index(x[, start[, end]])` - Return zero-based index in the list of the first item whose value is equal to x. Raises a ValueError if there is no such item. The optional arguments start and end are interpreted as in the slice notation and are used to limit the search to a particular subsequence of the list. <br>
`count(x)` - The number of times x appears in the list. <br>

`sort(*, key=None, reverse=False)` - Sort the items of the list in place <br>
`reverse()` - Reverse the elements of the list in place. <br>
`copy()` - Returns a shallow copy of the list. <br>

##### Stacks and Queues
List methods make it very easy to use a list as a stack. To add an item to the top of the stack, `append()` can be used and to retrieve an item from the top of the stack, `pop()` can be used.

Lists can also be easily used as queues, but its not efficient as doing inserts or pops from the beginning of a list is slow (because all of the other elements have to be shifted by one). `collections.deque` is what should be used for queues. It has functions such as `append()` and `popleft()` and there is also a `deque()` function to create a queue from a list.
```
from collections import deque
queue = deque(["Eric", "John", "Michael"])
queue.append("Terry")
queue.append("Graham")
queue.popleft()  
```

##### List Comprehensions

A list comprehension consists of brackets containing an expression followed by a `for` clause, then zero or more `for` or `if` clauses. The result will be a new list resulting from evaluating the expression in the context of the `for` and `if` clauses which follow it.

In the below example, the list comprehension creates a list where every element is a square of the index.
```
squares = [x**2 for x in range(10)]
```

Here every element is a tuple of two indices unless the indices are equal.
```
>>> [(x, y) for x in [1,2,3] for y in [3,1,4] if x != y]
[(1, 3), (1, 4), (2, 3), (2, 1), (2, 4), (3, 1), (3, 4)]
```

##### del

`del` remove an item from a list given its index instead of its value. It does not return anything. It can also be used to remove slices from a list or clear the entire list.
```
a = [-1, 1, 66.25, 333, 333, 1234.5]
del a[2:4]
del a[:]      # Clears the entire list
```

It can even be used to delete entire variables.
```
del a
```

#### Tuples and Sequences

Both lists and strings are sequence data types, they support things such as indexing and slicing. `Tuple` is another standard sequence data type.

A tuple consists of a number of values separated by commas, and can be accessed uding indexes (but is not a list, why not?).
```
>>> t = 12345, 54321, 'hello!'
>>> t[0]
12345
```

Also, unlike lists typles are immutable. They usually contain a heterogeneous sequence of elements that are accessed via unpacking.

Empty tuples are constructed by an empty pair of parentheses. A tuple with one item is constructed by following a value with a comma.
```
>>> empty = ()
>>> singleton = 'hello',    # <-- note trailing comma
```

The statement t = 12345, 54321, 'hello!' is an example of `tuple packing`.

The reverse operation is also possible. It is called `sequence unpacking` and works for any sequence on the right-hand side.
```
>>> x, y, z = t
```

#### Sets

```
basket = {'apple', 'orange', 'apple', 'guava'}    # Creates a Set
'orange' in basket                                # Fast memebership testing
a = set('abracadabra')                            # Creates a Set from a String

a - b                                             # Set with what's in Set a but not in Set b
a | b                                             # Set with what's in any of Set a or Set b
a & b                                             # Set with what's in both Set a and Set b
a ^ b                                             # Set with what's in Set a or Set b but not in both
```

Similarly to list comprehensions, `Set Comprehensions` are also supported:
```
>>> a = {x for x in 'abracadabra' if x not in 'abc'}
>>> a
{'r', 'd'}
```

#### Dictionaries

Dictionaries are indexed by keys, which can be any immutable type; strings and numbers can always be keys. Tuples can be used as keys if they contain only strings, numbers, or tuples.

```
tel = {'jack': 4098, 'sape': 4139}    # Creates a Dictionary
dict1 = {}                            # Creates an empty Dictionary
tel['guido'] = 4127                   # Sets a key's value
del tel['sape']                       # Remove a key

'guido' in tel                        # Check if a key is present
'jack' not in tel                     # Check if a key is not present

list(tel)                             # Returns a list of all the keys, in insertion order
sorted(tel)                           # Returns a list of all the keys, in a sorted order
```

The dict() constructor builds dictionaries directly from sequences of key-value pairs.
```
dict([('sape', 4139), ('guido', 4127), ('jack', 4098)])
```

`Dictionary comprehensions` can be used to create dictionaries from arbitrary key and value expressions.
```
>>> {x: x**2 for x in (2, 4, 6)}
{2: 4, 4: 16, 6: 36}
```

Looping through a dictionary -
```
for k, v in knights.items():
    print(k, v)
```

#### Looping through a sequence

When looping through a sequence, the position index and corresponding value can be retrieved at the same time using the `enumerate()` function.
```
for i, v in enumerate(['tic', 'tac', 'toe']):
    print(i, v)
```

To loop over two or more sequences at the same time, the entries can be paired with the `zip()` function.
```
questions = ['name', 'quest', 'favorite color']
answers = ['lancelot', 'the holy grail', 'blue']
for q, a in zip(questions, answers):
    print('What is your {0}?  It is {1}.'.format(q, a))
```

To loop over a sequence in reverse, reversed() can be used.
```
for i in reversed(range(1, 10, 2)):
    print(i)
```

To loop over a sequence in sorted order, `sorted()` function should be used.

Using `set()` on a sequence eliminates duplicate elements.
