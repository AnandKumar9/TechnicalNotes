###### Initialize/clone git

```
git init
git clone [url]
git clone -o customRemoteName[url] [custom folder name]   (the default remote name is origin)
git clone --single-branch -branch BranchName RepoURL (Clone a specific branch)
```

###### Add new or modified files to staging area
```
git add Default-568h@2x.png
git add *
```

###### Removing files
```
git rm (Unstaged file is deleted)
git rm [path] -f. (Staged file is unstaged and deleted)
git rm --cached [path] (Staged file is unstaged but not deleted)
git reset HEAD [path] (Staged file is unstaged but not deleted)

git revert [commit hash] --no-edit (Revert changes of specified commit and use a default commit message)
git revert [commit hash] --no-commit (Revert changes of specified commit but do not commit yet)
```

###### Get status of various files
```
git status
git status -s
git status --short
git diff
git diff --staged
git status --cached
```

###### Commit to git
```
git commit
git commit -v
git commit -m "commit message"
git commit -a -m "commit message"
git commit -am "commit message"
git commit --amend (Currently staged changes are added to prev commit. This creates a new commit ref and replaces the prev one.)
git commit --amend --no-edit (amend using the same commit message and metadata as previous commit)
git commit --amend -m "Commit 6" (amend option can also be used for just editing the prev commit message)
```

###### Get commit history -
```
git log
git log -p
git log -n
git log —stat
git log —-oneline
git log --pretty=format:"%h %an %s"
git log --oneline <filename> (All commits for the specified file.)
```
Time limiting options -  `--since=2.weeks or --after=2.weeks; --until=2.weeks or --before=2.weeks` <br>

Other filtering options - `--author, --committer, --grep (commit message), -S` <br>

Using custom date format - `--date=format:'%Y %m %d'`.
> So a log with custom date formats can be done this way.
```
git log --pretty=format:"%cd - %s" --date=format:"%Y %m %d"
```
Would print like this.
```
2019 06 23 - Parses path, topic
2019 06 17 - Initial commit
```

`%<|(n)` - Have the next placeholder take at least n columns.

```
git log --pretty=format:"%<|(15)%cd %<(36)%an %s" --date=format:"..."

2019 04 25      Kumar, Anand                         Remove test code and print logs
2019 04 25      Josh Adams                           call InitiatePayPalLinkingRequest in AgreeViewController
```


```
git show [commit hash]
git show --pretty="format:" --name-only [commit hash] (See the file added in a commit)
git diff --name-only [hash1] [hash2] (Get list of files changed between two commits)
git diff --name-only HEAD HEAD~2 (An alternate to using commit hashes, get list of files changed between current commit and the commit 2 levels before it.)
```

###### Get previous versions of files
```
git checkout --[path] (Overwrites working copy of just the specified file with that from last commit file)
git checkout [commit hash] (To get all files of an older commit)
git reset --hard [commit hash] (Discard uncommitted work in working directory and revert to an older commit)
```

###### Branching
```
git branch (Get a list of current branches)
git checkout -b [branch name] (Create a new branch and switch to it)
git branch [branch name] (Create new branch)
git checkout [branch name] (Switch to an existing branch)
git checkout -f [branch name] (To revert to another branch even if the current branch has uncommitted files)
git switch -c [new local branch name] [fetched remote branch name] (To checkout a fetched remote branch)

git log --oneline --decorate (Get commit history along with their current branches)
git log --oneline --decorate —graph --all (Get a graphical commit history along with their current branches)

git branch -d branch1 branch2 - To delete merged branches
git branch -D branch1 branch2 - To delete unmerged branches
git branch -m NewName - To rename the current branch

git merge [branch name] - To merge another branch into current branch
git merge --no-ff [branch name] -m "message" - To merge in a non-fast forward fashion
git branch --merged - To get a list of merged branches
git branch --no-merged - To get a list of unmerged branches
git cherry-pick [commit hash1, commit hash 2] - To cherry-pick selected commits

git format-patch <compared branch> -o <output directory> - To get git patches
git am <patch path> - To apply a git patch
```

###### Working with remote server
```
git remote -v (Get a list of configured remotes with URLs)
git remote add [custom name] [url] (Add a new remote)
git remote rm [remote name] (To remove a remote)
git remote show [remote name] (To get details of a remote)
git remote rename [old name] [new name] (To change the custom name of a remote)

git fetch [remote name] (Get latest files from a remote)
git fetch [remote name] [branch name] (Fetch just the specified branch from tne mentioned remote)
git fetch --all (Get latest files from all remotes)

git pull [remote name] (Get latest files from a remote and automatically merge it)
git pull [remote name] [remote branch name] (Get latest files from a specific remote branch and automatically merge it to current HEAD branch)
git pull [remote name] --rebase (To pull using a rebase)

git push origin master (To push the local commits from current branch into the master branch of origin remote)
git push [remote name] --mirror (To push all local branches to specified remote)

git push -u [remote name] HEAD (To push a new branch that is HEAD to remote, i.e. publish)
git push -u [remote name] localBranch:remoteBranch (To push change from a specific local branch to a specific remote branch)
git push [remote name] [branch name] --force (To do a force push, commits in remote are replaced altogether)
git push [remotename] [commit SHA]:[remotebranchname] (To push upto a specific commit, and not necessarily the latest commit)

git checkout -b [local_branch] [remotename]/[remote_branch]) (To pull changes from a remote branch into a new local branch of any name and checkout that branch).
git checkout --track [remote_name/branch_name] (To pull changes from a remote branch into a new local branch of same name and checkout that branch. Do a fetch all remotes before this if it says the branch name is not known.)
```

###### Working with tags
```
git tag (Get a list of tags)
git show [tag name] - To see a particular tag including which commit it is tagged to
git checkout -b [branch name] [tagname] - To checkout a tag from server into a new local branch

git tag [tag name] - To add a lightweight tag
git tag -a [tag name] -m "tag message" (Add an annotated tag)
git tag -a [tag name] [commit hash/checksum] - To add tag to an old commit
git tag -f v1.4 <commit-ref> 0 To forcefully use an existing tag name
git tag -d [tag name] - To delete a local tag

git push -u [remote name] [branch name] --follow-tags - To push all annotated tags to remote server while doing git push
git push [remote name] [tagname] - To push a specific tag to server/remote
git push [remote name] —-tags - To push all the tags to remote server
git push --delete origin [tag name] - To delete a remote tag
git push [remote name] :refs/tags/12345 - Another way to delete a tag from remote
```

###### Setting aliases

```
git config --global alias.[alias name] [command to be aliased] (To create a git command alias)
git config --global alias.cleanlog 'log --pretty=format:"%<|(15)%cd %<|(36)%cn %s" --date=format:"%Y %m %D"'

git conig --global --unset alias.cleanlog   (To remove the alias)

git config --get-regexp alias (list of configured aliases)
```

`~` can be used to refer to an older commit without giving the precise commit hash no.
For example, `git reset --hard HEAD~1` will reset to a commit that is just one version older than the current HEAD.

This worked when doing a usual push was giving an error message 'error: src refspec master does not match any.'
`git push origin HEAD:develop`
