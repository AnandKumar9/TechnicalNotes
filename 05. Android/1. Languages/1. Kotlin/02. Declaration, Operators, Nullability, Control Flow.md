##### Declaring variables - `val`, `var`, `const val`

`val` are immutable variables, `var` are mutable.

```
val i: Int = 5
var j = 7
```

The value for `const val` is determined at compile time, whereas the value for `val` is determined during program execution, which means, `val` can be assigned by a function at run time but `const val` cannot.

```
val value1 = complexFunctionCall() // OK
const val CONSTANT1 = complexFunctionCall() // NOT ok
```

In addition `const val` only works at the top level, and in singleton classes declared with object (not with regular classes). You can use this to create a file or singleton object that contains only constants, and import them as needed.
```
object Constants {
    const val CONSTANT2 = "object constant"
}
val foo = Constants.CONSTANT2
```

Kotlin allows you to place underscores in the numbers, where it makes sense to you.
```
val oneMillion = 1_000_000
val hexBytes = 0xFF_EC_DE_5E
```

`""` is used for strings and `''` for single characters. `$variable` is used for string templates.
```
val a = 5
val b = 12
"I have $a fish" + " and $b plants"
```

##### Number data types

Number types - `Int`, `Long`, `Double`, `Float`.

> Numbers are primitive, but can still have methods as if they were objects.

It is possible to create actual object wrappers around numbers, which is known as `Boxing`. Boxing happens automatically, such as for collections, where numbers are boxed and unboxed as needed. It is expensive though.

```
2.times(3)
res2: kotlin.Int = 6
```

##### Conditions and Booleans

###### Operators

Mathematical - `+`, `-`, `*`, `/` <br>
Comparison - `<`, `==`, `>`, `!=`, `<=`, `>=` <br>

###### `if` condition

```
val fish = 50
if (fish in 1..100) {
    println(fish)
}
```
`elseif` exists too.

###### `when` condition (i.e. `switch`)

`when` is like `switch` in other languages.
```
when (numberOfFish) {
    0  -> println("Empty tank")
    in 1..39 -> println("Got fish!")
    else -> println("That's a lot of fish!")
}
```

#### Loops

A `for` loop.
```
val school = arrayOf("shark", "salmon", "minnow")
for (element in school) {
    print(element + " ")
}

for ((index, element) in school.withIndex()) {
    println("Item at $index is $element\n")
}
```

You can step backward using `downTo` and change increments using `step`.
```
for (i in 5 downTo 1) print(i)

for (i in 3..6 step 2) print(i)
```

`while` loop.
```
var bubbles = 0
while (bubbles < 50) {
    bubbles++
}
```

`do...while` loop.
```
do {
    bubbles--
} while (bubbles > 50)
```

##### Misc.

###### No implicit casting between number types

Kotlin does not implicitly convert between number types, so you can't assign a short value directly to a long variable, or a Byte to an Int. This is because implicit number conversion is a common source of errors in programs. You can always assign values of different types by casting using functions like `toByte()`, `toInt()`, `toString()`, `toDouble()`.
```
val i: Int = 6
val b1 = i.toByte()
```

###### Nullability

By default, variables cannot be null. To have something be nullable, it should be declared with a `?` (i.e. like optionals in Swift).

```
var rocks: Int = null     // ⇒ error: null can not be a value of a non-null type Int
var marbles: Int? = null
```

`?` can also check if a variable is null.
```
var fishFoodTreats = 6
fishFoodTreats = fishFoodTreats?.dec()
```

`?:` is just like the nil-coalescing operator in Swift.
```
fishFoodTreats = fishFoodTreats?.dec() ?: 0
```

The not-null assertion operator, `!!` (double-bang), converts any value to a non-null type and throws an exception if the value is null. That is if you'd really prefer `NullPointerExceptions`. Using `!!` is not a recommended practice. (Like 'force unwrap' in Swift.)
```
val len = s!!.length   // throws NullPointerException if s is null
```
