##### Caching mechanisms

`Retrofit` - It can be configured to store a copy of every network result locally. Its a good solution for simple requests and responses, or small datasets.

`DataStore` - Can store key-value pairs. Its a good solution for a small number of keys and simple values, such as app settings. You can't use this technique to store large amounts of structured data.

App's internal storage directory - Data files can be saved in it. Your app's package name specifies the app's internal storage directory, which is in a special location in the Android file system. This directory is private to your app, and it is cleared when your app is uninstalled. This technique can be used to store complex and structured data that your app needs to query.

`Room` - Recommended solution for complex structured queryable data, because the best way to store structured data on a device's file system is in a local SQLite database.
