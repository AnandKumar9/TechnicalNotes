#### `awk` command
```
awk options 'SelectionCriteria {action}' file(s)
```

Both 'SelectionCriteria' and 'action' are optional, but at least one must be there. `print` is the default action. And by default the entire line is selected in the absence of a selection criteria.

###### Examples

All the below examples print all the lines that contain the text 'Word'. `$0` is a special variable that denotes the entire line.
```
awk '/Word/ { print }' Sample.txt
awk '/Word/ { print $0 }' Sample.txt
awk '/Word/' Sample.txt                    
```

Here, the 3rd column or field (i.e. word) of every line is printed.
```
awk '/.*/ { print $3 }' Sample.txt
```

Here only lines whose 2nd and 3rd columns have the specified text are selected, and then only their 1st column is printed.
```
Desktop (03:50 PM) $ awk '$2 == "India" || $3 == "Africa" { print($1) }' Sample.txt
NewDelhi
Calcutta
AdisAbaba
```

ERE regex can also be given in patterns in `awk`.
```
awk '/lineS[ie]/' Sample.txt               // Regex can also be used
```

Regex patterns can also be used on specific fields with `~` (match) or `~!` (negate match) operators. The below looks for 'America' text only in 3rd field.
```
Desktop (04:23 PM) $ awk '$3 ~ /.*America/' Sample.txt
```

`NR` is a built-in variable that specifies line number. `$x` specifies the field number 'x'. Here, only lines 2 through 4 get printed.
```
awk 'NR == 2, NR == 4 { print $1 }' Sample.txt
```

`-F` specifies the delimiter, whitespace is the default delimiter.
```
awk -F " " '/.*/ { print $3 }' Sample.txt
```
> `awk` is the only filter that uses whitespace as the default delimiter instead of single space or tab. A whitespace is any character that renders as a space, that is: space, tab, new line, carriage return, vertical tab, form feed.

###### Built-in variables

`$0` - Entire line <br>
`$1`, `$2`, etc. - 1st column, 2nd column, etc. <br>
`FNR` - Number of records so far processed in current file. Typically equates to line number of current file. <br>
`NR` - Number of records so far processed across all files. <br>
`FS` - Field separator (an alternative to `-f` flag). By default it is whitespace, however if being set it must be set in `BEGIN` section. <br>
`OFS` - The default output separator, by default it is an empty string. <br>
`NF` - Gives the number of fields in a line. Can be very handy when examining any line which does not have the same no. of fields across all lines. <br>
`NR` - Gives the number of records in the file. <br>
`FILENAME` - Name of the current file being processed. <br>
`ARGC` - No. of arguments in command line <br>
`ARGV` - List of arguments in command line <br>

###### Formatting output

`awk`'s `printf` action accepts most of the formats (such as `$d`, `%s`, etc.) that are used in C's `printf` function. This can be used to print the output in any desired way.

The output of `print` or `printf` can also be redirected with `>` and `|` symbols.
```
awk '{ print $1 }' Sample.txt  | sort   // Sorts the result and prints it
awk '{ print $1 }' Sample.txt > results.txt // Prints the result to another file
```

###### Variables and Expressions

Every expression can be interpreted as either a string or a number according to the context. <br>
Variable are deemed declared when they are used the first time, they are implicitly initialized as 0 or null string. They also need not be referred using `$` as in shell scripts. <br>

```
Desktop (03:27 PM) $ awk ' { \
x = "Hi"
print(x, $1) }' Sample.txt
Hi NewDelhi
Hi Bangkok
Hi Calcutta
Hi Ljubljana
```

Strings are always double-quoted and can include any character including escape sequences, octal and hex values. Octal values must be preceded by `\` and octal values must be preceded by `\x`.

Strings get concatenated just by placing them side by side (with a space in between).
```
Desktop (03:39 PM) $ awk 'NR == 1 { x="Hi"; y="There"; print(x y) }' Sample.txt
HiThere
```

> To separate lines of code in same line, put a `;` in between. To have a UNIX command go to multiple lines end every line with a `\`, press `Ctrl + Enter` to go to new line, and finally for running the command enter the usual `Enter`.

Any nonempty string or positive number is treated as true, and can hence be used as boolean check as well.

###### Operators

`||`  OR operator <br>
`&&` AND operator <br>
`!=` NOT EQUAL TO check <br>
`==` EQUAL TO check <br>
`~` FIELD MATCH <br>
`~!` NEGATE FIELD MATCH <br>
`>` GREATER THAN (for number comparison) <br>
`<` LESSER THAN (for number comparison) <br>

`awk` can handle decimal numbers as well, something that shell otherwise can't.

###### Flags

`-v` is used to specify initial value of a variable. This is especially useful when a command line argument needs to be used inside a script, but using it with `$` would otherwise not be possible due to it being interpreted as a column no. by awk.
```
remote_name=$1
git remote -v | awk -v argument=$remote_name '$1 ~ argument && $3 ~ /push/ {print $2}'
```

###### Storing script in a different file

The `awk` script can also be stored in a different file and then used with `-f` flag while running the `awk` command. The flag and other arguments continue to be specified directly in the command, it's just that the script itself gets stored in a separate file. Note that the script should not contain the enclosing quotes (`'`).
```
Desktop (04:41 PM) $ awk '$3 ~ /.*America/' Sample.txt
Lima Peru SouthAmerica Lima
WashingtonDC USA NorthAmerica WashingtonDC
NewYorkCity USA NorthAmerica WashingtonDC

Desktop (04:41 PM) $ cat Test.awk
$3 ~ /.*America/

Desktop (04:41 PM) $ awk -f Test.awk Sample.txt  // This is where awk file gets used
Lima Peru SouthAmerica Lima
WashingtonDC USA NorthAmerica WashingtonDC
NewYorkCity USA NorthAmerica WashingtonDC
```

###### `BEGIN` and `END` sections

`BEGIN` and `END` sections in a `awk` script indicate code that should be run before and after all the processing.
```
BEGIN {
	printf "STARTING "
} $3 ~ /.*America/
END {
	printf "ENDING "
}
```

###### More about data types

Array index can be anything, even a string. That is because, `awk` arrays are practically nothing but dictionaries (i.e. associative or key-value pairs in other words). There is no specified order in which the array elements are stored.
> How does that pan out? Having a string index. How do you then iterate sequentially?

Array elements are accessed using `varName[1]`, `varname[2]`, etc.

All the environment variables are maintained in the associative array `ENVIRON[]`.

`awk` is nearly a full fledged scripting language and has things like functions, if-else, for and while loop. An `awk` script is typically just a fraction of the size of its `C` counterpart. However `perl` is supposed to be even more powerful than `awk`.

###### Tricks

Using `awk` to trim a line.
```
awk '{$1=$1;print}'
```
That works because when you assign something to one of the fields, awk rebuilds the whole record (as printed by print) by joining all fields ($1, ..., $NF) with OFS (space by default). [link](https://unix.stackexchange.com/a/205854)

Assigning the output of an awk command to a variable.
```
url=$(git remote -v | awk '$1 ~ origin && $3 ~ /push/ {print $2}')
open $url
```

Use a tab character as the field separator.
```
awk 'BEGIN { FS = "\t" } { print $1 }' Filename.txt
```
