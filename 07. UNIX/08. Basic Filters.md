###### Printing and paginating filter for text files (`pr`)

`pr` command prints an input in a printer friendly fashion. It includes a header for every page, and also some blank lines as a a trailer towards the end of every page.

```
sou543$ ls -il | pr


Aug 28 16:19 2019  Page 1


    1	total 24
    2	 3847263 -rw-r--r--@  1 sou543  staff   175 Jul 27 04:47 Configurations.txt
    3	 4691357 -rw-rw-r--@  1 sou543  staff  1958 Aug  1 11:49 Links.txt
    4	 3927047 drwxr-xr-x@  7 sou543  staff   224 Aug 28 10:35 Notes
    5	 7078762 -rw-r--r--@  1 sou543  staff   118 Aug 13 19:19 Scratchpad.txt



```

`-t` flag suppresses the headers and footers. <br>
`-n` flag seems to print line number as well. <br>
`-x` flag (where 'x' is a number) tries to print entries in x number of columns. That means, if ''-3' is specified the 1st 3 lines will get printed in the first line itself in the output, as 3 different columns.

`+x` (where 'x' is a number) argument causes the printing to be done straight away from page number 'x'.

> As `pr` does formatting well suited for printers, it's very common to use `pr` and then pass it to `lp` for printing.

###### Line numbering filter (`nl`)

`nl` is another command that prints the received input (i.e. the passed file or the standard input) by prefixing a line number to each of the lines. Its a shorter alternative to `pr -tn`.
```
ls -ilR | nl
```
> But `cat -n` too does the similar thing on passed files. The forte of `nl` is that it can allow a lot more control on the line numbering. `cat -n` numbers empty lines as well, whereas `nl` by default does not.

`-s` flag inserts the specified string before every line.

###### Viewing top part of file (`head`)

`head` displays the first 10 lines of the file. <br>
`-n x` causes the first 'x' lines to be shown.

###### Viewing last part of file (`tail`)

`tail` displays the last 10 lines of the file. <br>
`-x` flag causes last 'x' no. of files to be shown. <br>
`+x` flag causes the files beginning from line no. 'x' to be shown as well. <br>
> If +x and -x are used together, that is an invalid use.

`-f` flag gives the output and does not return, and updates any changes to that file real time. This is particularly used to observe changes in a log file.
> Could see it working when appending contents to a file using `cat` in a separate session. However this did not work when I actually opened the file using a text editor and made changes.

`-c` flag gives the last (or after skipping) 'n' bytes instead of lines.
```
less -c -24 Test.txt
less -c +24 Test.txt
```

###### Slicing vertical portions (`cut`)

`cut` command can extract specified portions from every line of a file and print the output.

`-c` flag extracts specified columns (i.e. characters numbers). Here, the 2nd and 9th characters of each line are extracted and printed.
```
cut -c 2,9 Links.txt
```

`-d` flag extracts fields, the delimiter to separate fields is also specified as an argument.
```
cut -d Delimiter -f FieldNumbers filename
```
```
sou543$ cut -d \  -f 3 Links.txt
```
In the absence of that many fields, this seems to be extracting the first field instead for such lines. So be careful.

###### Combining inputs (`paste`)

`paste` command takes its inputs and combines them together by adding them literally. It uses tab as the default delimiter.
```
sou543$ cat File1
1
2
sou543$ cat File2
A
B
sou543$ paste File1 File2
1 A
2	B
```

`-d` flag allows to change the delimiter. <br>

It's also possible to provide only one file as an argument. The other argument can come from output of a previous command via a pipe.

`-s` flag when used with a single input joins all the lines together. <br>

###### Creating dump (`tee`)

`tee` command copies the input into the output (which can be a new file as well) and also prints the output. It essentially duplicates the character stream it receives in the input.
```
sou543$ head Links1.txt | tee shortlist
```
Here, the output of `head` command gets copied to a new file named 'shortlist'.

> Also, keep in mind that piping mechanism allows output of one filter to be the input of the another filter.

In the below example, `-` denotes the standard inout for second command which will be standard output of first command.
```
who | cmp user.txt -
```

###### Extracting sorted content from files (`sort`)

`sort` command can extract content, sort it and then give the output. It can even merge two sorted files and sort them.

```
sort Sample.txt
sort -t \  -k 2 Sample.txt
```

`-k` flag specifies the field to be used as primary (and secondary, etc. too) key for sorting. <br>
`-t` flag specifies the key/column to be used for sorting. <br>
`-n` does a numeric sort on files containing only numbers (otherwise 21 is considered to be before 4). <br>
`-u` flag removes repeated lines from the output. <br>
`-o` flag puts the output to a file, this file can even the same file that was sorted. <br>
```
sort -u Sample.txt Sample.txt
```
`-c` flag tells if the file is not sorted

###### Extracting unique entries from a sorted file (`uniq`)

`uniq` command gives the unique entries in a sorted file. it does not work on unsorted files and hence is typically used right after a sort command. <br>
Both `-u` and `-d` flags only shows lines that are not repeated. <br>
`-c` flag even shows the number of occurrences of each unique line. <br>

###### Translating (replacing) characters from standard input (`tr`)

`tr` command (translating characters) can change the individual characters in a line.
```
tr a b < Sample.txt
```
Here, all occurrences of 'a' in every line get replaced by 'b' and the result gets printed.

```
sou543$ cat -n Sample.txt
     1	a new file has been created
     2	second line in a new file
tr new old < Sample.txt
a old fill has bllo crlatld
slcood liol io a old fill
```
Here, 'n' is replaced by 'o', 'e' is replaced by 'l' and so on.

This command also takes in ranges such '[a-z]' in expressions.

`-d` flag can delete the characters mentioned in the only expression.
```
sou543$ cat -n Sample.txt
     1	a new file has been created
     2	second line in a new file

sou543$ tr -d e < Sample.txt
a nw fil has bn cratd
scond lin in a nw fil
```

`-s` flag can compress successive occurrences of specified character into a single occurrence.
