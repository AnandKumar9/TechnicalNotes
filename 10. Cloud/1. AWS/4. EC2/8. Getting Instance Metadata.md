Instance metadata, user-data, etc. can be fetched by running a particular `curl` command after ssh-ing into it. The IP address in this curl is `169.254.169.254`.

Getting metadata -
```
[root@ip-172-31-41-126 ec2-user]# curl http://169.254.169.254/latest/meta-data
ami-id
ami-launch-index
ami-manifest-path
block-device-mapping/
events/
hostname
iam/
identity-credentials/
instance-action
instance-id
instance-type
local-hostname
local-ipv4
mac
metrics/
network/
placement/
profile
public-hostname
public-ipv4
public-keys/
reservation-id
security-groups
```

([reference](https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/ec2-instance-metadata.html))
