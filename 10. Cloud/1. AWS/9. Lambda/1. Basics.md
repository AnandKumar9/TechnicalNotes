###### What is Lambda

Its a service in Compute section. It allows you to run code for any type of application or backend service, with zero administration. Lambda takes care of everything required to run and scale the code with high availability. The code can also be set up to automatically trigger from other AWS services.

> This kind of setup where you don't need to set up servers and auto-scaling yourself is known as `serverless architecture`. It is usually an advisable setup as everything gets taken care of automatically in it. `Lambda` it appears is a kind of serverless solution. (Apart from other things) It allows you to deploy APIs without having to set up necessary EC2 instances, load balancing, VPC, etc.

Some of the languages that Lambda support - Node.js, Java, Python, C#, Go

Some of its typical applications -
* As an event driven service. These events could be change in data in S3 bucket, DynamoDB table, etc.
* As a compute service in response to HTTP requests using API Gateway or API calls made using AWS SDKs.

One Lambda function can also trigger another lambda function. Some of the services such as RDS cannot trigger Lambda. Lambda functions are also said to be independent, i.e. every invocation triggers a new fresh function.

AWS X-Ray service is probably a service to help in debugging.

It can also do things an a global scope, for example backing up S3 buckets.

###### Pricing Model

With lambda, you only pay for the execution time.

Its priced on 2 things. First 1 million requests are free, and then its 20 cents per 1 million requests. Its also priced on duration the time code begins executing until it returns. The price depends upon the amount of memory allocated to the function.
