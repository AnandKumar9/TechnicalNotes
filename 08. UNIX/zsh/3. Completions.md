To initialize the completion for the current Zsh session, you’ll need to call the function `compinit`. Add this in your `zshrc`.

```
autoload -U compinit; compinit
```

`autoload` here loads a file called `compinit` containing shell commands. zsh looks for this file in the directories of the Zsh file search path, i.e. the directories defined in the variable `$fpath`. When the file is found, its content will be loaded as a shell function.  source could also have been used instead of autoload, but autoload has some advantages. It avoids name conflicts if you have an executable with the same name, doesn’t expand aliases thanks to the `-U` option, loads the function only when it’s needed (lazy-loading).

2. Zsh has two completion systems, the old `compctl` and the more recent `compsys`. `compsys` is a collection of Zsh functions. When you type a command in Zsh and hit the `TAB` key, a completion is attempted depending on the context. This context includes - What command and options have been already typed at the command-line prompt, Where the cursor is. 

   The context is then given to one or more *completer* functions which will attempt to complete what you’ve typed. Each of these completers are tried in order and, if the first one can’t complete the context, the next one will try. When the context can be completed, some possible *matches* will be displayed.

   The names of completers are prefixed with an underscore, like `_complete` or `_expand_alias`. A few completers return a special value 0 which will stop the completion.

3. Many aspects of the completion system using the zsh module `zstyle`. (`Modules` are part of Zsh but optional, detached from the core of the shell. They can be linked to the shell at build time or dynamically linked while the shell is running.)

   `zstyle` is used to configure some display styles, but can also be used to modify the default settings of Zsh scripts (modules, widgets, functions, and so on). The general way you can use zstyle to configure a Zsh module.

   ```
   zstyle <pattern> <style> <values>
   ```

   The pattern act as a namespace. It’s divided by colons and each value between these colons have a precise meaning. the context we saw earlier (what you’ve already typed in your command-line) is compared with this pattern.

   You can configure the Zsh completion system using options and the module `complist`, but using `zstyle` is the most flexible way to tune it.
