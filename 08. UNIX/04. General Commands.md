#### Printing with `echo` and `printf`

`echo` is quite a legacy command and its implementation varies a lot across shells. `printf` should be used instead.

`printf` accepts all the escape sequences `echo` is supposed to accept, but does not automatically insert a newline at the end. <br>
It also supports formatting as in C.
```
Desktop (01:18 PM) $ printf "ok %s now \n" $SHELL
ok /bin/bash now
```
`%s` - string <br>
`%30s` - printed in a space 30 characters wide (something about leading space) <br>
`%d` - decimal <br>
`%6d` - Similar to %30s <br>
`%o` - octal <br>
`%x` - hexadecimal <br>
`%f` - floating point number <br>

> Most shells have `printf` as an external command, but `bash` has it as an internal command.

##### Escape Sequences

An `escape sequence` is generally a two character string beginning with a `\`. `\n` is newline, etc.
However in bash at least, these escape sequences do not seem to be working when run on terminal using `echo`. However, they do work with `printf`.

If '0' is prefixed, the scape sequence denotes an octal value. For example, '\07' would denote the octal value of beep sound and would hence play the sound in printf.
```
Desktop (12:58 PM) $ printf '\07'
```

`\c `keeps the cursor in same line.
`\t` indicates a tab.
`\v` indicates a vertical tab (almost like a new line and the one tab)
```
Desktop (01:00 PM) $ printf "ok \v now \n"
ok
    now
```

`\0n` denotes ASCII character represented by octal value 'n' where 'n' must not exceed 0377 (decimal value 255).

#### Changing terminal characteristics with `stty`

`tty` gives the name (actually the filename) of the current terminal.
```
Desktop (01:32 PM) $ tty
/dev/ttys001
```

`stty` is used to view and set terminal's characteristics.
`-a` shows all the current settings.

```
Desktop (01:43 PM) $  stty -a
speed 9600 baud; 56 rows; 156 columns;
lflags: icanon isig iexten echo echoe -echok echoke -echonl echoctl
	-echoprt -altwerase -noflsh -tostop -flusho pendin -nokerninfo
	-extproc
iflags: -istrip icrnl -inlcr -igncr ixon -ixoff ixany imaxbel iutf8
	-ignbrk brkint -inpck -ignpar -parmrk
oflags: opost onlcr -oxtabs -onocr -onlret
cflags: cread cs8 -parenb -parodd hupcl -clocal -cstopb -crtscts -dsrflow
	-dtrflow -mdmbuf
cchars: discard = ^O; dsusp = ^Y; eof = ^D; eol = <undef>;
	eol2 = <undef>; erase = ^?; intr = ^C; kill = ^U; lnext = ^V;
	min = 1; quit = ^\; reprint = ^R; start = ^Q; status = ^T;
	stop = ^S; susp = ^Z; time = 0; werase = ^W;
```

`-` indicates the option is turned off.

`intr = ^C` indicates the interrupt key is 'Ctrl + C'. <br>
`erase = ^?` indicates the erase character is 'Ctrl + H' (does the same thing as backspace) <br>

Just giving `stty` too gives some information.
```
Desktop (01:43 PM) $ stty
speed 9600 baud;
lflags: echoe echoke echoctl pendin
iflags: iutf8
oflags: -oxtabs
cflags: cs8 -parenb
```

If `echo` is turned off, then keyboard entries are not shown in terminal. This is particularly useful when user is prompted to enter a password.
```
stty -echo
```

The interrupt key too can be changed this way. In the below example, the interrupt key gets set as Ctrl+C.
```
stty intr \^c
```

#### Misc. commands

`sleep` causes the execution to pause/sleep for the specified duration.

`basename` extracts the 'base' file name from an absolute pathname.
```
Desktop (02:42 PM) $ basename /Users/sou543/Desktop/script.sh
script.sh
```

`dirname` extracts the path of a file or directory's parent directory.
```
Desktop (11:09 PM) $ dirname /Users/sou543/Documents/Anand/Technical/Technical\ Notes/1.\ Languages/1.\ Regular\ Expressions/1.Basics.md
/Users/sou543/Documents/Anand/Technical/Technical Notes/1. Languages/1. Regular Expressions

Desktop (11:10 PM) $ dirname /Users/sou543/Documents/Anand/Technical/Technical\ Notes/1.\ Languages/1.\ Regular\ Expressions
/Users/sou543/Documents/Anand/Technical/Technical Notes/1. Languages
```

`cal` prints the calendar. Some of its format specifiers are `d, y, H, M, S, D, T`.
```
cal [ [month] [year] ] # This is the syntax
cal 03 2020

Desktop (12:19 PM) $ date +%Y
2019

Desktop (12:19 PM) $ date +"%Y %m"
2019 09
```
`bc` brings up a basic calculator in the shell session.

`script` records the entire session and saves it in a file (by default named as 'typescript') in the current working directory.

`passwd` is using for changing password.

`who` gives a list of all the logged in users.
```
Desktop (01:31 PM) $ who
sou543   console  Aug 27 01:12
sou543   ttys000  Sep  6 22:44
sou543   ttys001  Sep  8 11:41
```
First column shows the username, the second column shows the device names (really?) of the respective terminals (actually just the filenames associated with them), and then the date and time of logging in is shown.
`-H` shows a header as well <br>
`-u` shows idle time and PID too <br>

`PID` is the process-id, a number that uniquely identifies a process.
`who am i` prints the current user.


`uname` prints the name of the OS.
```
Desktop (01:38 PM) $ uname
Darwin
```
`-n` prints the nodename, i.e. the name by which the system is known to the network.
```
Desktop (01:39 PM) $ uname -n
38f9d3e3f3f5
```
> Keep in mind that UNIX even treats terminals as files.

`pbcopy` redirects the standard output's contents to clipboard. In the below example, the output of `grep` actually gets copied into clipboard and nothing is printed in the shell.
```
grep -E "SomeRegEx" Scratchpad.txt | pbcopy
```
