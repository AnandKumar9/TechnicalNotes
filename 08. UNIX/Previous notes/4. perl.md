#### perl

`perl` is another command line utility that is usually available in Unix systems and can be effectively used for string search-replace kind of tasks.

###### Running a perl script from command line
```
perl FilePath Arg1 Arg2
```

###### Basic syntax

All lines should end with a `;`. <br>
Comments begin with `#`.

```
$x = "Time to feed the cat!";   # Create variable and store a string in it.
print "$x\n";   # Print a variable in console.
```

Reading/writing a file's contents.
```
open my $fhread, '<', FilePath   # Open a file handler for reading contents of a file.
my $file_content = do { local $/; <$fhread> };   # Store contents of the file in a variable.
close $fhread;   # Close the file handler.

open my $fhwrite, '>', FilePath # Open a file handler for writing contents to a file.
print $fhwrite $file_content;  # Write contents of a variable to a file
close $fhwrite;   # Close the file handler.
```

Accessing `n`th argument passed to the script -
```
$ARGV[n] (Beginning from 0)   
# $#ARGV denotes index of last argument
```

A sample for loop.
```
my $numArgs = $#ARGV + 1;
foreach my $argnum (0 .. $#ARGV) {
    print "$ARGV[$argnum]\n";
}
```

###### Search-replace with `perl`

It seems pretty useful and more robust than `sed`. Works across multiple lines as well, and also with `\t`.

Replace a substring with something else.
```
$x =~ s/SearchSubString/ReplacementString/g;
```

Just like in sed, `g` implies global search and replace. Also, here too any delimiter can be used not just `\`.<br>

It also automatically does a regex search and replace.
> When there truly is a regex involved the last delimiter *has* to be specified (or else there is an error). <br>
`$x =~ s/fe[de]d/give/;`
