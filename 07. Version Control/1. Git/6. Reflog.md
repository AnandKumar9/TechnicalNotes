Git maintains a history or log of all the refs and this is what is known as `reflog`. They are stored in `.git/logs/refs/heads/.`, `.git/logs/HEAD`, and `.git/logs/refs/stash`.

The commit refs from here can even be used to get back a commit that was reset from and discarded.

```
git reflog (shows all the ref logs for HEAD branch)
git reflog show --all (show ref logs for all branches)
git reflog show --branch1 (show ref logs for a specific branch)
git reflog stash (show ref log for stash (if any))

git reflog expire (cleans up old or unreachable reflog entries)
git reflog delete commithash (deletes specified commit from ref log)

git merge commithash (apply specified commit from ref log to HEAD)

```

> Reverting to one of these commits can be as easy as doing a `git reset --hard <commit has from reflog>`. This I think does restore the entire commit history too. First take a backup though.
