### Chatting Modes

#### Various modes - Auto (default), Fast, Thinking

As of GPT 5.1 model, there are 3 modes -

![image-20251208184415575](./assets/image-20251208184415575.png)

#### Deep Research

Literally performs a 'deep research' where it analyzes information from multiple sources, **cross-verifies** them lot more than usual, and prepares a detailed report. Its a **long running task** that runs into minutes.

There is an **activity log** that is regularly updated in a sidebar on the right side, and all the consulted sources are also shown there.

> (As of GPT 5.1) It is different from the usual model's 'Thinking' mode. The Thinking mode does do more internal reasoning, but doesn't consult and analyze added resources on the internet. 

![image-20251207183411902](./assets/image-20251207183411902.png)

[Video](https://www.youtube.com/watch?v=YkCDVn3_wiw&t=554s)

#### Agent Mode

Automates things on your behalf, even brings up an embedded browser or shell view and simulates click, generates spreadsheets, automatically does deep research when it has to, and completes the task. Any of the connectors can also be toggled on to pull in additional data.

[Video](https://www.youtube.com/watch?v=AGr_Xolg0Ps)

#### Web Search

This basically does a real time internet search instead of relying only on trained information.

![image-20251207193508455](./assets/image-20251207193508455.png)

#### Canvas

Its like a notepad that I can start in any chat, and then later access it from that chat using a 'document' like icon on top right. The textbook usage is to basically upload a detailed file, and tell ChatGPT tom create a transcript from it in Canvas. You will then be able to edit it in Canvas (either yourself or by asking ChatGPT itself).

![image-20251208182947518](./assets/image-20251208182947518.png)

While entering a new prompt, just select canvas and then the answer will automatically go to the Canvas.

> There isn't any separate UI to access all the Canvases across various chats.

### Other Features

#### Apps and Connectors

Basically integrations with other apps and services. **Apps** work with things like Spotify, etc. **Connectors** work with document related services such as Google Drive, etc. 

> The connectors can be easily used to summarize Google drive documents.

#### GPTs

Just think of it as apps, there are specific GPTs that can be used and there is a GPT store.

##### Creating GPTs

Roughly there are two ways to create them - One is using chat instructions (**Builder Mode**) and other by filling up fields in a form (**Configure Mode**).

> These things are basically thought of and marketed as 'Assistants'. Set up some context with instructions and files, give it some APIs (termed as **Actions**) it can call, and then it will be an assistant specializing in that thing.
