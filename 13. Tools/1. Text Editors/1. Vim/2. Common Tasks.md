Append text at end of each line in a bunch of lines -

```
Ctl V (Enter Visual Block mode)
j or down (select as many lines as needed)
$ (Select till end for each line)
Shift A (Enter insert mode to append)
Type
Escape
```

Piping output from another filter into vim. The `-` in the end is necessary as that is what tells vim to read the input from stdin, otherwise by default vim's standard input is the console.
```
history | vim -
```
