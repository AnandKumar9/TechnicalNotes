`perl` can handle files, directories and processes, and can also do everything that `grep`, `tr`, `sed`, or `awk` can do. And even then, `perl` is supposedly faster than `shell`(?) and `awk`.

A `perl` program runs in special interpretive mode and the entire script is compiled internally in memory before being executed. Hence unlike other interpreted languages like the shell and awk, script errors are generated before execution itself.

Printing is not `perl`'s default action. All statements should end with `;`.
Usually perl programs are big and placed in separate `.pl` files.

`perldoc perlrun` can be used to bring up documentation.

`-e` flag is used to enter one line of program. Perl does not even look for filename in the argument list.
Perl variables need `$` prefix both in the definition, as well as in evaluation.
