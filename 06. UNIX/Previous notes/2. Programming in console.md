Create variables (don't have any space) - <br>
`9801a7a6eeb3:~ sou543$ x=5` (There shouldn't be any whitespace on either side of =)

Print variables (be mindful of spacing) - <br>
`9801a7a6eeb3:~ sou543$ echo $x`

Arrays -
```
m=(2,3) // Creates an array called m. Elements must be separated using commas
declare -a n=(5,6)  // Another way to create an array

{$m[1]}  // Accesses 2nd element of the array
{$m[*]}  // Accesses all the elements of the array
```

Export a shell variable as an environment variable - <br>
`export variableName`

Get all the environment variables - <br>
`env`

Sample environment variables for a terminal session.
```
PWD=/Users/sou543
x=5
LANG=en_US.UTF-8
XPC_FLAGS=0x0
and more
```

Exiting a programming mode - <br>
`exit`

Running a shell script -
The folder which has the script should be made the currently active directory in Terminal. <br>
`sh ScriptName`
