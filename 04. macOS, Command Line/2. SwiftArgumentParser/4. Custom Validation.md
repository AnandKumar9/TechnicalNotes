`validate()` method can be used on any `ParsableCommand`  or `ParsableArguments` type to perform custom validation. Throwing an error from there causes the program to exit with an error code, preventing the `run()` method from being called with invalid inputs.

```
struct Select: ParsableCommand {
    @Option var count: Int = 1
    @Argument var elements: [String] = []

    mutating func validate() throws {
        guard count >= 1 else {
            throw ValidationError("Please specify a 'count' of at least 1.")
        }
    }
  
   	mutating func run() { .. }
}
```

`ValidationError` type is a special `ArgumentParser` error.  It is always accompanied by an appropriate usage string.

([Reference](https://apple.github.io/swift-argument-parser/documentation/argumentparser/validation/))
