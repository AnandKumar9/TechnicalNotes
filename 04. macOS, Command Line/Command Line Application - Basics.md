When a command line application is created using Xcode, the exe/binary gets stored in that application's DerivedData folder. In a location such as this. The exe can be run directly from there if need be.

```
DerivedData/TestArgumentParser-gmvgiighapxjemajlazyqwbdpxjj/Build/Products/Debug/

anand@Anands-Air Debug % ./TestArgumentParser Hi
```
