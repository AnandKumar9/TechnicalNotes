Markdown is a way to format text on webpages. You write content in a simple text editor as per the markdown syntax and then when it gets rendered on a webpage (or anything that can render html), its automatically shown in a beautified way. The browser/site takes care of parsing the markdown content and generating the required HTML and rendering it. So in a way it's a wrapper around HTML and is easier than HTML.

Markdown files have the extension `.md`.
