##### /src/app/(site) folder

`src/app/(site)` is a **route group**, pages inside behave as if they were directly under `app/`.

![image-20260118133712025](./assets/image-20260118133712025.png)



##### Common files

**page.tsx** - Homepage, serves `/` <br>**layout.tsx** - Root layout for public site pages, wraps all routes inside `(site)`, and typically defines `<html>`, `<body>`, and other high level HTML tags <br>**posts/[slug]/page.tsx** - A blog post page, `[slug]` is a URL parameter. <br>**/tags/page.tsx** - All tags index page
