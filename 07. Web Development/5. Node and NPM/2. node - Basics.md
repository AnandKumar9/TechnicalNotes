##### What is node

`node` is a cross-platform JavaScript runtime environment that can be used in web servers, web applications, scripts, as well as command line tools. It runs V8, the JS enginer used by Chrome. ([Reference](https://nodejs.org/en/learn/getting-started/introduction-to-nodejs))

##### Runs in a single process

A `Node.js` app runs in a single process, without creating a new thread for every request. Node.js provides a set of asynchronous I/O primitives in its standard library that prevent JavaScript code from blocking, making blocking behavior the exception rather than the norm.

##### Any ECMAScript version can be used

In Node.js the new ECMAScript standards can be used without problems, as you don't have to wait for all your users to update their browsers - you are in charge of deciding which ECMAScript version to use by changing the Node.js version,

> Also Node.js supports both the CommonJS and ES module systems (since Node.js v12), while in the browser, we are starting to see the ES Modules standard being implemented. In practice, this means that you can use both `require()` and `import` in Node.js, while you are limited to `import` in the browser.

##### What is nvm

`nvm` (Node Version Manager) is a command line tool that allows to quickly install and maintain different versions of node. ([link](https://github.com/nvm-sh/nvm))

These are the options that nvm command has ([reference](https://github.com/nvm-sh/nvm?tab=readme-ov-file#usage-1)).

```
alias
deactivate
install
list-remote
reinstall-packages
uninstall
version
cacheexec
install-latest-npm
ls
run
unload
version-remote
current
help
list
ls-remote
unalias
use
which
```

`nvm install node` simply installs the latest version of node. `node` is an alias for the latest Node version, that can be used with nvm install, nvm use, nvm run, etc.

`nvm use` specifies the Node version to be used for current shell session. Uses `.nvmrc` if available and version is omitted. The precise documentation is that it modifies PATH to use the specified version.

> `nvm use <versionNumber>` is supposed to change the node version that is used (a `nvm install <versionNumber` may be needed before that) but it may not work very well. ReactNative's Metro bundler for instance still keeps picking whatever is marked as the default Node version. So for that first a `nvam alias default <versionNumber>` needs to be done (followed by `nvm use <versionNumber>`). ([link](https://stackoverflow.com/a/77299976))

`nvm run` whereas runs the specified Node version. It too uses `.nvmrc` if available and version is omitted.
