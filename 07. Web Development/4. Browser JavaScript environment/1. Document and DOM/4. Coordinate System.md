##### Coordinate Systems

JavaScript methods deal with one of two coordinate systems.

1. Relative to the window – Calculated from the window top/left edge (say clientX/clientY). Similar to position:fixed.
2. Relative to the document – Calculated from the document top/left edge (pageX/pageY). Similar to position:absolute in the document root.

When the page is scrolled to the very beginning, so that the top/left corner of the window is exactly the document top/left corner, these coordinates equal each other. But after the document shifts, window-relative coordinates of elements change, as elements move across the window, while document-relative coordinates remain the same.

##### Summary

Any point on the page has coordinates:

Relative to the window – `elem.getBoundingClientRect()`
Relative to the document – `elem.getBoundingClientRect()` + the current page scroll.
Window coordinates are great to use with `position:fixed`, and document coordinates do well with `position:absolute`.

Both coordinate systems have their pros and cons, there are times one is needed and there are times when the other one is needed, just like CSS position absolute and fixed.
