##### What is it

`XMLHttpRequest` is an older way of making API requests (and yes its not for just XML payloads alone). In modern development, it is used for supporting older browsers, and for doing things that `fetch` can't just yet (such as tracking upload progress).

##### Sample code

```
let xhr = new XMLHttpRequest();

xhr.open('GET', '/my/url');

xhr.send();

xhr.onload = function() {
  if (xhr.status != 200) { // HTTP error?
    // handle error
    alert( 'Error: ' + xhr.status);
    return;
  }

  // get the response from xhr.response
};

xhr.onprogress = function(event) {
  // report progress
  alert(`Loaded ${event.loaded} of ${event.total}`);
};

xhr.onerror = function() {
  // handle non-HTTP error (e.g. network down)
};
```

##### Resumable file upload

`xhr.upload.onprogress` allows to track upload progress, however it does not resume upload. To resume upload, we need to know exactly the number of bytes received by the server. And only the server can tell that, so an additional request is needed.

1. Create a file id, to uniquely identify the file

```
let fileId = file.name + '-' + file.size + '-' + file.lastModified;
```

2. Send a request to the server, asking how many bytes it already has. The server tracks file uploads by X-File-Id header. Should be implemented at server-side.

```
let response = await fetch('status', {
  headers: {
    'X-File-Id': fileId
  }
});

// The server has that many bytes
let startByte = +await response.text();
```

3. Use `Blob` method slice to send the file from startByte.

```
xhr.open("POST", "upload");

// File id, so that the server knows which file we upload
xhr.setRequestHeader('X-File-Id', fileId);

// The byte we're resuming from, so the server knows we're resuming
xhr.setRequestHeader('X-Start-Byte', startByte);

xhr.upload.onprogress = (e) => {
  console.log(`Uploaded ${startByte + e.loaded} of ${startByte + e.total}`);
};

// file can be from input.files[0] or another source
xhr.send(file.slice(startByte));
```
