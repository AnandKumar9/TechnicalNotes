#### Public-key encryption

Public key is distributed to everyone and anyone can encrypt some data using it. Private key however is kept just with you and data can be decrypted only using that.

The first algorithm to support this was developed by 3 people and is named after their initials `RSA`. It still remains the most commonly used public key encryption algorithm.

> In real world, cryptosystems follow a hybrid approach and use a mix of symmetric key and asymmetric key encryption algorithms.

##### Limitations

Public-key enryption algorithms are slow comapred to symmetrick-key encryption algorithms. Also, RSA can't encrypt anything larger than its modulus (i.e. 4096 bits) so it needs to the break the message intio several chunks.

##### Textbook RSA

Take 2 large secret prime numbers p and q. Multiply them and call it N. This is made public. Then pick an encryption exponent e (typically 3 or 65557). This too is made  public. `(N, e)` together is termed as the `public key`.

Anyone can then use the public key to do encryption. <br>
```
C ≅ M(mod N)
```

Decryption is done using decryption exponent d, which can be calculated using p and q. <br>
```
M ≅ C(mod N)
```

RSA essentially relies on decryption being impossible withiut knowing d , and d being very difficult to deduce from public key. It can however be obtianed using quantumn computers (that is thankfully not practical yet).

##### Implementation pitfalls

There are some RSA implementations like `Salt` that can have flaws and should not be used.

#### Hash functions

`Hash functions` are functions that take an inpit that can be of any length but always produce a fixed length value known as `digest`. Different inputs may give same digest but the same input will always give the same digest.

A good hash function is also quick to compute.

Hash functions have something called `internal state`. In some of the hash functions, this also gets used as the digest. But that is a flaw.

`Hash trees` are trees where each node is identifief by a hash value conssiting of its contents and hash value of its parent. This and its variants have many practical uses, including in git.
