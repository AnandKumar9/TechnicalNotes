Tuples -

Tuples are immutable. Also,they have an object reference at each position (unlike strings, which too are indexed in the same way but have a character at every position).

Creating a tuple -

```
tuple1 = 1, 4, 5   # Creates a non-empty tuple. That's it, just separate the elements with comma.
tuple2 = 1,        # Creates a one element tuple
tuple3 = tuple()   # Creates an empty tuple
```

Accessing the elements of a tuple -

```
tuple1[0]   # Use an index kind of operator, i.e. slice operator
```

Various tuple methods -

```
count(x)    # No. of times an object occurs in a tuple
index(x)    # Index of first occurrence of x in the tuple
```

Operators that can be used -

So it seems that all the usual operators can be used with tuples as well. Keep in mind though that these actually create a new tuple.

```
+, += (concatenation)
*, *= (multiplication)
[] (slice).
>=, ==, etc (Comparison operators)
```

print(x.key1)

Lists -

Lists are mutable.
All the items in a list are really object references (test this).

Creating a list -

```
list1 = [1, 2, 3, 4]  # Creates a non-empty list
list2 = list()        # Creates an empty list
list3 = list("ABC")   # Attempts to create a list from the passed argument
list4 = list(list1)   # Creates a list with shallow copy of the argument (i.e. only the first level is copied?)
```

Adding items to a list -

```
if 1 in list 1        # Tells if a particular item exists in a list (in, not in)
list5 = list1 + 5     # Concatenates items to a list and creates a new list (+)
list6 += [6, 7]       # Appends items to an existing list (+=)
list6 = list4 * 2     # Replicates a list, i.e. [1, 2] * 2 gives [1, 2, 1, 2]
list6 *= 3            # Replicates an existing list
```

Iterating through a list -

Iterating through a list.
```
for item in list1:
```

Getting index while iterating a list.

```
for index in range(len(list1)):
```

When the built-in range() function is given two integer arguments, n and m, the iterator it returns produces the integers n, n + 1, ..., m - 1. So specifying range(3, len(list1)) will cause the iteration to happen only from 3rd element to last element.

Various list methods -
```
reversed()
sorted()
```

List comprehensions -

Its just a syntactically compact way to create a list by iterating through another list and evaluating an expression on each of the items with an optional condition. (So for very simple examples, think of it like Swift's sequence map.)

```
[expression for item in iterable if condition]

list1 = [i for i in range(5, 9)]                # Creates [5, 6, 7, 8]. Upper bound is not included.
list2 = [i for i in range(5, 9) if i%2 == 0]    # Condition can also be specified.


list3 = [i + j for i in range(1, 5) for j in range (1, 3)]   # There can even be nested lists.
Here (i+j) is evaluated in the end. Think of first thing as the outermost for loop.
```

Slicing a list -

```
listOne = [1, 2, 3, 4, 5, 6]

listSlice1 = listOne[:2]                        # Creates [1, 2]. Slices from index 0 to 2.
listSlice2 = listOne[2:]                        # Creates [3, 4, 5, 6]. Slices from index 2 to end.
listSlice3 = listOne[::2]                       # Creates [1, 3, 5]. Slices every 2nd item beginning from index 0 .

itemGetterClosure = operator.itemgetter(1, 5)
slicedToTuple = itemGetterClosure(listOne)      # Creates a tuple (2, 6). Slices the mentioned indexes.
```

Sets -

Sets are mutable.
An unordered collection of zero or more object references that refer to hashable objects.

Technically it is a collection data type that supports the membership operator (in), the size function (len()), and is iterable, provides a set.isdisjoint() method, and supports comparison as well as bitwise operators (used for union, intersection, etc.).

Creating a set -

```
set1 = {1, 2, 1, 9, 7}        # Created using set literal
set2 = set("12a")             # Created using set() method, treats every character as a different element
```

Set comprehensions -

Creates a set by evaluating an expression through all elements of another set with an optional condition. Lot like list comprehensions.

```
setA = {x for x in set1 if x > 5 }
```

Various set operators -

```
| - union
& - intersection
- - difference
^ - asymmetric difference, i.e. mutually exclusive elements from both sets
```

Various set methods -

```
discard(set1)      # Removes all elements of set1 that are also in the receiver set. Exampe - set1.discard(set2)
```

Frozen sets -

Frozen sets are immutable.
So they are just sets that cannot be changed.

```
frozenset1 = frozenset([1, 5, 2, 1])      # Creates a frozen set
```

Various methods supported by frozen sets -

The only methods and operators they support are those that produce a result without affecting the frozen set to which they are applied.

```
copy(), difference(), intersection(), isdisjoint(), etc.
```

Dictionaries -

Dictionaries are mutable.

Dictionary keys should be hashable, so immutable data types such as float, frozenset, int, str, and tuple can be used as dictionary keys, but mutable types such as dictionary, list, and set cannot. (Are all immutable types hashable? Looks so.)

If a non-existent key if accessed in dictionary raises a `KeyError` exception

Creating dictionaries -

```
dict1 = dict({"key1": 2, "key2": "value2"})               # Creates a dictionary by specifying keys and values
dict2 = dict()                                            # Creates an empty dictionary
dict3 = dict([("key1", 1), ("key2", 2), ("key2", 2)])     # Creates a dictionary by passing another sequence (list of tuples)
dict4 = dict(zip(("key1", "key2"), ("value1", "value2"))) # Creates a dictionary using zip function. Keys and values in separate tuples.
dict5 = {"key1": 2, "key2": "value2"}                     # Creates a dictionary using literal notation {:}
dict6 = dict(key1="value1", key2="value2")                # Creates a dictionary by converting variables names to string key names.
```

Comparing dictionaries -

Dictionaries can be compared using the standard equality comparison operators (== and !=), with the comparisons being applied item by item (and recursively for nested items such as tuples or dictionaries inside dictionaries).

Comparisons using the other comparison operators (`<, <=, >=, >`) are not supported since they don’t make sense for unordered collections such as dictionaries.

Iterating through a dictionary -

```
Iterating over a dictionary’s items.
for key, value in d.items():
for item in d.items():
  # item[0] is key and item[1] is value
```

Iterating over a dictionary’s keys.
```
for key in d.keys():
for key in d:   # Yes, this too works.
```

Iterating over a dictionary’s values.
```
for value in d.values():
```

Dictionary views -

```
dict.items(), dict.keys(), and dict.values() methods all return dictionary views. A dictionary view is effectively a read-only iterable object that appears to hold the dictionary’s items or keys or values, depending on the view we have asked for.
```

If the dictionary the view refers to is changed, the view reflects the change.
The key and item views also support some set-like operations, i.e. intersection, union, difference, asymmetric difference.

Dictionary comprehensions -

Lot like other comprehensions. Creates a dictionary from another by evaluating an expression based on an optional condition.

```
{keyexpression: valueexpression for key, value in iterable if condition}

dictComprehension1 =  { key : value + 1 for (key, value) in dict3a.items() if value > 1 }
```

Default dictionaries -

Just like dictionaries, except that if a non-existent key is accessed a new entry actually gets made with using a default value.

Creating default dictionary -

```
def default_value(): return 0                    # The default value has to be provided using a factory function.
dictA = collections.defaultdict(default_value)   # Creates the default dictionary.
```

The name of a function is an object reference to the function. So when we want to pass functions as parameters, we just pass the name.

Ordered Dictionaries -

They store their items in the order in which they were inserted.
This however does not mean that they can be accessed using an index, just that they are always iterated in the same order.

Creating an ordered dictionary -

```
orderedDict1 = collections.OrderedDict([('key1', 1), ('key2', 2), ('key3', 3)])   # Creates an ordered dictionary
```

Iterable data type -

What is an iterable data type -
A data type that can provide an iterator.

What is a iterator -
An object that provides a `__next__()` method which returns each successive item in turn, and raises a StopIteration exception when there are no more items.

```
iterator1 = iter(list4)
while True:
    try:
        print(next(iterator1))
    except:
        break
```

What data types are iterable -
1. Any object that has an `__iter__()` method, OR
2. Any sequence (i.e., an object that has a `__getitem__()` method taking integer arguments starting from 0)


Some of the functions common to all iterable data types -
```
all(), any(), len(), max(), sum()
```

enumerate function -

Takes an iterator object and returns something called an enumerator object which can then be treated like an iterator, and at each iteration it returns a 2-tuple with the tuple’s first item the iteration number (by default starting from 0), and the second item the next item from the iterator enumerate() was called on.

```
iterator2 = iter(list4)
enumerator2 = enumerate(iterator2)
for index, item in enumerator2:
    print(index, item * 2)
```

Sequence unpacking operator (Splitting a list into multiple parts) -

Any iterable (lists, tuples, etc.) can be unpacked using the sequence unpacking operator, i.e. an asterisk or star (`*`). It works like this. The `*` portion is called starred argument.

```
list5 = [1, 2, 3, 4, 5, 6, 7]
first, second, *rest = list5
print(first, rest) prints 1 and [3, 4, 5, 6, 7]
```

So the sequence unpacking operator seems to just figure it out in how many parts should the iterable be split. And its a little strange, it isn't that it is splitting into a tuple but different keys, each of which can be different things. In the above example, variables first and second are int, but rest is a list.

Copying Collections -

As Python uses object references, when the assignment operator (=) no copying takes place.

If the right-hand operand is a literal such as a string or a number, the left-hand operand is set to be an object reference that refers to the in-memory object that holds the literal’s value.

If the right-hand operand is an object reference, the left-hand operand is set to be an object reference that refers to the same object as the right-hand operand.

When a separate copy is indeed needed, copy() function can be used.
```
listAlphaCopy = listAlpha.copy()
```

The above however creates a shallow copy (i.e. only one level is copied.) To create a complete copy, deepcopy() can be used.
```
listAlphaDeepCopy = copy.deepcopy(listAlpha)
```

map, filter, reduce -

Well the same thing as Swift collections' map, filter, reduce. Keep in mind though that map and filter actually produce map and filter objects, these then need to be converted to the appropriate iterable (i.e. list, etc.)

```
listA = [1, 2, 3, 4]

mapListA = map(lambda x: x*3, listA)                          # (function, iterable)
filterListA = filter(lambda x: x >= 3, listA)                 # (function, iterable)
reduceListA = functools.reduce(lambda x, y: x+y, listA, 0)    # (function, iterable, initial value) Unlike Swift, inital value is optional.

print(mapListA)                        # Prints <map object at 0x101b096d8>
print(filterListA)                     # Prints <filter object at 0x101b09780>    

print(list(mapListA))                  # Prints [3, 6, 9, 12]
print(list(filterListA))               # Prints [3, 4]
print(reduceListA)                     # Prints 10
```

Very often though a generator expression or list comprehension, etc. can also be used instead of map or filter.
```
[x*3 for x in listA]                   # Using comprehension instead of map.
[x for x in listA if x >= 3]           # Using comprehension instead of filter.
```

The operator module can also be used instead of function in reduce. It has functions for all the Python operator to make functional programming easier.

```
reduceListA = functools.reduce(operator.add, listA, 0)
```

There are also several built-in reducing functions that given an iterable, do the needful. sum(), max(), min(), all(), any(). all() returns true if all the elements are true, any() returns true if even one element is true.

```
sumListA = sum(listA)
```

itertools -

itertools module has plenty of useful functions to deal with iterables.

chain function gives all the items of passed lists (or iterables?) sequentially.

```
listA = [1, 2, 3, 4]
listB = [-3, -2]
for value in itertools.chain(listA, listB):
    print(value)                               # Prints [1, 2, 3, 4, -3, -2]      
```
