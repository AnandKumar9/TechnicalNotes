  },

Extracting an object function in strict mode -

If strict mode is enabled, then if any function property of an object has to be extracted it must be first binded.

m1 = jane.describe                   // This will not work
var z2 = jane.describe.bind(jane)
print(z2())                          // This will work


Constructors -

So constructors in JavaScript seem to be analogous to classes (though I think it is called an object) in other languages.

Its created using function syntax. Point is actually an object now.

function Point(x, y) {
  this.x = x;
  this.y = y;
}                                                             // Create a new object and add properties to it

Point.prototype.distance = function() {
  return Math.sqrt(this.x * this.x + this.y * this.y);
};                                                            // Add functions to the object

var p = new Point(3, 5);        // Creating a new instance of the object
p.distance()                    // Invoking the instance's function
p.x                             // Accessing the instance's property
delete p.x                      // Dalete a property from an instance                       
if ('x' in p) {                 // Check if a property exists in the instance

'this' keyword -

Every function also has a special variable called 'this' which probably just allows it to refer to the properties of the object it might be in.

This can cause an issue if the function has a nested function within its definition and that nested function also uses this. There are ways to work around this.

One is to store of the this in a different variable.
logHiToFriends: function () {
    'use strict';
    var that = this;
    this.friends.forEach(function (friend) {
        console.log(that.name+' says hi to '+friend);
    });
}

Sometimes the method in question (like forEach above) also takes another argument which says what should be treated as this inside the method.
logHiToFriends: function () {
    'use strict';
    this.friends.forEach(function (friend) {
        console.log(this.name+' says hi to '+friend);
    }, this);
}
