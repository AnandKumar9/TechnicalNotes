Its really just a simple try-catch construct. The exceptions are of type Error and custom errors too can be thrown using the throw keyword.

function funcA(x1) {
  if (x1 == 0) {
    throw new Error('Hey, 0 here')
  }
  return x1 * 2
}

try {
  print(funcA(0))
} catch (exception) {
  print(exception)
}
