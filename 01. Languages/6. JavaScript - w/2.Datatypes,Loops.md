###### Strings -

```
var str1 = "abcdefb"      // Creating a string
str1.slice(2)             // Creates a new string by slicing out a substring beginning from index 2 of str1      
str1.slice(1, 3)          // Creates a new string by slicing out a substring from index 1 to 2
str1.indexOf('b')         // Gives the first index which has the passed item. If the item does not exist, it returns -1 as index.
```

###### Regular expressions -

```
var regexp1 = /d(b+)d/                  // Creating a new regexp, just put the regexp between / and /
var regexp1 = /d(b+)d/g                 // Specifying a modifier for the regexp. 'g' is the global modifier.
var regexp3 = new RegExp('^(ABC).*')    // Creating a new regexp using Regexp keyword

"cdbbdbsbz".match(regexp1)              // String.match(regexp) returns an array containing all the possible matching substrings.
regexp1.exec("cdbbdbsbz")               // A regular expression method instead of the above string method. Does the same thing though.
```

###### Inspecting the type of data -

`typeof()` needs to be used.

```
typeof(true)            // Returns boolean
typeof("abc")           // Returns string
typeof(null)            // Returns object
typeof(f)               // Given f was assigned a function, returns function
typeof({})              // Returns object
```
