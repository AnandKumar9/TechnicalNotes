Declaring and calling a function -

function func1(a, b) {
  return a + b;
}

func1(5, 9);


Variable no. of arguments -

In fact a variable no. of arguments can be passed to functions and all these arguments are accessible using arguments keyword inside the function.In the below snippet, although seemingly only 1 argument is passed to the function if at all more were passed, they can be acceesed using built-in arguments array. If an argument that is not referred to is accessed, it will return 'undefined'.

function func2(a) {
  print(a)
  print(arguments[1])     // Gives the 2nd argument that may have been passed. If there isn't any 2nd argument it gives 'undefined'.
}

func2(4, 5);

arguments is not actually an array, arguments.length is however allowed. If needed, it can be converted into a full-fledged array by the spread operator.
Array.prototype.slice.call(arguments)


Checking if an argument has been passed -

Whether a specific argument that is there in the function declaration actually gets passed or not, can be checked inside the function definition by the || operator.

function pair(x, y) {
  x = x || 5;            // If x is not passed, 5 is used instead
}


Function declarations are hoisted -

What it means is that no matter where in the file functions are declared, they are automatically moved to the beginning of its current scope. Hence, they can be called even before they are declared.

};

f(10, 20))              // This is how the function can then be get called


Closures -

A closure is a function that has connection to the variables of its surrounding scopes.

Each function stays connected to the variables of the functions that surround it, even after it leaves the scope in which it was created. Hence, in the below exampe the value keeps incrementing with every invocation.

function funcC(x) {
  return function() {      
    x++
    return x
  }
}

var x1 = funcC(20)
x1()                 // Returns 21
x1()                 // Returns 22


IFFE -

IFFE (immediately invoked function expression) is just a technique to immediately invoke a closure so that it uses the current value of the variable.

So here is the problem.

var result = [];
for (var i = 0; i < 5; i++) {
  result.push(function() {
    return i
  });
}
print(result[0]())     // Returns 5 and not 0 as that is the current value of i
print(result[3]())     // This too returns 5 and not 3 as that is the current value of i


And here is how IFFE solves it.

var result = []
for (var i = 0; i < 5; i++) {
  y = function() {
    var x = i
    result.push(function() {
      return x
    });
  };
  y();
}
print(result[0]())     // Returns 0
print(result[3]())     // Returns 3
