###### Primitive types -

Primitive types - booleans, numbers, strings, null and undefined
Everything else is object

Primitive types are compared by their values when compared using ===. Also, properties cannot be added, removed or modified. You already get a pre-determined set.

###### Ternary operator -
var z = x == 3 ? x * 3 : -x

###### Boolean operators -
&&, ||, !, ===, !==, ==, !=, >, >=, <, <=


###### Equality -

== is lenient equality
=== is strict equality

if (obj1 === obj2)  // Matches for empty non-identical objects, or for identical objects

in case of primitives, === evaluates to true, if the value matches.
in case of objects, === evaluates to true only if the operands are the very same objects.

|| operator -

|| operator returns x if it is truthy (not null, undefined, etc.). Otherwise, it returns the second operand.
y = x || 5;  // Here if x is not truthy, y is assigned 5.

false, 0, NaN, and '' are also considered false

undefined and null -

Undefined means no value, null means no object. So its as if undefined is a primitive thing, null is an object thing.

Checking for undefined or null.
if (x === undefined || x === null) {
if (!x) {


###### Strict and sloppy modes -

Strict mode enforces more correctness of the code. For example, if strict mode is enabled a variable should really have the qualifier var at its declaration.

Enabling strict mode - 'use strict';


###### Misc. -

Putting a semi-colon at the end of a line is actually optional.

NaN and Infinity are special values

All numbers in JS are floating-point. Hence, 1 === 1.0 evaluates to true
