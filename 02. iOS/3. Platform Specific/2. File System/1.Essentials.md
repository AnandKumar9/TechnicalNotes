#### Physical location of various files.
When running on simulator, here are various locations in `Finder`.

###### UserDefaults.standard - <br>
Physically, UserDefaults are plist files. As of iOS 11, the precise location of the corresponding plist file for `UserDefaults.standard` is  `Library\Preferences\<BundleID>.plist`.

So programmatically it can be found with below code.

```
NSArray *paths = NSSearchPathForDirectoriesInDomains(NSDocumentDirectory, NSUserDomainMask, YES);
NSString *libraryDirectory = [paths objectAtIndex:0]; // Get Library directory
```

As of iOS 11, the Finder location is like this.
```
/Users/sou543/Library/Developer/CoreSimulator/Devices/<Some ID>/data/Containers/Data/Application/<Another ID>/Library
```

Keep in mind that this plist file is meant only for `UserDefaults.standard` and hence only gets created if there is something actually getting stored in it by the app.
