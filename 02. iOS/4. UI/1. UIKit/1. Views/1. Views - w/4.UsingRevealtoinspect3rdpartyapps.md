Using Reveal to inspect 3rd party apps, i.e. apps whose source code is not available with you. This can be done with Simulator apps.

Find process name or process id for the app. (pro attach -n MobileSideShow)
Attach lldb to it.
Call the code needed to launch Reveal.
Resume the program.

Statically adding Reveal to a project (i.e. without using pod) ([link](http://support.revealapp.com/kb/getting-started/integrating-reveal-static-linking))
1. Locate framework file and add to project. Have ‘Copy items’ checked. Reveal.framework should show up in Link Binary with Libraries.
2. Add ‘-ObjC -lz -framework Reveal’ in Other Linker Flags - Debug.
3. Have the following in Framework Search Paths.
$(inherited) 
"$(SYSTEM_APPS_DIR)/Reveal.app/Contents/SharedSupport/iOS-Libraries"
