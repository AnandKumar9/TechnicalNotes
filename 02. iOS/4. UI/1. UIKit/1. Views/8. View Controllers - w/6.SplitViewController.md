A split view controller class is container view controller that manages two different panes. The first pane has a fixed width of 320 points and a height that matches the visible window height. The second pane fills the remaining space.

It is available only in iPad.

The panes are managed by the view controllers that are provided. The interaction between these view controllers should be managed programmatically. However rotations and some other aspects (?) are managed by the split view controller itself. These view controllers are specified using the viewControllers property, with the left view controller (also called master view controller) being the first element of the passed array and the right view controller (also called detail view controller) being the second element of the passed array.

A split view controller must always be the root of the application window. It is usually created using a storyboard and is marked as 'first view controller'. It can just as easily be created programatically too.

A split view controller supports an orientation only if both the contained view controllers do.

The presentsWithGesture property allows to specify if the left view should shown up via a swipe gesture. The default value is YES. Hiding will anyway happen via a swipe gesture, this property controls whether even it should show up based on a swipe gesture. However usually in such a case, the delegate should also implement splitViewController:willHideViewController:withBarButtonItem:forPopoverController: method.

In the splitViewController:willHideViewController:withBarButtonItem:forPopoverController: method, the passed bar button item can be assigned appropriate text, etc. and set as the bar button item in navigation bar or toolbar being used. Taps on this button will show the popover and this popover is available in the last argument of this method.

Most probably the popover shown in case of split view controllers is special as it slides in from left, unlike the usual popovers which can just be shown from anywhere in the screen.

Creating a split view controller programatically.

In AppDelegate's didFinishLaunchingWithOptions: -

self.window = [[UIWindow alloc] initWithFrame:[[UIScreen mainScreen] bounds]];

ViewController1* vc1 = [[ViewController1 alloc] init];
ViewController2* vc2 = [[ViewController2 alloc] init];
UISplitViewController* splitViewController = [[UISplitViewController alloc] init];
splitViewController.viewControllers = [NSArray arrayWithObjects:vc1, vc2, nil];

self.window.rootViewController = splitVC;
[self.window makeKeyAndVisible];


Getting a reference to split view controller in the code when created in storyboard.

In AppDelegate's didFinishLaunchingWithOptions: -

UISplitViewController *splitViewController = (UISplitViewController *)self.window.rootViewController;
ViewController *leftViewController = [splitViewController.viewControllers objectAtIndex:0];
UIViewController *rightViewController = [splitViewController.viewControllers objectAtIndex:1];

splitViewController.delegate = rightViewController;
