Table view custom header and footer -

The following needs to be done to have a custom header or footer which has its own xib. It works with both iOS 8 and iOS 9.

Create the custom UITableViewHeaderFooterView class. And then create another xib for it. Ensure that the xib's file's owner is NSObject and that the custom class is the class just created.

Override custom subclass's initWithFrame with below implementation.

- (id)initWithFrame:(CGRect)frame {
    if ((self = [super initWithFrame:frame]))
    {
        NSArray* objects = [[NSBundle mainBundle] loadNibNamed:@"nibName" owner:self options:nil];
        UIView *nibView = [objects firstObject];
        UIView *contentView = self.contentView;
        contentView.backgroundColor = [UIColor clearColor];
        CGSize contentViewSize = contentView.frame.size;
        nibView.frame = CGRectMake(0, 0, contentViewSize.width, contentViewSize.height);
        [contentView addSubview:nibView];
    }
    return self;
}

In table view's view controller, register the header view class for reuse identifier (though this is not needed with this approach), create a header view and assign it to the table view's tableHeaderView (or tableFooterView) property.

ChooseFacilityHeaderView* headerView = [[ChooseFacilityHeaderView alloc] initWithFrame:CGRectMake(0, 0, 320, 200)];
self.tableView.tableHeaderView = headerView;

There is no need to implement the viewForHeaderInSection: or heightForHeaderInSection: method. Those methods are meant for the section header and not the table view header.

A xib with UITableViewHeaderFooterView as its custom class should not have a background color assigned in the xib as it then gives an error in the debug console (nothing crashes though) and the color is not implemented. If however the backgroundColor is assigned programmatically to the contentView it works.


*************************


iOS 11 onwards UITableViewHeaderFooterView should be used for all headers and footers. Both table view headers and footers, and also section headers and footers. Any subviews should only be added to their contentView.
