Rules of thumb (there can be exceptions) - 

1. View’s geometry should never be specified using its frame, bounds, or center properties.
2. Stack views should be used wherever possible. Stack views manage the layout of their content themselves.
3. Create constraints between a view and its nearest neighbor.
4. Avoid giving views a fixed height or width. However, setting a minimum or maximum size for the view can be useful (this can probably only be done programmatically).
5. In iOS, leading and trailing constraints should be used over right and left constraints. 
6. For anything that can have an intrinsicContentSize, use it and have appropriate CHCR priorities. 
7. Superview’s semantic content attribute should be used specify whether the content’s layout should be flipped when switching between left-to-right and right-to-left languages.

8. The following horizontal constraints should be used in iOS, when constraining an item to the edge of the view controller’s root view.

  a. For most controls, a zero-point constraint to the layout margins should be used. The system automatically provides the correct spacing based on what the device is and how the app presents the view controller.

  b. For text objects that fill the root view from margin to margin, the readable content guides should be used instead of the layout margins.
c. For items that need to fill the root view from edge to edge (for example, background images), the view’s leading and trailing edges should be used.

9. The following vertical constraints should be used in iOS. <br>

   a. If the view extends under the bars, the top and bottom margins should be used. This is particularly common for scroll views, allowing the content to scroll under the bars. However, the scroll view’s `contentInset` and `scrollIndicatorInsets` properties should be correctly set for an accurate initial position of the content. Alternately `automaticallyAdjustsScrollViewInsets` property of the view controller can also be modified.

   b. If the view does not extend under the bars, top and bottom layout guides should be used.
