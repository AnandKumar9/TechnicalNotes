For an object to be archivable, it must conform to the `NSCoding` protocol. What it means is that all its properties too should conform. Foundation classes such as `NSString`, `NSArray`, `NSDictionary`, etc. already conform to `NSCoding` protocol. However, custom objects must be made to explicitly conform to it.

There are just two methods in `NSCoding` protocol -<br> `encodeWithCoder:` (for archiving)<br>
`initWithCoder:` (for unarchiving)<br>

###### Sample implementation of NSCoding methods in a custom object

```
- (void)encodeWithCoder:(NSCoder *)aCoder {
    [aCoder encodeObject:_directorName forKey:@"directorName”]; //actually a NSString
    [aCoder encodeObject:_directorMovies forKey:@"directorMovies"]; //actually a NSArray
}

- (id)initWithCoder:(NSCoder *)aDecoder {
    self = [super init];
    if (self)
    {
        self.directorName = [aDecoder decodeObjectForKey:@"directorName"];
        self.directorMovies = [aDecoder decodeObjectForKey:@"directorMovies"];
    }
    return self;
}
```

If this class had a custom superclass which itself implements `NSCoding`, then the `super encodeWithCoder` and `initWithCoder:` methods must also be called in these methods.

###### Archiving and unarchiving with convenience methods

```
BOOL success = [NSKeyedArchiver archiveRootObject:director1 toFile:archivePath]; //Archiving
Director *director = [NSKeyedUnarchiver unarchiveObjectWithFile:archivePath]; //Unarchiving
```

###### Custom Archiving

```
NSMutableData *data = [NSMutableData data];
NSKeyedArchiver *archiver = [[NSKeyedArchiver alloc] initForWritingWithMutableData:data];
[archiver encodeObject:aPerson forKey:ASCPersonKey];
[archiver finishEncoding];

NSKeyedUnarchiver *unarchiver = [[NSKeyedUnarchiver alloc] initForReadingWithData:data];
Person *aPerson = [unarchiver decodeObjectForKey:ASCPersonKey];
[unarchiver finishDecoding];
```
