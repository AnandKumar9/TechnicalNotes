What window or tab shows up when you pause a run, complete a run, etc. can be set up in Preferences -> Behaviors.

Custom created tabs can also be used here. Usually, most of the settings are done in Running - Pauses, Generates Output, Complete.
You can decide which tab to show when these things happen, how to show the debug area and which navigator view to be shown.
