##### Associative References

Associative references allow to add data to objects (both objects of user-created classes as well as in-built classes). They do not seem to be quite like instance variables, but do add data (or variables) to objects.

`<objc/runtime.h>` needs to be imported for it. Also, the project's base SDK should be at least 10.6. The base SDK of a project can be set from Project -> Edit Project Settings.

###### Code snippet

```
static void *SuperClassKey;
NSString *result = objc_getAssociatedObject(self, &SuperClassKey);
objc_setAssociatedObject(self, &SuperClassKey, variableC1, OBJC_ASSOCIATION_RETAIN_NONATOMIC);
```

To break an association, `nil` needs to be passed to the object along with the concerned key.
```
objc_setAssociatedObject(student1, &prefPhone, nil, OBJC_ASSOCIATION_RETAIN);
```
