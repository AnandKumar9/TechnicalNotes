#### Cancellable

`Cancellable` is a protocol that indicates that an activity or action supports cancellation. Subscriptions (such as the one craeted when a sink is called on a publisher) are cancellables. They can be cancelled by calling the `cancel` function.

`cancel()` - Cancels the activity.

`store<C>(in: inout C)` - Stores this cancellable instance in the specified collection.

`store(in: inout Set<AnyCancellable>)` - Stores the cancellable instance in the specified set. Its basically a convenient way to store a cancellable in an array.
```
var cancellables: [AnyCancellable] = []
testCancellable?.store(in: &cancellables)
```

`AnyCancellable` is a type-erasing cancellable object (i.e. a class) that executes a provided closure when canceled. Its apparently used to store cancellation tokens.

#### Subsription

`Subscription` is the protocol that actually represents the connection between a publisher and a subscriber. They conform to `Cancellable` and are usually reference types (like class). A subscription can be cancelled only once.

`request(Subscribers.Demand)` - Required. Tells a publisher that it may send more values to the subscriber.
