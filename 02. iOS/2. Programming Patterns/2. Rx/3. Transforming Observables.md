There are functions that can do work upon events emitted by an observable before passing them on to the subscribers.

##### map

`map` returns a new observable which modifies each `next` event emitted by the source observable by applying the passed transform.

```
func map<Result>(_ transform: @escaping (Int) throws -> Result) -> Observable<Result>
```

```
subscription1 = publishSubject1.map { $0 + " MODIFIED" }.subscribe {
    print("\($0)")
}
```

##### scan

`scan` is kind of like Sequence reduce. Every next event emitted by the source observable goes through a closure where the result of the previous closure invocation is also available.

```
func scan<A>(_ seed: A, accumulator: @escaping (A, Int) throws -> A) -> Observable<A>
```

```
sequence1.scan(-1, accumulator: { $0 + $1 }).subscribe(onNext: {
    print("\(Date().get(.second)) SCAN: \($0)")
}).disposed(by: disposeBag)
```

##### reduce

Lot more like Sequence reduce than scan is. Emits just one event which is the final scan event after observable completes. What it also means is that the source observable needs to send a `onComplete` event for reduce to emit an event.

```
func reduce<A>(_ seed: A, accumulator: @escaping (A, Int) throws -> A) -> Observable<A>
```
