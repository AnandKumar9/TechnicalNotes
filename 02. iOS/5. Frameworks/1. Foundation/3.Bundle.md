`Bundle` has some pretty impressive capabilities and can even tell the linked frameworks, etc. at runtime.

`main` -

`allFrameworks` - A class property that gives all the application bundles that represent a framework. <br>

`allBundles` - A class property that gives all the application bundles that are not a framework. <br>

`isLoaded` - <br>

`infoDictionary` - A dictionary, constructed from the bundle’s Info.plist file, that contains information about the receiver. <br>

`classNamed` - Gets the class object in the bundle with the specified name. <br>

`principalClass` - <br>

> Try out all of this.

###### Code sample
```
var bundles = Bundle.allFrameworks
bundles.append(contentsOf: Bundle.allBundles)
bundles.append(Bundle.main)

let manifestClasses = bundles.flatMap{ (framework: Bundle) -> AnyClass?  in
    // Checking for isLoaded excludes bundles that may not have any code
    // resources in them. For example the system's Artwork bundle would
    // printout a warning that it could not find an executable for it. By
    // returning nil here, we avoid that warning.
    if framework.isLoaded == false {
        return nil
    }

    if let bundleName = framework.infoDictionary?[String(kCFBundleNameKey)],
        let manifestClass = framework.classNamed("\(bundleName).Manifest") {
        return manifestClass
    }

    let principalClass: AnyClass? = framework.principalClass
    return principalClass
}
```
