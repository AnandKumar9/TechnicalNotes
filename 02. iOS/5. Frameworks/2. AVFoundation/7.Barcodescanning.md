A `AVCaptureMetadataOutput` needs to be added to the session.

The captured data is passed on to `the AVCaptureMetadataOutputObjectsDelegate` object and the callback method called. 

The `captureOutput:didOutputMetadataObjects:fromConnection:` delegate method is called repeatedly even for a single code being captured. The code should internally include the logic to process it just once.

Be aware that only those codes will be captured that have been specified in `the AVCaptureMetadataOutput` object.

Bar code scanning is essentially a video capture session and not an image capture session.
