###### The basic classes

```
AVCaptureSession
AVCaptureDevice
AVCaptureDeviceInput
AVCaptureStillImageOutput, etc.
AVCaptureConnection
AVCaptureVideoPreviewLayer
```

`AVCaptureSession` manages session, i.e. the data flow between the inputs and outputs. It is the main coordinating object.<br>
`AVCaptureDevice` represents a hardware device, such as camera or microphone.<br>
`AVCaptureDeviceInput` is initiated with a capture device and provides the data coming from the capture device to the session. <br>
`AVCaptureOutput` represents the captured output.<br>
`AVCaptureConnection` represents the connection between a capture input and output in a session. A session can have multiple inputs and outputs added to it. Connections are not formed between all of them.<br>
`AVCaptureVideoPreviewLayer` represents the live feed generated by a camera input as a CALayer.<br>

##### The usual process

> Mentioned here for capturing a still image, but the general process should be similar for other output types too. 

1. Create a capture session object using `AVCaptureSession()`.
2. Go through all capture devices available in the system, identify the one that captures video and hold on to it. `AVCaptureDevice.devices()` gives all available capture devices.
3. Create an `AVCaptureDeviceInput` object from the identified capture device.
4. Add the above input to the capture session.
5. Configure the session as needed (`sessionPreset`, etc.)
6. Create an image output object using just `AVCaptureStillImageOutput()`.
7. Add the above image output to the capture session.
8. Create a `AVCaptureVideoPreviewLayer` by associating it to the capture session and then configure it by setting its frame, `videoGravity`, etc. and add it to the view which should show the camera feed.
9. Start running the session.
10. When image needs to be captured, get the capture connection. One way to do it is through the output object. Configure the connection by setting its `videoOrientation`, etc.
11. Capture the image by calling `captureStillImageAsynchronouslyFromConnection` on the output object. The captured image is made available as a `CMSampleBuffer` in the callback closure.
12. Check if the given buffer is not nil and converted it to `NSData` and then that to `UIImage`.

Once done stop running the session.
