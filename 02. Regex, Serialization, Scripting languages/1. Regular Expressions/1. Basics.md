##### Some theory

###### Patterns are made of atoms

A `pattern` is nothing but the regular expression you create. <br>
It is composed of `atoms` (probably also called `tokens`). So very roughly speaking every character in the pattern is called an atom.

The simplest `atom` is a literal (i.e. a character).

###### Pattern are matched against a test string

So when it is said that a regex pattern matches a target string, what it means is that all occurrences of the regex pattern are searched for in the specified string.

Pattern - [N|n]ew <br>
Test string - `New `iPad and `new `generation

In above example there are 2 matches found for the pattern.

###### Meta-characters and Quantifiers

Parts of a `pattern` can be grouped together using certain `meta-characters`, such as `( )` to form a single atom. `Quantifiers` tell how many successive occurrences of the preceding atom should be looked for.

If a meta-character or quantifier has to be used literally, then it should be preceded with a back-slash. For example `*` is a quantifier, but to be used literally can be specified as `\*.`

There are also certain simple characters that become meta-characters when prefixed with back-slash. For example `\d` denotes a digit.

Depending upon the engine used there are up to 14 different meta-characters.

Usual meta-characters - `{} [] () ^ $ . | * + ? \` <br>
Characters that become meta-characters when prefixed with `\` - `d s w D S W N`

Quantifiers - `?` `*` `+` `{}` <br>
Anchors and Boundaries - `\A` `\Z` `\z` `\b` `\B` `^` `$`

##### Summary

`\d` - digit <br>
`\w` - alphanumeric characters + underscore(`_`) <br>
`\s` - whitespace characters (blank space, tab, newline) <br>
`.` - any character except line break <br>

`+` - Match the preceding element one or more times. <br>
`*` - Match the preceding element zero or more times. So even an empty string can match. <br>
`?` - Matches preceding element exactly once or not even once. <br>
`{m,n}` - A specific no. of occurrences for the preceding element. <br>
`*?` or `+?` - Lazy matching <br>

`[..]` - One of the chars in the bracket <br>
`[l-n]` - One of the chars in range <br>
`[^..]` - One of the chars not in the bracket <br>

`|` - or <br>
`()` - Group things together. The subexpression matched by this can be later referenced. <br>
`\1`, `\2` - Denote the group nos. , i.e. ()s <br>

`?:` - Non-capturing group <br>
`?=` - Look ahead positive <br>
`?!` - Look ahead negative <br>
`?<=` - Look behind positive <br>
`?<!` - Look behind negative <br>
`?>` - Atomic group <br>

`^` - Start of string or start of line <br>
`$` or `\Z` - End of string or end of line <br>
`\A` - Start of string (line feed is not end of string) <br>
`\z` - End of string (line feed is not end of string) <br>
`\G` - Beginning of string or end of previous match (Need to test this?) <br>
`\b` - At the boundary of a word on the specified side <br>

`\` - Escape a special character. \. denotes . <br>
`\t` - Tab <br>
`\r` - Carriage return <br>
`\n` - Line feed <br>
`\h` - horizontal whitespace <br>

`\D` - All characters not included in \d <br>
`\W` - All characters not included in \w (so \w also includes whitespace) <br>
`\S` - All characters not included in \s <br>
`\N` - Not a line break <br>
`\B` - Non-word boundary- <br>

`[:alnum:]`, `[:alpha:]`, `[:blank:]`, `[:digit:]`, `[:lower:]`, `[:upper:]`, `[:space:]`, `[:word:]` - POSIX classes <br>
`[:cntrl:]` - POSIX class for control characters <br>

`(?i)` - Case-insensitive mode <br>
`(?s)` - Dot-all mode (. includes lines breaks too) <br>
`(?m)` - Multi-line mode (^ and $ match beginning and end of line) <br>
