()[Reference - Deploying to Heroku](https://docs.vapor.codes/deploy/heroku/))

```
heroku git:remote -a testhellovapor    // Configure heroku for local web-server repo app
heroku create --buildpack vapor/vapor     // Sets the buildpack as Vapor
heroku buildpacks:set vapor/vapor

echo "web: App serve --env production" \             
  "--hostname 0.0.0.0 --port \$PORT" > Procfile   // Create a procfile
  
git add .
git commit -m "adding heroku build files"
```

Heroku buildpack reference ([link](https://github.com/vapor-community/heroku-buildpack))

There is a similar instruction for [https://docs.vapor.codes/deploy/digital-ocean/](https://docs.vapor.codes/deploy/digital-ocean/) (another cloud provider) too.
