###### What is DNS

`DNS (Domain Name System)` is a system of computers that together resolve a user-friendly URL (also loosely referred to as domain) to an IP address that corresponds to the eventual web server that the user is trying to access.

Traditionally IP addresses had been `IPv4` (a 32 bit field), which has over 4 billion different addresses. It's now being replaced by `IPv6` (a 128 bit) field, which has over 340 undecillion different addresses.

###### TLD and SLD

In a URL, the highest level domain (the last part) is termed as the `Top-level Domain (TLD)`. That is .com, .edu, .uk, etc.

`Second-level domain (SLD or 2LD)` is the part just before the top-level domain, or in more technical terms the domain just below TLD. For example `co` is the 2LD for 'uk' in `xyz.co.uk`.

The TLD names are controlled by a body called `IANA (Internet Assigned Numbers Authority)`. All the TLD names can be viewed at http://www.iana.org/domains/root/db.

A `Domain registrar` is an authority that can assign domain names directly under one or more top level domains. These domain names are registered with a body called `NIC` (also known as `InterNIC`), which ensures domain names are unique across internet. Some of the domain registrars are Amazon, GoDaddy.

TLD get stored in something known as `Root Zone Database`. Each domain name gets registered in a central database known as `Whois database`.

###### Various kinds of DNS records

> The DNS is broken up into many different `Zones`. These zones differentiate between distinctly managed areas in the DNS namespace. It's not necessarily the same thing as a domain name or a single DNS server.

`SOA (Start of Authority) record` - It contains administrative information about the zone, especially regarding zone transfers.

`NS (Name Server) record` - It tells a zone which name servers to use to query for a given domain name.

`A (Address) record` - The most fundamental type of DNS record, maps a domain name to an IP address. There can be multiple A records for the same domain in order to provide redundancy. Also, multiple A records can point to the same address.

`CName (Canonical Name) record` - It's used to alias one domain name to another. So there can be a CName record to automatically resolve xyz.com as abc.com.

`Alias record` - Does the same thing as Cname record, i.e. is points to point to a different DNS record but there is a difference in how it achieves that when compared to a CName record
([Link](https://help.ns1.com/hc/en-us/articles/360017511293-What-is-the-difference-between-CNAME-and-ALIAS-records-) for difference between CName record and Alias record). <br>
In `Route53`, they are typically used to map record sets in the hosted zone to Elastic Load Balancers, CloudFront distributions, or S3 buckets that are configured as websites.

> A `apex record (naked domain)` is the DNS record at the root (or apex) of a DNS zone. Typically it can't be a `Cname` record, and instead must be `A record`.

`MX (Mail Exchanger) record` - It specifies the mail server responsible for accepting email messages on behalf of a domain name.

`Pointer (PTR) record` - It resolves an IP address to a fully-qualified domain name (FQDN). So it is the opposite to a `A record`.

Different kinds of DNS records - [Link](https://en.wikipedia.org/wiki/List_of_DNS_record_types)

###### Misc.

`TTL` is the time a DNS record is cached either in the resolving server, or on the user's own system. With most providers, the default TTL is 48 hours.

DNS is on port 53. (Does it mean that DNS servers communicate using port 53.)

ELBs do not have a pre-defined IPv4 address, they can only be resolved using a DNS name.
