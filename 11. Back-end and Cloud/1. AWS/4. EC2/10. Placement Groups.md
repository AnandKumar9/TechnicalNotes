`Placement Group` is a way of physically placing the EC2 instances. ([reference](https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/placement-groups.html))

###### Different Types of Placement Groups

1. `Clustered Placement Group` - Instances placed within a single AZ. It is recommended for applications that need low network latency or high network throughput. Only some instance types can be launched into it.

2. `Spread Placement Group` - Instances are each placed on distinct underlying hardwares. It is recommended for applications that have a small number of critical instances that must be kept separate from each other. So if a rack fails, it only affects one instance. Instances are placed on separate racks.

3. `Partitioned` - It is similar to Spread placement groups. Each group is divided into logical segments called partitions and each partition gets its own rack. So it is less 'spread', but not 'clustered' either.

###### Some more things about them

The name for a placement group must be unique within the AWS account.

Only certain types of instances can be launched in a placement group (Compute Optimized, GPU, Memory Optimized, Storage Optimized).

Placement groups cannot be merged. An existing instance can't be moved to a placement group either. It is possible however to create an AMI from an existing instance, and then launch a new instance from the AMI into a placement group.
