**Binary Tree** - Every node can have upto 2 children

**Binary Search Tree (Ordered Binary Tree/Sorted Binary Tree)** - Every progeny on left is lesser, and every progeny on right is greater.

**Max-Heap** - Every node is greater than all its children, no notion of left being lesser than right, etc.

**Min-Heap** - Every node is lesser than all its children.



A Binary Tree can be represented as an array
